# AURAD-0018 — SDK Meta на Android без экрана согласия

Date: 2026-10-14
Status: accepted

## Decision

SDK Meta (`react-native-fbsdk-next`, `AURAT-0088`) включается в prod-сборках
Android сразу, без экрана согласия на рекламное отслеживание: рекламный ID и
три события (регистрация, открытие пополнения, покупка) уходят Meta у всех
пользователей. Отказ — по запросу на почту, описанный в политике приватности.
iOS не затрагивается.

## How it works

- Prod-сборка (`aab:prod` / `apk:prod`) включает флаг
  `AURA_META_ATTRIBUTION_ENABLED`; остальные цели — нет.
- Play: Advertising ID — «да», Data safety — передача Meta рекламного ID,
  событий и покупок; переподаются в той же отправке, что первая сборка с SDK.
- Политика `aura-app.cc/privacy/`: Meta в списке третьих лиц, что передаётся,
  как отказаться.

## Why

Владелец выбрал вариант A из `AURAT-0088-005`: так же поступает конкурент
PsychicBook (на Android — без согласия, «using = accepting the policy»), а
атрибуция нужна полной и быстро. Против рассматривался вариант B (SDK только
после явного «да» — экран, поле профиля, неполная атрибуция).

**Риск принят владельцем осознанно:** аудитория Play — 34 страны, почти все
под GDPR / ePrivacy, которые требуют согласия на рекламный ID и передачу
событий для рекламы; условия Meta Business Tools перекладывают получение
согласия на приложение. Вероятность санкций для приложения этого размера
низкая (начинаются с жалобы в надзорный орган), но не нулевая. Пересмотреть —
при росте аудитории ЕС или первой жалобе; техническая база для B (флаг,
инициализация из JS) остаётся в коде.
