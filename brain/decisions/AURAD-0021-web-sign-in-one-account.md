# AURAD-0021 — Способы входа на вебе: один аккаунт с привязкой способов; почта ссылкой и кодом через BFF

Date: 2026-10-23
Status: accepted (owner-ratified 2026-10-23, разбор `AURAI-0008`)
Связано: `AURAD-0019` (веб, тот же Firebase-проект), `AURAD-0020` (домены веба), `AURAF-0020`,
`AURAI-0005` (реклама Meta), `AURAS-0004` (стоимость, Resend)

## Decision

Аккаунт Aura — это Firebase uid, и к нему **привязываются** способы входа. Данные двух uid не
склеиваются. На вебе по умолчанию — **почта**: одно письмо со ссылкой и кодом из 6 цифр, их
выдаёт и проверяет BFF, вход — Firebase custom token. Рядом Apple, Google, SMS и Facebook;
набор и порядок кнопок зависят от браузера. Приложение получает новые способы позже, отдельной
фичей.

## Р1. Один аккаунт

- Аккаунт = Firebase uid; способы — Firebase provider linking (`linkWithCredential` /
  `linkWithPopup` / `linkWithRedirect`), почта — подтверждённый `email` пользователя Firebase,
  который ставит BFF.
- Склейки данных двух uid (кошелёк, сессии, чаты, Chatwoot) нет — «O5» остаётся не
  ратифицированной.
- Второй аккаунт предотвращается: при первом входе новым не-телефонным способом (`isNewUser`)
  **до первого запроса к BFF** — экран «Новый в Aura? / Уже пользуюсь Aura в приложении → войти по
  номеру»; во втором случае пустой новый Firebase-пользователь удаляется, человек входит по SMS, и
  credential привязывается к его uid.
- `auth/credential-already-in-use` — отказ «этот способ уже вход в другой аккаунт», без склейки.
- Один подтверждённый адрес = один uid: Google / Apple с почтой существующего аккаунта входят в
  него (если Firebase не впускает сам — BFF проверяет ID token провайдера и отдаёт custom token
  этого uid, веб привязывает credential).
- `/me` → «Способы входа»: список, привязать / отвязать (кроме последнего), «Добавьте номер,
  чтобы войти в приложении».

## Р2. Способы и кнопки на вебе

- Почта — по умолчанию (поле + «Continue with email»), ряд «or continue with» под ней.
- Google в встроенных браузерах не показывается (`disallowed_useragent`).

| Окружение | Ряд |
|---|---|
| Webview Facebook / Instagram | **Facebook** · Apple · Phone (+ «открыть в браузере — вход через Google») |
| Прочие webview | Apple · Phone · Facebook |
| iOS / macOS Safari | **Apple** · Google · Phone · Facebook |
| Остальные | **Google** · Apple · Phone · Facebook |

- Facebook Login — в существующем Meta App `4422398391357112`.
- Popup на desktop; redirect на телефоне и во webview.

## Р3. Почта

- Одно письмо (Resend, отправитель на `send.aura-app.cc`, 24 языка): кнопка «Log in to Aura» и
  код из **6 цифр**. На экране сначала ссылка, «Enter code instead» — код.
- **Ссылка впускает только браузер, в котором её открыли.** Ждущая вкладка того же браузера
  подхватывает вход сама (синхронизация Firebase между вкладками); другое устройство — по коду.
  Вход ждущей вкладки по ссылке, открытой где-то ещё, не делается (фишинг «approve on another
  device»).
- Страница ссылки входит по нажатию кнопки, не на загрузке (сканеры ссылок).
- BFF: попытка в Redis (хэши кода и токена, TTL 15 мин), ответ без перечисления почт, лимиты на
  почту и IP, 5 неверных кодов гасят попытку; `getUserByEmail` / `createUser({ emailVerified:
  true })` → `createCustomToken`.
- Email-провайдер Firebase (пароль, ссылка) не включается.

## Р4. `authDomain`

`authDomain` = домен веба (`web-dev.aura-app.cc`, `web.aura-app.cc`); `/__/auth/` и
`/__/firebase/init.json` проксируются nginx'ом на `aura-2781b.firebaseapp.com`; на этих путях —
без `frame-ancestors 'none'`. Redirect URI провайдеров — на каждое окружение.

## Р5. Почта в профиле

`email` в BFF — только подтверждённая (токен с `email_verified`, код / ссылка). У человека,
вошедшего по телефону, — редактируемое поле «for receipts» до подтверждения; рассылка — только
на подтверждённую.

## Р6. Оффер первой сессии

Как есть — по аккаунту; метрика доли офферов у аккаунтов без телефона. Ужесточение (оффер только
с привязанным номером) — по данным.

## Р7. Приложение

Остаётся на SMS. Google, Apple, почта (+ Facebook на Android), экран способов и тот же вопрос
«уже есть аккаунт?» — отдельной фичей позже (ID — при запуске). На iOS при стороннем входе
обязателен Sign in with Apple (App Store 4.8). До паритета строка окна входа уточняется: «One
account for the app and the web — the app signs in with your phone».

## Р8. Шаг имени

«Tell us who you are» — без Skip (подтверждает `AURAT-0104-006`) для любого способа: выход —
только закрыть окно; действие не продолжается, следующий gate снова спрашивает имя. Имя из
Google / Apple подставляется.

## Деньги

Платим только за SMS (по стране, US $0.01, ES $0.04, DE $0.10); почта, Google, Apple, Facebook — $0
до 50 000 MAU. Новые способы снижают расход на SMS. Письма входа — Resend: бесплатно 100 в сутки
(общий лимит с Chatwoot), дальше Pro $20/мес. Identity Platform не нужен.
