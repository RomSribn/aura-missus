# AURAI-0012 — ИИ-перевод чата: архитектура, провайдер через DI, стоимость, приватность

Дата: 2026-11-07 · Статус: **заглушка — не запущено** · Фича: `AURAF-0024`
Выдано координатором (сессия slave-1-ac) по решению владельца (решение 8 `AURAI-0010` — Б): «давай сделаем вариант Б,
попробуем прикрутить ИИ перевод, claude за max подписку выдает 100 баксов на API usage. Только нужно сделать так, чтобы
через DI мы могли в будущем менять модели или АПИ на другие провайдеры, не только CLAUDE».
Репо исследования — `aura-bff-manor` (ядро — BFF); итог — решения владельца и разбивка на задачи по репо.

## Вопросы

1. **Где и когда переводить.** Путь отправки (человек → Chatwoot) и путь приёма (вебхук / опрос: чаттер → человек):
   синхронно или очередью (BullMQ уже есть), что видит чаттер (перевод как текст + оригинал в `content_attributes`, или
   оригинал + перевод заметкой, или свой стол `agent-desk`), что видит человек (перевод, «показать оригинал»?).
   Токены чаттера (`::SESSION::`, `::CUPS_02::`), маркеры сессии, вложения (переводится только подпись), удаление
   столом, повторы вебхука и опроса — переводить один раз (идемпотентность по id сообщения).
2. **Язык разговора.** Сервер сейчас язык человека не хранит (`AURAF-0023`: вне объёма v1). Для ответов чаттера он
   нужен: хранить на разговоре по последнему `?lang` отправки / чтения истории; передавать в Chatwoot атрибутом
   (`AURAT-0168-007` §5 — набросок). Смена языка посреди разговора: старые сообщения — как были или перевод при чтении.
3. **Порт и DI (требование владельца).** Интерфейс перевода без типов провайдера (`translate({ text, from, to,
   context }) → { text, detected?, provider, model }` — уточнить), токен внедрения в NestJS, адаптеры: Claude (официальный
   `@anthropic-ai/sdk`) — первый; «выключено» / фейк для тестов и dev; выбор провайдера и модели — env (`TRANSLATION_*`),
   проверка при старте, как `DISABLED_LANGUAGES`. Как добавить второго провайдера (OpenAI, DeepL, Google) без правок
   чата — показать на скелете.
4. **Модель и стоимость (бюджет владельца — около $100 в месяц).** Цены из справки Claude API (на 2026-10-06, за
   1 млн токенов, вход / выход): Claude Opus 5.5 — $4 / $20 (чтение кэша $0.20), Claude Sonnet 5.5 — $2 / $10, Claude
   Haiku 5.5 — $0.10 / $0.50. Оценить на выборке сообщений со staging (длина, языки) цену одного перевода и сколько
   переводов даёт бюджет для каждой модели; кэширование системного промпта (глоссарий, обращение по языкам; минимальная
   длина кэшируемого префикса зависит от модели), `effort`, лимиты, потолок расходов и что делать при его достижении.
   Модель — решение владельца (по умолчанию в справке — Opus 5.5; смена — конфигурацией).
5. **Качество.** Глоссарий приложения (`scripts/i18n/glossary.json` v3: таро, psychic, medium, запрет reader / reading),
   обращение по языкам (`AURAF-0023-glossary.md`), не согласовывать с полом человека, не добавлять и не терять смысл,
   имена и эмодзи как есть; набор примеров для проверки (eval) на нескольких языках.
6. **Приватность и право — блокер прода.** Переписка уходит внешнему провайдеру; в консультациях бывают здоровье,
   отношения, вера (особые категории данных GDPR). Политика конфиденциальности, договор обработки данных, хранение у
   провайдера, уведомление в приложении («переводит ИИ»), согласие — решение владельца / юриста. Staging — можно сразу.
7. **UX.** Приложение и веб: подпись «переведено», «показать оригинал», что в пуше (пинг без текста — не меняется),
   ошибки перевода (оригинал + пометка, повтор). Стол чаттера: оригинал и перевод, язык клиента, приветствие.
8. **Выкатка.** Флаг на сервере, staging → прод; порядок с клиентами; что видят старые версии приложения.
