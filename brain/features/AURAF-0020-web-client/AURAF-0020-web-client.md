## What
Веб-версия Aura в браузере, desktop и телефон одной адаптивной сборкой: тот же
аккаунт, что в приложении (вход по телефону), каталог и профили советников открыты
гостю, бесплатный чат, бронь платной сессии с баланса. Бренд, токены и оффер −50%
те же, что в приложении. Отдельный репозиторий `aura-web` и манор `aura-web-manor`.

## NOT in scope
- Голосовые и видеозвонки — их нет в продукте.
- Вложения в чате, колокольчик уведомлений, поиск в шапке — v2 по хендоффу.
- SSR/SEO — позже, пререндером, отдельным решением.
- Общий пакет логики `@aura/domain` — отдельным решением (`AURAD-0019`).

## Languages
Веб — на английском и на всех официальных языках ЕС (bg cs da de el es et fi fr ga hr hu it lt lv
mt nl pl pt ro sk sl sv), i18next; язык — первый поддерживаемый из настроек браузера, иначе
английский. Каждая задача веба добавляет свои строки сразу на все языки (решение владельца
2026-10-20, `AURAT-0101-010`; правило 9 в `aura-web-build-rules.md`). Приложение не затронуто.

## Context
- Стек и топология — `AURAD-0019`; план фаз и FSD-раскладка — `AURAI-0007`.
- Расхождения хендоффа (навигация, OTP 4→6, брейкпоинты, `/me` vs `/profile`)
  сверяются с дизайнером до хай-фай; источник истины — README/NAVIGATION, OTP — 6.
- BFF для веба (задачи `…-bff-…` для `aura-bff-manor`, ID минтятся в
  `aura-app-manor`): CORS, проверка Origin на `/ws`, `@Public` каталог и профиль,
  фильтры/сортировка/пагинация `GET /v1/advisors`, веб-домен в Firebase.
- BE в строках 001, 002 — `AURAT-0102`: каталог `@Public`, слоты и цена гостю
  (токен необязателен), CORS и `Origin` на `/ws` по `WEB_ALLOWED_ORIGINS`.
  Профиль — из ответа каталога (`GET /advisors/:id` нет), фильтры и сортировка —
  на клиенте (8 персон); фильтра «язык» и онлайн-точки гостю нет (решение
  владельца, `AURAT-0102-006`). BE ✗: 011 — PSP; 012 — матчинг.
- UI 001, 002 — `AURAT-0103`: фильтры онлайн и язык не показываются (данных нет, `AURAT-0102-006`),
  категорий три (`AdvisorCategory`); оффер гостя — из ответа pricing (`AURAT-0103-006`).
- UI 003, 004 — `AURAT-0104`: BFF без изменений (`/v1/me` создаёт аккаунт при первом обращении).
  «Skip for now» нет — имя обязательно, как в приложении (`AURAT-0062`; решение владельца
  `AURAT-0104-006`); опт-ин на рассылку выключен по умолчанию (GDPR, как приложение). Намерение
  и шаг кода переживают перезагрузку (`sessionStorage`, 15 мин). Get started — с задачей Home;
  Ask (причина `ask`) — со строкой 012. Временная `/me` (имя, телефон, Log out) — до строки 010.
  Живой вход требует Firebase Web App (`VITE_FIREBASE_API_KEY`/`APP_ID`) — действие владельца.
- UI 005 — `AURAT-0105`: BFF без изменений. Список — история по советникам каталога, свежие сверху;
  догон по REST при каждом подключении сокета, возврате на вкладку, появлении сети и раз в 30 с в
  открытом треде (свои сообщения по сокету не приходят, push у веба нет). Решения владельца
  (`AURAT-0105-006`): бейдж — «новое за этот визит»; typing рисуется; поиска по чатам нет; `/chats`
  на desktop открывает свежий тред; 761–1180 — две колонки без rail; в треде на телефоне таб-бара
  нет; Enter отправляет только с мышью; два маркера сессии BFF переводятся; в приглашении нет цены и
  минут (`AURAF-0013`). Бронь из чата (календарь, приглашение, rail) — ссылка `?book=1` до строки 006.
  Входящие вложения — превью картинок и скачивание файлов; отправка — v2.
- UI 006 — `AURAT-0107`: BFF без изменений. Одна шторка Book с оплатой внутри из профиля и чата
  (из чата — с ближайшим свободным слотом: Quick book), 14 дней с сегодня, блоки сервера, черновик
  в `sessionStorage`; `/checkout` своей страницы не имеет (ведёт в шторку черновика) до строки 007;
  Booked — сессия из ответа брони или из `GET /v1/sessions`, «Open chat» и .ics, «Go to session» —
  со строкой 009; баланс в шапке без Top up; при нехватке — временная строка «пополните в
  приложении» до PSP; без `startNow` и поля вопроса (решения владельца `AURAT-0107-006`). Строка
  007 — `AURAT-0108`.
- Бэклог 014–016: сейчас `GET /v1/advisors` отдаёт весь каталог одним ответом, и каждая персона
  несёт все опубликованные отзывы; фильтры, сортировка и страницы по 24 — в браузере
  (`AURAT-0102-005` §4: персон 8). Делается задачами contracts + BFF + web (ID — в
  `aura-app-manor`): параметры и курсор у `GET /v1/advisors`, отдельный постраничный эндпоинт
  отзывов. Приложение тоже читает `reviews` из каталога — убирать их из ответа только вместе с
  ним (или с переходным периодом). Бесконечная прокрутка вместо «Show more» хендоффа — решение
  владельца; веб-часть — `IntersectionObserver` на RTK Query с курсором, URL-контракт
  `?cat&sort&pmin&pmax&rating` не меняется.
