# AURAF-0021 — Промокоды
Type: product
Status: done — сервер и бэкофис (`AURAT-0143`), приложение (`AURAT-0144`) и веб (`AURAT-0145`) проверены на bff-dev, 2026-10-28
Priority: P1
Source spec: none (слова владельца + план `aura-app-manor`; разбор — `AURAT-0143-005`)

## What
Оператор в бэкофисе BFF создаёт партию одноразовых промокодов на сумму кредита в USD —
под кампанию и со сроком действия. Человек вводит код в приложении или на вебе: баланс
кошелька пополняется на сумму кода, код гаснет. Промо-кредит — отдельная проводка журнала
`PROMO_CREDIT`, отличимая от оплаченных пополнений.

## NOT in scope
- Многоразовые публичные коды («ANNA10» на первых 100), коды только для новых аккаунтов,
  ссылка с кодом — модель им не мешает (погашение — отдельная таблица).
- Ручное списание погашенного кода — журнал append-only; если понадобится, это своя
  компенсирующая проводка.
- Отдельный промо-баланс — понадобится вместе с возвратом денег на карту (`AURAF-0009`);
  тип `PROMO_CREDIT` позволяет отделить промо-деньги задним числом.
- Продажа кодов — только бесплатные (обход IAP: Apple 3.1.1, платёжные правила Play;
  `AURAI-0006`).
