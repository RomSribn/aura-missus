# AURAT-0036-008 — Запись голосового снята, сборка перевыпущена

Дата: 2026-08-21
Коммит: `ec6e7f0`

## Почему сборка упала

Первый прогон `bundleRelease` завершился отказом на
`:react-native-audio-recorder-player:compileReleaseKotlin`:

```
HybridAudioRecorderPlayerSpec.kt:31:11 Unresolved reference 'updateNative'
```

**И это не мой код.** Это сгенерированный nitrogen'ом Kotlin самого пакета: он
зовёт `updateNative`, которого нет в установленном `react-native-nitro-modules`
0.36.5.

Отдельно стоит записать: **первый прогон отрапортовал успех**. Команда была
`./gradlew … > log 2>&1; echo EXIT=$?; tail log`, и наружу вышел код `tail`, а
не gradle. Проверять надо результат (`ls` артефакта), а не строку в конце лога —
ровно та же ловушка, что в `AURAT-0031` («логи умеют врать»).

## Развилка

| Вариант | Цена |
|---|---|
| Поднять Nitro до нужной рекордеру | Нарушает `^0.36.5`, объявленный `react-native-iap` — рельсом Google Play. Владелец в этот же день попросил включать биллинг в **каждый** AAB |
| Откатить рекордер до 4.0.1 | Единственная версия, чей Kotlin собирается против 0.36.5 (проверено grep'ом по тарболам 4.0.1 / 4.1.5 / 4.2.2 / 4.3.1 / 4.4.4). Но у неё другой API — класс вместо синглтона; `tsc` дал 5 ошибок сразу |
| Снять запись голоса | Теряется одна строка из девяти |

Выбрано третье. Рисковать платёжным рельсом ради голосовой заметки — плохой
размен, а гнуть приложение под годовалый пакет — плата, которую нечем оправдать.

## Что снято и что осталось

Снято: зависимость, ветка записи в `use-attachment-draft`, четвёртая строка
шита, состояние записи в строке черновика, разрешение на микрофон в обеих
платформах (приложение, объявляющее микрофон и не пишущее — вопрос на ревью).

Осталось: камера, галерея, файл, честный отказ. **Приём голосовых не затронут** —
играет через `react-native-video`.

## Заодно

- `npm run aab` — «биллинг в каждом AAB» стало механикой, а не памятью.
  Закоммиченные значения флагов остаются `false` во всех таргетах, как требует
  `env/README.md`; включает их команда сборки.
- `env/.env.prod` наконец несёт боевой адрес. Файл сам обещал: «когда AURAD-0005
  появится, реальный origin коммитится сюда». Он появился 2026-08-19, а значение
  с тех пор лежало незакоммиченным в рабочей копии.
- Тест этого файла разъехался с реальностью и подвинут: `prod` теперь закреплён
  за боевым хостом, `tunnel` сохраняет прежний инвариант — адрес туннеля
  принадлежит одной машине и одной сессии.

`tsc` чисто, `lint` чисто, **374 теста**.
