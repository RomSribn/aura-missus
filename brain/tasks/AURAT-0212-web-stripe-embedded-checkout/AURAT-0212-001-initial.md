## Что нужно

После «Pay $X» в шторке Book форма Stripe открывается прямо в шторке (Embedded Checkout), и человек не
уходит с сайта.

1. **Stripe.js.**
   - `@stripe/stripe-js` — `loadStripe`. Скрипт грузится только с `js.stripe.com`, собирать его в
     бандл нельзя.
   - `@stripe/react-stripe-js` — `EmbeddedCheckoutProvider` и `EmbeddedCheckout`.
   - Отдельный чанк, загружается только при оплате.
2. **Поток в шторке.** Сейчас `features/pay/model/use-pay.ts:298` делает `loadPage(page.redirectUrl)`.
   Станет так:
   - старт отдаёт `clientSecret` и публичный ключ (решение 2 `AURAT-0211`) — форма появляется в шторке;
   - `onComplete` запускает тот же `settleTopUp` на месте: «Still confirming…», бронь тем же ключом,
     Booked. Без перехода на `/checkout`;
   - банковские методы уходят к банку и возвращаются на `/checkout?payment=`. Для них остаются
     нынешний путь возврата, `pending-store` и обработка Back (041);
   - если, пока форма открыта, человек закрывает шторку или меняет выбор — `provider.cancel`. Сессия
     закрывается; если человек успел заплатить, деньги зачислены и бронь проходит, как при
     `cancelled=1`.
3. **Порт `TopUpProvider`** (`model/top-up-provider.ts:39`). `startCard` вместо ссылки отвечает данными
   для формы — по контракту `v0.33.0`. Фейк (`fake-provider`, `/psp-sandbox`) — решение 2.
4. **CSP** (`deploy/web/headers.conf:18`). Добавить источники Stripe для встроенной формы в
   `script-src`, `frame-src` и `connect-src` по списку Stripe: `js.stripe.com`, `hooks.stripe.com`,
   `api.stripe.com` и другие — точный список сверить в спеке. Без этого форма не загрузится в проде.
5. **Вёрстка.**
   - Форма высокая: в шторке это отдельный шаг «оплата» на всю высоту, на телефоне — во весь экран,
     с понятным «назад».
   - Внешний вид формы задаётся в Branding в Dashboard: цвета, шрифт, логотип Aura. Что ещё можно
     настроить у встроенной страницы — сверить.
6. **Строки — на 24 языках.**
   - `topUp.note` («Opens Stripe’s secure page — …») меняется, потому что форма теперь на месте.
     Например: «Secure payment by Stripe — you may be charged in your local currency».
   - Новые строки шага оплаты и закрытия формы.
   - Язык самой формы — `locale` сессии из `?lang`, BFF его уже передаёт.
7. **Тесты** — Vitest с моком `EmbeddedCheckout`:
   - старт → форма → `onComplete` → Booked без перехода;
   - закрытие шторки → `cancel`;
   - уход к банку → `/checkout`;
   - 404 на старте → «Top up in the Aura app»;
   - CSP — если `build.sh` проверяет заголовки, добавить проверку туда.

## Уточнения от `AURAT-0211` (2026-11-12, до старта этой задачи)

Пришли из сессии BFF. Черновик контракта может поменяться после одобрения спеки владельцем —
сверить с тегом `v0.33.0`.

- **Контракт.**
  - Запрос: новое поле `ui: 'hosted' | 'embedded'`, по умолчанию `hosted`.
  - Ответ — `discriminatedUnion('kind')`:
    - `{ kind: 'redirect', redirectUrl }`;
    - `{ kind: 'embedded', clientSecret, publicKey }`.
  - Повтор того же `paymentId`, пока сессия открыта, отвечает тем же `clientSecret`. Тот же `paymentId`
    с другим `ui` — `409 card_top_up_payment_conflict`.
- **В режиме embedded веб обязан понимать и `kind: 'redirect'`.** Так BFF отвечает, если оплата уже
  прошла и ждёт подтверждения (REVIEW, банковский метод). Тогда — переход на свою
  `/checkout?payment=<id>`.
- **Домен для кошельков.**
  - `web-dev.aura-app.cc` зарегистрирован в sandbox: `pmd_1Uaxr3PzZXCl9nsG4HT7Sl34`. Apple Pay, Google
    Pay, Link, PayPal, Klarna — `active`.
  - Файл ассоциации Apple не нужен: проверку мерчанта Stripe делает сам.
  - `web.aura-app.cc` — регистрировать в live вместе с воротами `AURAD-0023`.
- **Apple Pay во встроенной форме** — только Safari / iOS 17+.
- **Permissions-Policy.** У веба сейчас этого заголовка нет (`deploy/web/headers.conf`). По словам сессии
  BFF, без `payment=(self "https://js.stripe.com" "https://checkout.stripe.com")` Chrome на Android не
  покажет Google Pay. Сверить по документации Stripe в спеке.
- Форму не класть во вложенный iframe.
- **Истечение.** Встроенная сессия живёт до `expires_at` (1 ч). Если форма открыта дольше, сессия
  истекла: Stripe покажет это в форме, а статус BFF ответит `cancelled`. Веб начинает новую попытку с
  новым `paymentId`, а не оставляет мёртвую форму. Ключ брони при этом не меняется.
- **Повторный маунт.** Повтор старта тем же `paymentId`, пока сессия открыта, отдаёт тот же
  `clientSecret` — проверено в sandbox 2026-11-12: `retrieve` его отдаёт. Перемонтировать форму тем же
  секретом можно.
