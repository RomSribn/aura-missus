# AURAT-0096-010 — fix: без `::SESSION::`

Владелец на телефоне (staging, `cmvcngelf…`, Sunshine): приглашение заменяет **весь** пузырь
своей карточкой — текст промо не виден. Варианты: два сообщения (текст + отдельный
`::SESSION::`) или без токена. Решение владельца — **без токена** (рекомендация: основная
аудитория на старых сборках увидела бы второй пузырь «Continue this reading privately», и
два пуша на юзера).

Решение D1 из `005`/`006` отменено.
