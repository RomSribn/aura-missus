# AURAT-0096-018 — add: `--every-thread`

Владелец: «а почему 75, чатов же 155» → объяснено (156 диалогов у 77 юзеров, по одному сообщению
на юзера) → «давай во все диалоги, кроме Justine».

## Находки на проде (read-only)
- Justine = контакт `w0x0F…` → userId `cmvblw6s50k0u01ryaidmwgt5`: оффер использован → команда её
  пропускает и так; отдельного исключения не нужно. Советника/агента с таким именем нет.
- После прогона владелец вручную отправил из деска ещё **25** копий (sender `Roman Sribnyi`, id 1;
  19:18–19:22). Они отличаются апострофом: `It’s` (U+2019) вместо `It's` → точное сравнение текста
  их бы не узнало и в эти 25 диалогов ушло бы второе сообщение.
- Осталось: **54 диалога у 29 юзеров** (активный советник, оффер не использован, промо в диалоге нет).

## Изменения
- `--every-thread` (с `--dry-run` / отправкой / `--limit`; не с `--only`): каждый диалог с активным
  советником, где промо ещё нет. Отправка кругами — сначала у всех первый (самый свежий) диалог,
  потом второй… — у одного человека пуши от разных советников разнесены на целый круг.
- «Уже отправлено» — по началу текста `FIRST_SESSION_PROMO_MARK` («Good news — your first session
  with me is now 50% off», `startsWith`), а не по точному тексту — ручные копии засчитываются.
- `PromoConversation.announced` (по диалогу), `pendingConversations`, `inRounds`; тесты; README.

typecheck / lint — чисто; `jest` 122 suites / 1546 tests — зелёные.

develop → `bff-dev` (`--dry-run --every-thread`) → main → prod `--dry-run --every-thread`
(ожидаем 54 сообщения) → прогон. Владелец не шлёт вручную во время прогона.
