# AURAT-0220-005 — Spec: рабочие часы чаттеров (BFF + расписание в меню Chatwoot)

Date: 2026-11-18
Status: draft — ждёт одобрения владельца. Правила — `AURAD-0025`, здесь только как это строится.
Исполнитель — `aura-bff-manor`. Приложение и веб не меняются, контракт `@aura/contracts` — тоже.

## 1. Данные (Prisma, миграция)

- `ChatterSchedule` — `chatwootAgentId` (unique), `timeZone` (IANA, проверяется), `updatedAt`.
- `ChatterWeeklyInterval` — `chatwootAgentId`, `weekday` (ISO 1–7), `startMinute`, `endMinute`
  (локальное время, `0 ≤ start < end ≤ 1440`, кратно `SESSION_SLOT_STEP_MINUTES`). Несколько на день.
  Смена через полночь — два интервала (UI режет сам).
- `ChatterDateOverride` — `chatwootAgentId`, `date` (локальная `YYYY-MM-DD`), интервалы того же вида;
  пустой список = выходной. Правка дня заменяет шаблон этого дня целиком.
- Прошедшие правки чистит существующий механизм джобов (или запрос просто их не читает — на выбор
  исполнителя).

## 2. Покрытие (чистые функции, рядом с `slot-grid.ts`)

- `expandWorkingHours(schedule, from, to): BusyInterval[]` — шаблон + правки → UTC-интервалы окна.
  Локальная дата → инстант через `zoned-date`, не «+24 ч» (DST).
- `unionIntervals(...)`, `covers(coverage, from, to)`.
- В покрытие идут только агенты, которые **сейчас есть в аккаунте** Chatwoot окружения: удалённый
  чаттер своё расписание теряет. Список агентов уже читается для `onlineAgentCount` — переиспользовать,
  с кешем.
- `fitsInterval` получает `coverage: BusyInterval[] | null`; `null` = флаг выключен = 24/7.

## 3. Где применяется

- `getAvailability` — сетка и `instantAvailable`. Для «сейчас» — покрытие **и** `onlineAgentCount > 0`.
- Бронь, «сейчас» и перенос — та же проверка на сервере; вне часов — тот же `SlotTakenError` / 409:
  клиент уже умеет это показывать, причина наружу не выходит.
- Календарь агент-деска (`advisor-calendar`, `AURAT-0083`) — помечает нерабочее время, чтобы чаттер не
  предлагал клиенту такой слот.
- Флаг `SESSION_WORKING_HOURS_ENABLED` (env, по умолчанию `false`).

## 4. API агент-деска (вход — существующая сессия `DeskAgent`)

- `GET  agent-desk/api/schedule` — своё расписание (пустое, если не заведено).
- `PUT  agent-desk/api/schedule` — сохранить целиком (таймзона, неделя, правки на горизонт).
  Ответ несёт `uncoveredBookings` — сколько живых броней после сохранения осталось без покрытия.
- `POST agent-desk/api/schedule/preview` — то же число **до** сохранения, для предупреждения.
- `GET  agent-desk/api/schedule/coverage?days=N&tz=…` — покрытие пула по шагам сетки: сколько чаттеров
  работает. Без имён других чаттеров.

## 5. Страница «Расписание» (`GET /agent-desk/schedule`)

Тот же клиентский бандл / сборка, что `client/desk.ts`, тот же вход через мост. Русский, как виджет.
1. Таймзона — по умолчанию из браузера, выбор из списка.
2. Неделя — 7 строк: переключатель «работаю», интервалы `09:00–18:00 [+]`, «скопировать на будни».
   Шаг выбора — `SESSION_SLOT_STEP_MINUTES`.
3. Ближайшие `SESSION_BOOKING_HORIZON_DAYS` дней — клик по дню: свои часы или выходной; метка у
   изменённых, «вернуть по неделе».
4. Покрытие пула — тепловая карта недели по часам, дыры (0 чаттеров) подсвечены.
5. Сохранение с предупреждением «N броней останутся без покрытия» (не запрет).

## 6. Пункт меню в Chatwoot (мост `install-agent-desk-bridge.rb`)

- Тот же блок между маркерами: к ответу на вход добавляется вставка пункта «Расписание» в левое меню.
  Держится `MutationObserver` (сайдбар перерисовывается). Не нашёл якорь — плавающая кнопка в углу.
- По клику — панель на всю рабочую область с iframe `<BFF>/agent-desk/schedule`, закрытие — крестик /
  Esc / уход на другой роут. Iframe — свой фрейм страницы, мост отвечает ему как есть.
- BFF выбирается по аккаунту из URL: новая переменная раннера (вида `AGENT_DESK_ACCOUNTS=1=https://…,
  2=https://…`); аккаунт без записи — пункта нет. Какой аккаунт какой — сверить с `AURAD-0016`.
- Идемпотентность и `AGENT_DESK_REMOVE=1` сохраняются. В чек-лист обновления Chatwoot (`deploy/README`)
  — «пункт меню на месте».

## 7. Бэкофис

Страница «Расписания»: все чаттеры (имя из Chatwoot) — таймзона, неделя, правки; правка за чаттера;
дыры покрытия на горизонт; список живых броней без покрытия (персона, время, ссылка на разговор).

## 8. Тесты (в слоте)

- `expandWorkingHours`: DST вперёд/назад (Europe/Kyiv, America/New_York), смена через полночь двумя
  интервалами, правка дня поверх шаблона, выходной.
- `covers` на стыке двух чаттеров (17:45–18:15 при 9–18 и 18–24).
- `getAvailability` / бронь / перенос / «сейчас» с флагом и без; вне часов — 409; без онлайна — «сейчас»
  недоступно при покрытом блоке.
- Удалённый из аккаунта агент не покрывает.
- API расписания: чужое не читается и не пишется; валидация шага и границ.
- Раннер моста: идемпотентен, удаление, вставка не ломает существующий ответ на вход.

## 9. Проверка в маноре (после мёржа)

dev-аккаунт Chatwoot: пункт «Расписание» в меню, сохранить часы, в приложении / на вебе слоты вне часов
недоступны, «сейчас» гаснет без онлайна, предупреждение о бронях без покрытия, бэкофис видит расписания.
Флаг на проде включать после заполнения расписаний.

## Вне скоупа

Лимит одновременных сессий на чаттера (v2), команды по персонам, изменения приложения / веба / контракта,
автопереключение статуса Chatwoot по расписанию.
