# AURAT-0177-001 — initial (заглушка)

Дата: 2026-11-07
Репо: `aura-web-manor` (веб). Выдан координатором (сессия slave-1-ac) по решению владельца в спеке `AURAT-0175`
(`AURAT-0175-006-approval.md`, вариант А): «Принятие глоссария в веб — отдельной задачей, номер выдаётся в
aura-app-manor».
Фича: `AURAF-0023` (переводы на 24 языка).

## Откуда

Build rules приложения говорят: `scripts/i18n/glossary.json` — единый источник терминов, «aura-web берёт копию по
`version`». На деле у веба копии нет вовсе — ни v1, ни v2 — и нет проверки, которая её читала бы (`AURAT-0175-004`).
Поэтому расхождения веба с глоссарием, найденные при переводе приложения, до сих пор не исправлены.

## Что нужно

1. **Копия глоссария** в вебе (например, `scripts/i18n/glossary.json`) — по `version`. Брать **v3**, когда
   `AURAT-0174` (приложение) её закоммитит: в v3 el `psychic` — «Διορατικός / Διορατική». До этого — v2.
2. **Проверка** «в переводах нет запретных форм (`avoid`)» — как в приложении: правила сопоставления —
   `aura-app/scripts/i18n/terms.js` (начало слова, режим `exact` у кнопок и ярлыков), тест переводов приложения —
   образец. Номер версии копии — виден в тесте, чтобы обновление глоссария было заметно.
3. **Правка расхождений веба** — список в brain `features/AURAF-0023-app-localization/AURAF-0023-glossary.md`,
   раздел «Расхождения веба — для задачи в aura-web-manor» (ga «léitheoir», es «Hecho» / lt «Gerai», da «Redigér»,
   кнопки bg / hr / sl / hu / el в форме кнопки, fr / pt / ro «chat» в значении разговора ≈ 20 строк, lt / it / ro
   «бронировать», «Browse advisors», sl «dobroimetje», `auth-by-phone:phone.legal`, `app:nav.getStarted`, `daily-page`,
   `advisor-page:specialties`, `write-review:title`, pt — род в обращении, fr U+00A0, кнопки `delete-account:keep`).
   Без этого проверка сразу красная.
4. Решения по дрейфу веба (`AURAF-0023-glossary.md`, «Решения по дрейфу веба») — уже приняты, не пересматривать.
5. Ревью носителями — желательно; `@sensitive`-строки (оплата, удаление аккаунта, юридические) — по правилу
   `AURAI-0010`, решение 7.

## Зависимость

`AURAT-0174` — глоссарий v3. `AURAT-0175` (веб, подписи советников) идёт отдельно и эту задачу не ждёт.

Не запущена — ждёт команды владельца.
