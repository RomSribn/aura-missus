# AURAT-0136-009 — Fix: Language — поле с автодополнением

Date: 2026-10-25

Владелец: «в списке языков хорошо бы сделать селектор автокомплит».

Сделано: список из 24 строк (radiogroup) заменён полем-комбобоксом (ARIA APG «list autocomplete»):

- Поле в виде `Field` (метка «Language», иконка поиска, шеврон); закрытое показывает текущий язык
  его собственным названием.
- Фокус открывает все 24 языка; набор сужает список по любому имени — своему (`Deutsch`), на
  языке экрана (`German` / `Alemán`), английскому, коду; без учёта регистра и диакритики
  (`espanol` → Español). У каждого варианта — своё название и, серым, название на языке экрана.
- ↑/↓ — по списку (активный прокручивается в видимость), Enter или клик — выбрать, Esc — закрыть
  (на телефоне Esc закрывает сначала список, потом шторку). Ничего не нашлось — «No language
  matches that». Выбор — как раньше: язык сразу, `localStorage`.
- Desktop — выпадающий список под полем (до 440px шириной); телефон — список в потоке шторки.

Файлы: `pages/me/model/use-language-picker.ts` (вместо `use-choose-language.ts`),
`pages/me/lib/match-language.ts` + тест, `pages/me/ui/language-picker.tsx` + css (вместо
`language-list.*`); `shared/i18n` `languageName(language, inLanguage?)`; строки
`me-page` `language.search`, `language.none` — en + 23 языка (свои переводы, без вычитки).
Тесты: два теста Language в `app/__tests__/profile.test.tsx`, `match-language.test.ts`,
`language-choice.test.ts`.

Проверки: typecheck, lint, vitest (86 / 1564), build — зелёные.

## Доработка (2026-10-25)

Владелец: на телефоне при пустом или коротком результате шторка сжимается, низа не видно. Поле
на телефоне держит высоту не меньше 62 % видимой части экрана (`--visible-h` слоя шторки — над
клавиатурой): шторка не скачет при наборе и не прячется под клавиатурой.

Владелец: на телефоне скроллиться должен только список, не вся шторка. Пикер на телефоне — колонка
фиксированной высоты (62 % `--visible-h`), список в ней тянется и прокручивается сам; раздел
Language в шторке (`.fill`) может сжаться, если шторке не хватает места, — поэтому шторка сама не
скроллится.
