## A · Бакет: что лежит на самом деле

Все 78 карт скачаны с публичного домена по ключам манифеста с заменой
`.png` → `.jpg` (в scratchpad, не в репозиторий — вопрос прав из `AURAD-0012`).

| Проверка | Результат |
|---|---|
| 78 × `tarot/<card>.jpg` | **200**, `content-type: image/jpeg` |
| 78 × `tarot/<card>.png` (выборочно, с `?cb=`) | **404** |
| `ETag` (MD5 объекта) против MD5 скачанного файла | **78 из 78 совпали** — край отдаёт байты бакета без изменений |
| Размеры | 67 × **672×986**, 11 × **670×989** (`cups-10`, `cups-knight`, `pentacles-05`, `swords-09`, `swords-king`, `swords-page`, `swords-queen`, `wands-05`, `wands-06`, `wands-knight`, `wands-page`) |
| Вес | **13,6 МБ** всего, от 146 КБ до 211 КБ; 78 различных sha256 |
| `last-modified` | 10 Sep 2026 14:41 GMT |
| `cache-control` | `max-age=14400` — снова дефолт Cloudflare (ручная заливка через дашборд) |

Это **другой арт**, не переименование: был PNG 413×712, стал JPEG ~672×986.
Прежний манифест (sha256/bytes от PNG) к нему не подходит ни одной строкой.

Локально `.jpg` нет: `/Volumes/Work/personal/lightseerstarot/` — только 78 PNG.
Происхождение JPEG неизвестно → вопрос к владельцу в `005`.

## C · Правило `AURAD-0012` соблюдено, порядок — нет

«Живой ключ не перезаписывают; новый арт едет новыми объектами, `imageKey`
переставляется на них». Смена расширения — это и есть новые ключи, так что
кэш на устройстве (Fresco по URI) не помешает. Сломан только порядок: старые
объекты удалены **до** того, как переставили ключ. Сейчас порядок
восстанавливается сам: объекты уже отдают 200, ключ переедет деплоем.

## D · Побочное: пропорция на стороне приложения (не наша правка)

`aura-app/src/entities/tarot/config/card.ts`: «бумага» 270/176 = **1,534**,
комментарий говорит «арт выше рамки (413×712 ≈ 1,72), рисуем `cover`, режем
верх и низ». Новый арт — **1,467**, то есть **шире** рамки: `cover` теперь
срежет ~4 % по бокам, а не сверху-снизу. Имя карты внизу арта не пострадает.
Комментарий в приложении устарел, решение по рамке — за `aura-app-manor` и
дизайнером; здесь только фиксируем.

## E · Противоречий в источниках нет

Бриф и код сходятся. Уточнение к брифу: `.jpg` — не просто новое расширение,
а новый рендер арта, поэтому манифест пересчитывается целиком, а в `AURAD-0012`
нужна поправка про формат и размеры, а не только про ключи.
