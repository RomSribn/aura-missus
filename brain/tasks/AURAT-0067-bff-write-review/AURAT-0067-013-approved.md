## Чего не было и остаётся за владельцем

Живой проверки в маноре — правило слота не даёт поднимать стек, а слот
освобождается по прямому указанию. Не проверено ничем, кроме кода и прогона
маршрутов на фейковом хранилище:

1. `drop_seeded_reviews` на настоящих 42 строках и `review_writing` до неё —
   снятие `advisor_reviews_sessionId_key`, `UNIQUE (userId, advisorId)` с
   NULL-ами, `DEFAULT 'PUBLISHED'`;
2. транзакция вокруг upsert + пересчёта;
3. **отзыв → рестарт контейнера → числа на месте** (проверка исправленного
   затирания агрегатов сидом; до `daf42bd` они бы обнулились);
4. `npm run prisma:seed` дважды — отзывы не возвращаются;
5. `reviews:pending` / `publish` / `decline` на живой строке.

Если что-то из этого не сойдётся — это новая задача (или `wts-start` на
`AURAT-0067-…-1`), потому что слот освобождён и ветка удалена.
