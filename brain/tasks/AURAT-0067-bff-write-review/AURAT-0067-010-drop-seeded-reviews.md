# AURAT-0067-010 — засеянные отзывы выводятся из базы

Дата: 2026-09-08 · запрос владельца

> «можешь с базы удалить все отзывы, которые там висят? они фиктивные просто,
> имея функционал оставления отзывов, я соберу настоящие»

Причина ровно та, ради которой `source: SEED` и заводился (`AURAF-0014`,
«Достоверность»): написанные нами тексты помечены, чтобы их можно было вывести,
когда появится способ собрать настоящие. Способ появился этой задачей.

## Почему это не один `DELETE`

Сид бежит **на каждом старте контейнера** (`docker-entrypoint.sh` →
`node dist/seed.js`), поэтому:

1. вычищенные SQL-ом строки вернулись бы при ближайшем рестарте —
   `seedAdvisorReviews` upsert-ит те же 42 id;
2. **и без всякого удаления там уже есть баг**: `seedAdvisors` пишет
   `ratingTenths` / `reviewsCount` из константы **в `update`**, то есть каждый
   деплой затирает агрегаты, посчитанные по живым отзывам. Первый настоящий
   отзыв поднял бы счётчик до 5, а следующий рестарт вернул бы засеянные 4.
   Вскрылось из этого запроса; чинится тем же изменением.

## Решение владельца — 2026-09-08

**Миграцией + правкой сида.** Миграция удаляет `WHERE source = 'SEED'` (живые
строки не трогает) и пересчитывает `advisors` по тому, что осталось; из сида
уходят и отзывы, и запись агрегатов — колонки принадлежат таблице отзывов.

Названо и принято: у всех восьмерых станет ноль отзывов, поэтому приложение по
`AURAF-0014-005` перестанет рисовать секцию Reviews, звёзды и счётчик в списке,
а сегмент «Top rated» при нулях выродится в порядок по `sortOrder`.
