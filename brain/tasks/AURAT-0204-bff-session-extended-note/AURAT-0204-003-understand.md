# AURAT-0204-003 — understand

Когда клиент продлевает идущую платную сессию, на столе Chatwoot в диалоге должна
появиться приватная заметка с @упоминанием назначенного агента — как уже бывает при
брони / переносе / отмене / старте. В служебный чат Telegram продление **не** идёт.
Только BFF, всё уже за `billing_enabled`; контракты и приложение не меняются.
