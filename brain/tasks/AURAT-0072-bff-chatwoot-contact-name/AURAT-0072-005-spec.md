# AURAT-0072-005 — Спека: имя пользователя на контакте Chatwoot

Дата: 2026-09-16
Статус: **draft — ждёт решения Q1 и утверждения**
Опирается на: `001` (запрос), `004` (код и Chatwoot)

## Что увидит оператор

На контакте в Chatwoot — `displayName` из профиля, как человек его ввёл
(обрезанный, 2–64). Имя появляется при первом контакте и обновляется после
каждой смены. Почта и дата рождения на стойку не уходят.

## Как устроено

### 1. Адаптер (`modules/chatwoot/`)

- `ChatwootClient.updateContactName(contactId, name)` — `PUT /contacts/{id}`
  с JSON `{ name }`; `request` учится методу `PUT`.
- `ChatwootContactPort.setName(contactId, name)`. **404 = успех**: контакта
  нет — значит, аккаунт удалён или контакт убрали на стойке, и дописывать
  некуда. Чем-либо ещё, включая 422, джоба повторяется.

### 2. Одна джоба на имя — `contact-name` / `push`, payload `{ userId }`

`ProfileService.pushNameToDesk(userId)` читает строку **в момент выполнения**
и отправляет текущее имя. Поэтому порядок джоб не важен: две быстрые смены
имени ставят две джобы, и обе отправляют последнее. Ничего не делает, если
строки нет, если у неё нет контакта (надгробие удалённого аккаунта — сюда же)
или если имени нет. Своя очередь, а не `avatar`: у той процессор и опции про
фото. 5 попыток с backoff, как у фото.

### 3. Когда ставится

- **Контакт появился** (`ProvisioningService.ensureChatwootIdentity`, там же,
  где пуш фото). Имя сразу уходит в `createContact`, а после записи
  идентичности джоба ставится **всегда**. Это нужно, если контакт был найден
  по uid, а не создан (у найденного имя старое или пустое). И закрывает
  гонку: `PATCH` имени мог пройти, пока контакт создавался со старым снимком
  строки.
- **Имя сменилось** (`PATCH /v1/me`): если `displayName` в патче отличается
  от прежнего и у строки уже есть контакт. Контакта нет — ставить нечего: имя
  уедет при его создании.
- Отказ очереди логируется (без имени) и проглатывается: имя уже сохранено, а
  стойка — удобство оператора, не часть ответа пользователю. Так же, как с
  фото.

### 4. Удаление аккаунта (пункт 4 из `001`)

Имя не воскресает. Джоба по надгробию ничего не делает: контакта нет. Если
джоба прочла строку до удаления, её `PUT` приходит на удалённый контакт,
получает 404, а контакт `PUT` не создаёт. Финальный проход удаления
(`AURAT-0042-013`) вдобавок ищет и удаляет контакт по uid. Отдельного стирания
имени не нужно.

## Решение владельца

### Q1. Дозаливка имени на контакты, заведённые до задачи

Контакты без имени есть только в `development` (тестовые). В проде реальных
пользователей ещё нет (`AURAD-0016`).

- **A (рекомендую): команда оператора** `npm run contacts:push-names`
  (в проде `node dist/contact-names.js`). Ставит джобу `push` каждому
  пользователю с контактом, работу делает запущенный сервис. Идемпотентна,
  повторный запуск ничего не портит. Прогнать один раз на `development` после
  мёржа.
- **B: без дозаливки.** Старые тестовые контакты получат имя при следующей
  смене имени. Кода меньше, но пункт 3 из `001` закрывается словами, а не
  механизмом.

## Не делается

- Почта, дата рождения и прочие поля профиля на контакт не идут.
- Обратной синхронизации нет: имя, исправленное оператором на стойке,
  перезапишется при следующей смене имени в приложении. Источник истины —
  профиль.
- Контракты не меняются: провод приложения не трогается.

## Проверка в слоте

`lint` · `tsc --noEmit` · `jest` · `build`. Тесты:

- клиент: `PUT` JSON `{ name }` на правильный путь;
- порт: 404 → успех, 5xx/422 → бросает;
- `pushNameToDesk`: текущее имя уходит; нет строки / нет контакта / нет имени
  → ничего;
- провижининг: имя в `createContact`, джоба после записи идентичности, и для
  найденного, и для созданного контакта;
- `PATCH`: смена имени при наличии контакта → джоба; то же имя, другое поле
  или нет контакта → не ставится; отказ очереди не валит ответ и не пишет имя
  в лог;
- граф приложения поднимается (`app.module.spec`); команда дозаливки — разбор
  аргументов и граф, если Q1 = A.

## Проверка в маноре после мёржа (`bff-dev`)

1. Новый пользователь с именем пишет советнику — у контакта в Chatwoot есть
   имя.
2. `PATCH /v1/me { displayName }` — имя на контакте сменилось за секунды.
3. (Q1 = A) `contacts:push-names` — старые контакты получили имена.
4. Удаление аккаунта сразу после смены имени — контакт удалён и не появился
   снова.
5. В логах нет имён.
