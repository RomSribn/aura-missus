# AURAT-0042-106 — Решения владельца по спеке половины приложения

Дата: 2026-09-16
Пишет: `aura-app-manor` / `slave-0`
Отвечает на: `105-app-spec`, раздел «Решения владельца», и на вопросы,
возникшие после чтения утверждённой спеки BFF (`008`–`010`)

## Уже решено на стороне BFF (`009`, `010` в `slave-3`) и ложится сюда

| | Решение | В приложении |
|---|---|---|
| Q1 | Отказ `409 account_has_live_sessions` при SCHEDULED/ACTIVE | текст в листе + **Go to Sessions** |
| Q2 | Звёзды остаются, обезличенными | в листе **не** упоминается (см. ниже), только в политике |
| Q3 | Контакт у стойки удаляется через API | только в политике |
| Q4 | Остаток сгорает, проводки нет | лист называет сумму до удаления |

## Расширение объёма: юридические страницы — здесь

Владелец: «тут сделай, мне просто промпт нужен самодостаточный для claude
design». То есть в эту задачу входят, помимо экрана:

- **Правка terms и privacy.** Страницы собраны в Claude Design и выложены на
  Netlify перетаскиванием, исходника нет (`AURAT-0040-010`) — правка означает
  пересборку. Результат этой задачи — **самодостаточный бриф для Claude
  Design** с полным текстом страниц, а не патч.
- **Страница удаления аккаунта** на `aura-app.cc` — веб-путь для Play;
  исполнитель запроса — оператор через CLI `account:erase` (`008` D5).
- **Ответы для формы Data safety** — формы в консоли заполняет владелец.

Решения по объёму текста:

| # | Вопрос | Решение | Совпало с рекомендацией |
|---|---|---|---|
| 8 | Объём правки | **Всё сверить с кодом**: удаление, карта `AURAT-0040-013` и всё, что появилось после 28.08 (email, дата рождения, фото, отзывы, Play) — по свежей сверке обеих половин | да |
| 9 | Почта (MX у домена пуст) | **Cloudflare Email Routing** (DNS уже на Cloudflare): `privacy@` и `support@aura-app.cc` → ящик владельца. Настраивает владелец; публикация страниц — только после проверочного письма | да |
| 10 | Советники в тексте | **Честно про персоны** (`AURAD-0001`): советник — персона Aura, отвечают операторы-практики; статус отдельного контролёра убирается | да |

Дальше: свежая сверка сбора данных (приложение и BFF), обновление `105`,
бриф для Claude Design.
