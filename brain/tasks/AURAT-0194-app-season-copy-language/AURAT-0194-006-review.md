# AURAT-0194-006 — review (координатор)

Дата: 2026-11-07 · Ревью `005-spec.md` координатором (сессия «Локализация i18n для aura-app», бывш. `slave-1-ac`),
сверено с `develop` `3bee447`. Блокеров нет, два замечания к хранилищу:

1. **`inFlight` чистит только свой.** Сейчас `.finally(() => { inFlight = null })` безусловный: после
   `followLanguage` старый запрос, закончившись, снимет из `inFlight` новый — и `refresh()` при возврате в приложение не
   присоединится к запросу в пути. Чистить только свой (`if (inFlight === request)`, как `catalog-store`), принудительному
   запросу ставить `lastAskedAt = now` (не `-Infinity`). Тест: ответ прежнего языка пришёл раньше нового → `refresh()`
   присоединяется к новому, третьего запроса нет.
2. **(желательно) Неудачное перечитывание за языком** (сеть, не 404) — повторять при следующем возврате в приложение без
   минутного троттла, как каталог (`status === 'error'` → `load`). Флаг в store «последний запрос за языком не удался»;
   тест.
