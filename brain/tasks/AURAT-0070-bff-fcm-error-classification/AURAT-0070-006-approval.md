# AURAT-0070-006 — утверждение

Дата: 2026-09-15 · slave-2 · `feature/AURAT-0070-bff-fcm-error-classification`

**Спека `005` утверждена владельцем без правок.**

**Q1 → вариант A.** Если в попытке были только ошибки настройки (без
временных), задача в очереди завершается успешно (`completed`), сигнал —
`error` в логе. `UnrecoverableError` не используется.

Что решило выбор (разъяснено владельцу перед ответом):

- в коде никто не читает набор failed очереди: нет обработчиков `failed`,
  Bull Board, метрик. Вариант B не дал бы нового сигнала, только запись в
  Redis, видимую при ручной проверке;
- при B, пока нет ключа APNs, в failed добавлялась бы задача на каждое
  сообщение пользователю с iPhone, и настоящие временные сбои терялись бы в
  лимите `removeOnFail: 5000`;
- при B для смешанного случая (временная + настройка) понадобился бы признак,
  переживающий повторы.
