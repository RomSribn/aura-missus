# AURAT-0159-008 — fix review

Дата: 2026-11-05. Ревью диффа сессией slave-1 (по просьбе владельца): критичных и серьёзных нет, четыре правки —
внесены, в индексе, не закоммичено.

1. **Отрицательные суммы и числа по CLDR.** Генератор берёт знак и его место из `formatToParts(-1234,5)`:
   `usdNegativePrefix` / `usdNegativeSuffix` (nl «US$ -1,99», et / fi / hr / lt / sl / sv — U+2212) и `minusSign`
   для простых чисел (проверяет, что там знак стоит перед числом); U+2212 пишется escape-последовательностью.
   `formatUsdMinor` / `formatUsdMinorCompact` / `formatDecimal` их используют; «−0» не печатается. Drift-тест — с
   отрицательными в суммах, целых суммах и десятичных; тесты на en / fi / nl / sv.
2. **`BookedScreen`**: месяц в заглавных получил `accessibilityLabel` в обычном регистре.
3. **`DateStrip`**: подпись доступности сегодняшней карточки начинается с `day.today` («Today, Friday, August 14»).
4. **`formatFileSize`**: сначала округление до kB, потом выбор единицы — 999 600 байт → «1.0 MB», а не «1000 KB».

Проверка: `tsc` чисто, lint 0 / 0, Jest 175 / 1659 зелёные, `generate-formats.mjs --check` совпадает.

Ждут решения владельца (ревьюер советует принять оба): английская группировка «$1234.56» → «$1,234.56»;
отрицательные «$-1.99» → «-$1.99» (старое было неверным).

Попутно (от ревьюера): `AURAT-0158` уже в develop (`7d5f056`), слияние 0159 с ней — без конфликтов.

**Решение владельца (2026-11-05):** «Принять оба» — «$1,234.56» и «-$1.99» остаются по CLDR en.
