# AURAT-0159-003 — understand

Дата: 2026-11-05.

Владелец хочет, чтобы все деньги, даты, дни недели, месяцы, время и размеры файлов в приложении печатались по CLDR
языка интерфейса (а английская дата — по региону телефона: US-порядок для US / CA / PH, иначе en-GB), без `Intl` во
время работы: заранее сгенерированные из Node ICU таблицы + drift-тест в Jest. Все текущие потребители
(`formatUsdMinor` и три таблицы дней/месяцев) переходят на общий API в `shared/lib` с явным языком и хук
`useLanguage()`, подписи перестраиваются при смене языка. Флаг `AURA_I18N_ENABLED` выключен — релиз английский;
английский вывод меняется только там, где этого требует решение `008`.
