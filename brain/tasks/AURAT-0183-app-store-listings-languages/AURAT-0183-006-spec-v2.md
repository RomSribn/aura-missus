поддерживает — для них остаётся en-US (записано в `AURAF-0023` и в поправке к `001`).

## «Что нового» — не здесь, у `AURAT-0182`

Заметки релиза 37 / 1.1.0 на всех языках пишет `AURAT-0182` (`AURAT-0182-release-notes.md`, английский
оригинал на 396 знаков с фразой «Chats with advisors stay in the language your advisor writes in for now»).
0183 их не дублирует. Чтобы два текста совпадали:

1. **Языки заметок — 21 + en-US**, ga и mt нельзя. В Р4 спеки `0182` стоит «21 сейчас + ga / mt, если
   `AURAT-0183` успеет» — ga / mt вычеркнуть. «21 сейчас» тоже неверно: страница сейчас только на en-US. Править Р4
   должен координатор или слот 0182, в чужую папку не пишу.
2. **Порядок в консоли**: переводы страницы (0183) вставить до релиза 37 или в одном пакете с ним. Заметки на
   языке, для которого нет перевода страницы, Play может не принять — проверить в консоли, когда владелец будет
   вставлять.
3. **Одни слова**: страница и заметки берут термины из глоссария (advisor, chat, free chat, tarot, reading).
   Путь «Profile → Language» в заметках 0182 — то же название пункта, что в приложении.

## Как переводить

- Глоссарий `scripts/i18n/glossary.json` (v4) и раздел «Translations» в build-rules:
  - обращение по языку: на «ты» в de es nl sv da fi et hu ro it pl, на «вы» в bg cs el fr hr lt lv pt sk sl;
  - формы `avoid` не использовать;
  - для «reading» есть открытый вопрос глоссария к носителям (el / ro / hr / sl) — помечу.
- Не переводятся: «Aura», «Google Play», «App Store».
- Название «Aura — Psychic Reading»: «Aura —» без изменений, остальное — по терминам `psychic` / `reading`.
  Длина ≤ 30 проверяется для каждого языка.
- Типографика:
  - fr — U+00A0 перед ? ! : ; »;
  - pt — европейский;
  - ro — ș / ț;
  - el — без капса;
  - NFC, без soft hyphen.
- Где у aura-web уже есть перевод той же английской фразы, беру его. Для каждой фразы смотрю глоссарий и локали
  веба; `translate.mjs scan` работает только с `en.ts`, к странице стора его не применить.
- Длины считает разовый скрипт в scratchpad, в репо его нет. Код приложения не меняется.

## Вычитка носителем (`AURAI-0010`, решение 7)

- **legal**: 18+, «для развлечения», советники — персоны команды (Terms §05), всё о возврате и отмене.
- **payment**: цены, баланс, оплата времени, оффер — если они есть в исходнике.

Обязательна до маркетинга в стране. Публиковать страницу до вычитки можно, решает владелец.
`native-review.json` ведётся по пространствам имён `en.ts`, поэтому учёт — в таблице README.

## Шаги владельца (войдут в README)

1. Play Console → Aura → Grow users → Store presence → Store listings → Main store listing.
2. Manage translations → Add your own translations → отметить 21 язык → Apply.
3. Для каждого языка: в селекторе языка выбрать его → вставить название, краткое и полное описание из `<lang>.md` → Save.
4. Send for review (Publishing overview), вместе с релизом 37 (`0182`) или отдельно.
5. Отметить в README дату вставки. Если Play обрежет текст или отклонит его, переслать сообщение координатору.
