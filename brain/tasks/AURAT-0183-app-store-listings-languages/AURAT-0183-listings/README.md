## Как вставить (владелец)

1. Play Console → Aura → Grow users → Store presence → Store listings → Main store listing.
2. Manage translations → Add your own translations → отметить 21 язык из таблицы ниже → Apply.
3. Для каждого языка: в селекторе языка выбрать его → вставить «Название», «Краткое описание» и «Полное описание»
   из блоков `text` в `<lang>.md` → Save. Блок копировать целиком: переносы строк — часть текста.
4. Маркер списка: в исходнике — «- ». Если в консоли у en-US стоит «•», заменить на него и в переводах.
5. Send for review (Publishing overview) — до релиза 37 (`AURAT-0182`) или одним пакетом с ним.
6. Записать дату вставки ниже. Если Play что-то обрежет или отклонит, переслать текст сообщения координатору.

## Название

«Aura —» не переводится. «Psychic Reading» передано так, как на языке называют эту услугу: термины `psychic` /
`reading` из глоссария, слова веба (`match:advisor.PSYCHIC`):
- de «Hellseherische Deutung»;
- fr «Consultation de voyance»;
- pl «Jasnowidzenie i wróżby»;
- el «Διόραση» — без «ανάγνωση», это открытый вопрос глоссария.

hr «čitanje», sl «branje», ro «citire» — тоже открытый вопрос глоссария к носителям: в паре с «vidovito /
jasnovidno / psihică» читаются естественнее, чем по отдельности, но вычитать стоит.

## Перевод

- Глоссарий `scripts/i18n/glossary.json` v4: advisor, psychic, reading, tarot, tarot-card, chat, private-session,
  session, book, photo, file, notifications, review, rating, specialties. Форм `avoid` нет (проверено скриптом).
- Обращение — по `register` глоссария:
  - на «ты»: da de es et fi hu it nl pl ro sv;
  - на «вы»: bg cs el fr hr lt lv pt sk sl;
  - pl — «Twój» / «Ciebie» с заглавной.
- Типографика:
  - fr — U+00A0 перед `: ? ! ;`, апостроф ’;
  - pt — европейский: «telemóvel», «utilizadores», без «você»;
  - ro — только ș / ț;
  - es — Испания: «móvil».
- «card details» везде — платёжная карта, а не карта таро:
  - там, где слово одно и то же, — «данные оплаты» / «платёжной карты» (de «Zahlungsdaten», it «dati di pagamento»,
    sv «betaluppgifter», da «betalingsoplysninger», nl «betaalgegevens»);
  - там, где слова разные, — как есть (es tarjeta / carta, pt cartão / carta, ro card / carte).
- Бренды Aura / Google Play / App Store не переводятся.
