# AURAT-0152-005 — spec (draft)

Тип: задача (без фичи). Только `aura-app`. Веб — `AURAT-0153`.

## Что меняется

Стартовая страна на экране телефона выбирается по цепочке; берётся первый сигнал, страна которого есть в
`SMS_REGIONS` (неподдерживаемая страна пропускается — пикер её не предлагает, AURAT-0087):

1. **Часовой пояс** устройства → страна (таблица IANA-поясов только для 35 стран `SMS_REGIONS`, включая
   старые имена вроде `Europe/Kiev`; пояс с несколькими странами — по `zone.tab`: `Europe/Zurich` → CH).
2. **Регион локали** — через публичный `I18nManager.getConstants().localeIdentifier`, запасной путь —
   `Intl...resolvedOptions().locale`. (Чинит текущий баг: свойства `NativeModules` на New Architecture пусты.)
3. **Испания** — как и сейчас, если ничего не подошло.

Ручной выбор, вставка `+380…` (страна берётся из номера), проверка «не можем отправить SMS в X» — без изменений.

## Где

- `screens/phone-auth/lib/device-country.ts` — цепочка; чистые функции `countryFromTimeZone`,
  `regionOfLocale`, `pickStartCountry(candidates)` — тестируемы без натива.
- `screens/phone-auth/config/time-zone-countries.ts` (или `shared/config`, если веб-манор захочет ту же
  таблицу — у веба своя копия в своём репо) — таблица пояс → ISO2.
- Тесты: `lib/__tests__/device-country.test.ts` — пояса, старые алиасы, локали `es_ES` / `en-GB` / `uk-UA` /
  `en` без региона, неподдерживаемые страны, порядок сигналов.

## Опция (решает владелец): SIM-карта на Android

Первым звеном — `TelephonyManager.getSimCountryIso()` → `getNetworkCountryIso()`. Требует первый собственный
нативный модуль (Kotlin, ~40 строк + регистрация пакета) и нативную пересборку; на iOS ничего не даёт.
Рекомендация: **не сейчас** — пояс даёт то же самое для всех, кто физически в своей стране, на обеих платформах
и без натива.

## Проверка

Slave: `npm run lint`, `npm run typecheck`, `npm test`. Манор/устройство (владелец): A50 — сменить часовой
пояс (или выключить автопояс и выбрать Kyiv / London / New York) → экран входа стартует на UA / GB / US.

## Не входит

Веб (`AURAT-0153`); запоминание последней выбранной страны (в приложении нет KV-хранилища); IP-геолокация.
