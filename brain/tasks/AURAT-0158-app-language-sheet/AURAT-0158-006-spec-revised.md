# AURAT-0158-006 — spec revised (ревью спеки, сессия-рецензент по просьбе владельца)

Дата: 2026-11-05. Итог ревью: спека хорошая, решение 3 выполнено, порядок «латиница, затем Ελληνικά,
Български» оставить. Правки к `005-spec.md` (остальное — без изменений):

1. **Дрейф-тест таблицы имён — прямо в Jest**, без отдельного процесса: `jest.setup.js` сохраняет родной
   `Intl.DisplayNames` перед удалением (`global.__NODE_DISPLAY_NAMES__`, как `__NODE_PLURAL_RULES__`), тест
   сверяет таблицу с ним. `jest.setup.js` может править и `AURAT-0159` — одна строка рядом с PluralRules.
2. **Пространство — `app-language`** (по слайсу через дефис, как на вебе `me-page`, `auth-by-phone`).
3. **Строка профиля**: значение справа — `numberOfLines={1}`, подпись не сжимается; у строки
   `accessibilityValue={{ text: <самоназвание> }}` — диктор читает «Language, Deutsch».
4. **Список** — `accessibilityRole="radiogroup"` с подписью заголовком листа.
5. **`I18N_ENABLED || __DEV__`** — с однострочным комментарием о причине (`env.ts` просит не ветвиться по
   `__DEV__`; здесь это инструмент разработчика, до запуска строку видит только dev).

Подзаголовок — к владельцу, три варианта: убрать; вместо него строка о том, что не переводится (решение
владельца 5: анкеты, приветствия и сообщения консультантов в v1 английские — выбравший Deutsch иначе примет
английскую анкету за ошибку), одна строка во всех 24 языках; оставить как на макете.
