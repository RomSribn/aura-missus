## Что сделано

`shared/ui/bottom-sheet/BottomSheet.tsx`:
- **Удалено:**
  - пресет `gestureY` / `pullFrom` на BEGAN;
  - пружина `pullFrom` и флаг `springing`;
  - `settle` / `onRelease`;
  - перезапуск `follow` на END.
- **Открытие:**
  - сбрасывает все флаги, в том числе `settling`, `travel`, `restingDrag`, `listToTop`;
  - взводит `pullFrom = 0` у scrollable;
  - заново вешает свои listener'ы (035 §1): `gestureY` → `travel` — только Android; `drag` → `restingDrag`.
- **`follow`:** параметр `sticky = !onList`; `placePull` только при `at !== pullFromAt`.
- **`onListScroll`:**
  - в простое: взвод 0 или парковка, по положению списка;
  - в касании: только парковка, и только для касаний на списке без старта;
  - при `settling` событие флаг на Android снимает, на iOS — нет (035 §8), `listY` и `pullFrom` не трогает.
- **BEGAN:**
  - у всех листов сбрасывается hold-check;
  - у scrollable — `drag.stopAnimation()` без флага и снятие `settling`.
- **`onListRelease` (любой конец касания):**
  - shownStart / travel (iOS — `lastMove`) / shownPull;
  - `decisionStart` — только на END, чистым вызовом;
  - `ownPull`; предикат `pulling` (035 §5);
  - `closes` по `restingDrag + ownPull` при `ownPull > 0` (035 §2);
  - фолд в порядке 034 §3.4, `restingDrag += shownPull` (035 §3);
  - при `pulling` — `toTop`, `settling`, `listY = 0`;
  - затем `release`.
- **`release`:**
  - при `!visible` — ничего, лист уходит с места;
  - иначе закрытие с hold-check или пружина `drag → 0` без колбэка.

`BottomSheetLists.tsx`:
- `onListTouch(toTop)` — `toTop` хранится в ref касания (035 заметка);
- `onListTouchEnd`: на `onTouchEnd` / `onTouchCancel` списка, если касание листа уже закончилось, снимает `onList` —
  START тапа, пришедший после `onFinish` (034 §2, способ выбран здесь);
- `onListGone` при размонтировании — снимает `settling`;
- свои `onTouchEnd` / `onTouchCancel` consumer'а по-прежнему вызываются.

`drag.ts`: `listPullStart(…, sticky)` → `start ?? 0`.

`features/app-language/ui/LanguageSheet.tsx` (035 §9): `onLayout` — на строке над выбранной, прокрутка к её `y`.

Код:

- **LanguageSheet.** Прокрутка к выбранной строке — один раз за открытие: перелэйаут не сбрасывает прокрутку.
- **JSDoc `scrollable`:** проп читается при открытии и за время открытия не меняется.
