# AURAT-0158-029 — fix: ревью 028 — сброс в `onListScroll` срабатывает после закрывающего свайпа

Дата: 2026-11-05. Рецензент (по просьбе владельца): подхват у верха теперь верный; пока не мёржить.

1. **Блокирует, регрессия.** Ветка закрытия в `onRelease` уходит без `settle` — `pullFromAt` остаётся стартом
   тяги (0 у любой тяги с верха и за грип). После `onFinish` любое событие прокрутки с y > 0 (катящийся после
   флика список; scroll из очереди Fabric, пришедший после END) проходит условие сброса → `pullFrom` паркуется →
   лист прыгает вверх на всю тягу перед закрытием. То же режет пружину и окно hold-check. Правка: сбрасывать только
   при живом касании и без пружины (`panActive && !springing`). Тесты: грип при прокрученном списке → закрывающий
   свайп → scroll 320 — лист не прыгнул; с верха → закрывающий свайп → scroll 4 — то же.
2. Hold-check: `settle` отложен на `HOLD_CHECK_MS`, `springing` ещё false — BEGAN в эти 120 мс сделал бы пресет;
   добавить `holdCheck === null` в условие пресета (сейчас латентно).
3. Тесты на события после отпускания: тяга во время пружины — `follow` перехватывает; Android: END(60, 1500) при
   маппинге уже на 60 без JS-движения — закрывает без прыжка.
4. **Известные остаточные прыжки на Android** (не регрессия, без кода; замер после мёржа): быстрый флик сразу после
   открытия при занятом JS (пресет доходит до UI-потока позже первых движений); грип / заголовок / поиск при
   прокрученном списке (пресета нет — `onList` на BEGAN неизвестен); подхват во время пружины возврата (снап домой,
   затем догон).
