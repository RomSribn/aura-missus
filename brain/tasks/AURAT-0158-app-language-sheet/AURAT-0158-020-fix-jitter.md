# AURAT-0158-020 — fix: список дёргается, пока тянут лист

Дата: 2026-11-05. Проверка на A50 (develop `248c7db`, legacy-API; передано рецензентом по просьбе владельца):
падений нет (logcat чистый), лист закрывается свайпом от верха списка, но список во время тяги дрожит.

Причина: сдвиг scrollable-листа считается на JS (`drag.setValue`) и отстаёт от пальца на кадр+; список работает
одновременно с жестом листа — в его координатах палец «уезжает вверх», он прокручивается на несколько pt и обратно.

Правка (предложение рецензента):
1. Тяга scrollable-листа — на UI-потоке: `Animated.event` (native, форма v2) пишет `translationY` в `gestureY`,
   сдвиг = `max(0, gestureY − pullFrom)`; JS (`listener`) только переставляет `pullFrom` при передаче / возврате.
   Возврат пружиной — с текущего положения, без скачка. Грип тоже снова на UI-потоке (п. 5 ревью `014`).
2. Страховка: пока лист тянут, список прижат к 0 (`scrollTo({ y: 0, animated: false })` в `onScroll` при y > 0);
   не `scrollEnabled={false}` — на iOS он отменяет прокрутку до конца касания.
3. Тесты: native-событие с `listener`, запись `pullFrom`, прижатие списка, пружина без скачка.
