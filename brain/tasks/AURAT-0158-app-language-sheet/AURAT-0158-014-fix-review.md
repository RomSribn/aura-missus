# AURAT-0158-014 — fix: ревью диффа 013 (сессия-рецензент по просьбе владельца)

Дата: 2026-11-05. Итог ревью: API v3 использован правильно (проверено по JS и нативу RNGH 3.0.1); одно серьёзное.

1. **Серьёзное.** `listY` / `onList` переживают закрытие листа: лист смонтирован постоянно (`ProfileScreen`,
   `PhoneAuthScreen`), список при новом открытии на 0 scroll-событий не шлёт (iOS `scrollToOffset` на тот же offset
   выходит сразу; Android — только при сдвиге) → свайп по списку не двигает ни список, ни лист. Правка: список
   сообщает 0 при размонтировании (эффект с пустыми зависимостями); открытие сбрасывает `listY`, `onList`,
   `pullStart`, `lastTranslationY`; тест «прокрутить → закрыть → открыть → свайп закрывает».
2. `testID` жеста — только в `__DEV__` (в релизе RNGH ругается на каждую отправку конфига); ключа не должно быть.
3. Конфиг `usePanGesture` новый на каждом рендере → лишние `setGestureHandlerConfig` и перерисовки контекста:
   колбэки через ref, конфиг в `useMemo`. В тестах — `afterEach` с размонтированием.
4. Тесты движения: маппинг `Animated.event` (`handlerData.translationY`, `dispatchesAnimatedEvents`), JS-путь у
   scrollable, сдвиг листа после передачи (90 − 40 = 50), связь `simultaneousHandlers` дошла до нативного жеста
   списка — и для `BottomSheetFlatList`.
5. Scrollable-листы тянутся с JS-потока, грип тоже — осознанный размен ради `listY`; принять, проверить на слабом
   Android в маноре; позже — Reanimated, не блокирует.
6. Фильтр `simultaneousHandlers` в `JSON.stringify` тестов — остаток Legacy-версии, v3 его в пропы хоста не кладёт:
   убрать; фраза в `013` неверна.
7. `drag.setValue(0)` на каждом update обрывает пружину `settle` — не писать 0 повторно.
8. `scroll.tsx` → PascalCase (`BottomSheetLists.tsx`).
