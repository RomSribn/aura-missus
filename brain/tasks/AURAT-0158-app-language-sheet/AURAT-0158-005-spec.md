# AURAT-0158-005 — spec (draft)

Тип: задача фичи `AURAF-0023` (строка 002), шаг 2. Только `aura-app`. Основание — `AURAI-0010` §8, решение
владельца 3; контекст — `004-context.md`. Флаг `AURA_I18N_ENABLED` не трогаю: в релизе строки нет, в dev видна.

## 1. Новый слайс `features/app-language`

Как остальные листы профиля (promo-code, account-deletion): фича владеет листом, его состоянием и подписью своей
строки в меню (как `PROMO_CODES_LABEL`, `DELETE_ACCOUNT_LABEL`), экран держит `activeSheet`.

- **Таблица имён** `config/language-names.ts` — генерируется `scripts/i18n/generate-language-names.mjs` из Node
  ICU, как `countries.ts` (в Hermes нет `Intl.DisplayNames`): самоназвание каждого языка и 24×24 «имя языка X на
  языке Y», первая буква заглавная по правилам языка — те же строки, что рисует веб. Дрейф-тест сверяет файл с
  Node (отдельным процессом: Jest убирает `DisplayNames`, как Hermes).
- **Порядок** — фиксированный массив: «Язык устройства», English, затем 23 по самоназванию: латиница по алфавиту
  (Čeština, Dansk, Deutsch, Eesti, Español, Français, Gaeilge, Hrvatski, Italiano, Latviešu, Lietuvių, Magyar,
  Malti, Nederlands, Polski, Português, Română, Slovenčina, Slovenščina, Suomi, Svenska), затем Ελληνικά,
  Български. Тест: массив = все `LANGUAGES` ровно по разу.
- **Строки** — пространство `appLanguage`, 24 языка: `row` «Language» (веб, = глоссарий), `title` «Choose
  language», `device` «Device language» (глоссарий), `choose` «Choose» (форма кнопки языка, `@max 20`); ✕ —
  `shared:close`. Линтер `i18next/no-literal-string` = `error` на слайс.
- **Модель** `model/use-language-sheet.ts`:
  - при открытии черновик = текущий выбор: `'device'`, если язык на экране = языку системы, иначе этот язык
    (`chooseLanguage` и так стирает выбор, совпавший с системой — «следую за устройством» и «выбран системный»
    на телефоне одно и то же);
  - тап по строке меняет только черновик; ✕, скрим, свайп — закрыть без изменений;
  - «Choose» закрывает лист, `chooseLanguage(черновик)` — в `onClosed`, когда модал реально ушёл (иначе
    уходящий лист перерисовывается на новом языке и мигает); черновик = текущему → ничего не делаем;
  - навигация не перезапускается: экраны перерисовывает `useTranslation`.
- **Лист** `ui/LanguageSheet.tsx` по макету 15: заголовок + ✕, радиосписок, коралловый круг с галочкой,
  «Choose».
  - Строка: самоназвание (body 600, 16) и под ним подсказка — имя на языке интерфейса (13, ink2); подсказки нет,
    где она равна самоназванию (строка языка интерфейса). «Device language» — подсказка: самоназвание языка
    системы («Deutsch»).
  - Список ≈ 58% высоты экрана, индикатор прокрутки виден (Android `persistentScrollbar`, iOS —
    `flashScrollIndicators` при открытии), при открытии прокручен к выбранной строке; `dragFromGrip`.
  - Доступность: `accessibilityRole="radio"` + `accessibilityState={{ checked }}`, у самоназвания —
    `accessibilityLanguage` (iOS читает «Ελληνικά» греческим голосом). Строки — `React.memo`.
  - Без поиска.
- **shared** — две строки экспорта в `@/shared`: `I18N_ENABLED` и `systemLanguage` (уже есть в
  `lib/i18n/detect-language.ts`). Файлы `AURAT-0159` не трогаю; `index.ts` правят обе задачи в разных местах —
  конфликт слияния, если будет, тривиальный.

## 2. Профиль

- `ProfileMenuRow` получает `id` (ключ строки вместо подписи) и необязательное `value` — серым справа перед
  шевроном, как на макете 14.
- Строка `language` (globe, `#C9B6E4`) на месте из макета — после «Coupons & Promo Codes»: Promo · Language ·
  Terms · Privacy. Подпись — `appLanguage:row`, значение — самоназвание языка на экране; оба обновляются при
  смене языка.
- Фильтр `use-profile.ts:66-69` заменяю пометкой строки: promo — `wallet` (как сейчас, только при живом
  биллинге), language — видна при `I18N_ENABLED || __DEV__`.
- `ProfileSheetKey` += `'language'`. Остальные строки профиля остаются английскими до его задачи шага 3.
