# AURAT-0158-030 — execute (правки ревью 029)

Дата: 2026-11-05. Не закоммичено — ждёт одобрения владельца.

1. `onListScroll` сбрасывает пресет только при живом касании и без пружины (`panActive && !springing && y > 0 &&
   pullStart === null && pullFromAt === 0`) — закрывающийся лист больше не прыгает вверх от поздних / катящихся
   событий прокрутки. Событие прокрутки после END по-прежнему покрыто: `settle(null)` на END паркует пресет.
2. Пресет на BEGAN — ещё и при `holdCheck === null` (не во время ожидания решения хоста).
3. Тесты (`after the let-go`): закрытие за грип при прокрученном списке → scroll 320 — лист на месте; закрытие с
   верха → scroll 4 — на месте; тяга во время пружины перехватывает её (30 → +30, затем домой); касание в окне
   hold-check ничего не пишет. Android-файл: флик, END(60, 1500) при маппинге уже на 60 без JS-движения — закрывает,
   лист на +60, без прыжка. Мутационная проверка: условие сброса как в 028 → 2 теста падают; без `holdCheck` в
   пресете → 1.
4. **Известные остаточные прыжки на Android** (не регрессия, замер после мёржа): быстрый флик сразу после открытия
   при занятом JS; грип / заголовок / поиск при прокрученном списке (без пресета); подхват во время пружины
   возврата (снап домой, затем догон).
