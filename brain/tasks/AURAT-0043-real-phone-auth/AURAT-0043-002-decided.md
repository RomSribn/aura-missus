# AURAT-0043-002 — Три вопроса закрыты владельцем

Дата: 2026-08-28
Отвечает на: `AURAT-0043-001`, раздел «Три вопроса, которые надо решить до кода»

## Q1 — страны: **всё, где продаёт Play**

Пикер получает **полный список стран**, а не короткий перечень рынков.

Следствие для кода, и оно определяющее: список из ~150 стран с их правилами
длины **нельзя вести руками** — это таблица, которая устаревает молча, а
симптом устаревания «мой номер не принимают» неотличим от всех остальных стен
из `-001`. Поэтому валидация и форматирование берутся из **`libphonenumber-js`**
(чистый JS, нативной части нет — значит `pod install` не нужен и правило слейва
не нарушается). Оттуда же приходят и коды стран: `getCountries()` +
`getCountryCallingCode()`.

Единственное, что остаётся статикой в репозитории, — **названия стран на
английском**. `Intl.DisplayNames` в Hermes есть не везде и ведёт себя по-разному
на двух платформах, а список стран, который на одном телефоне читается словами,
а на другом кодами, — это тот же класс дефекта, что `formatClockTime` в
`shared/lib/format.ts` уже обходит вручную по той же причине.

Следствие для владельца: пункт 1 из таблицы действий (`-001`) становится
**снятием** `allowlistOnly`, а не расширением списка.

## Q2 — bundle id: **переименовать в `cc.silvermind.aura`**

Совпадает с Android после `AURAT-0026`. Тянет за собой цепочку, и порядок в ней
обязателен:

1. `PRODUCT_BUNDLE_IDENTIFIER` в обеих конфигурациях `project.pbxproj`;
2. **новое** iOS-приложение в Firebase под `cc.silvermind.aura` (старое под
   шаблонным id остаётся, пока не будет удалено осознанно);
3. новый `GoogleService-Info.plist`;
4. новая схема возврата в `Info.plist` — она выводится из `GOOGLE_APP_ID`, то
   есть меняется вместе с ним, и **если её не поменять, reCAPTCHA-возврат
   сломается ровно так же, как он сломан сейчас**;
5. App ID у Apple и ключ APNs — только после 1–4.

## Q3 — Android: **включить Play Integrity**

`playintegrity.googleapis.com` включается, приложение связывается в Play
Console. Отпечатки (5 SHA-1 + 5 SHA-256) уже зарегистрированы — эта половина
была готова.

## Что из этого может сделать slave, а что нет

Три действия в живых проектах вызываются через API тем же токеном, которым
велась разведка (`gcloud`, аккаунт владельца): снять `allowlistOnly`, включить
Play Integrity, зарегистрировать iOS-приложение. **Это записи в боевой проект**,
и они делаются только по отдельному подтверждению владельца в момент
исполнения — разведка была чтением, это уже не оно.

Загрузка ключа APNs через API невозможна: нужен аккаунт Apple Developer.
Связывание приложения в Play Console — тоже руками.
