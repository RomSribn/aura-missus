# AURAT-0140-001 — initial (заглушка)

Дата: 2026-10-25
Репо: `aura-bff-manor` (BFF) + `aura-contracts`. Выдан из `aura-app-manor` slave-0, `AURAT-0139`.

## Что нужно

Решение владельца (`AURAT-0139-009`, §4b): промо-пуши из Firebase Console уходят только на
topic `promo`, а подписка на него идёт за **отдельным согласием на промо-пуши**, по умолчанию
**выкл.** Существующее `marketingOptIn` — согласие на email, его не трогаем.

- Контракты: новое булево поле профиля (рабочее имя `pushOffersOptIn`), по умолчанию `false`, в
  ответе профиля и в теле его обновления.
- BFF: колонка (миграция, `false` у всех существующих), чтение и запись через профиль; время
  изменения согласия хранить (запись о согласии для GDPR).
- После релиза контрактов приложение (`AURAT-0139`, часть 4) поднимет версию `@aura/contracts`.

Не запущена.
