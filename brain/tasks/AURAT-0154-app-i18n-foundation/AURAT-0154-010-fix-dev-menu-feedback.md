# AURAT-0154-010 — fix: меню разработчика молчит

2026-11-04. Владелец на A50: «после нажатия на i18n: next language или pseudo ничего не происходит».

Проверка через adb (`uiautomator dump`): язык переключается. В псевдоязыке подпись подложки листа Top Up стала
`[Çļöšé~~]`. Но на главной, в профиле, советниках и сессиях нет ни одной видимой строки `shared/ui`: купон —
только для аккаунта с неиспользованным офером, билет — только при включённом сезоне, таймер — только на входе.
Сам пункт меню ничего не сообщает.

Решение владельца — «Добавить тост»:

- dev-сборки: после пункта меню — сообщение «i18n → de» / «i18n → pseudo» (Android — `ToastAndroid`, iOS —
  `Alert`), при ошибке — «i18n: failed»;
- меню выносится в `app/i18n/dev-menu.ts` с тестом;
- чтобы тест прошёл путь приложения, `jest.setup.js` стартует i18n через `startI18n(…, { strict })`, а не
  `initI18n`: иначе `chooseLanguage` ждёт старта, которого в тестах не было.
