# AURAT-0154-004 — context

Основной источник — `AURAI-0010` (8 расследований + критик, 2026-11-04; решения владельца там же). Код
сверен в слоте (`develop` @ `28633b4`).

## Что важно для этой задачи

- Hermes V1: в Intl только `Collator`, `DateTimeFormat`, `NumberFormat`, `getCanonicalLocales`. Без шима
  `PluralRules` i18next 26 молча ставит английские one/other. Шим на `make-plural` 8.1.0 — 0 ошибок из 55 560
  (`AURAI-0010` §1, прототип `AURAI-0010-plural-shim-prototype.js`). Metro не вычищает неиспользуемый код →
  24 функции генерировать в файл, а не импортировать `make-plural/plurals` целиком.
- Загрузчики `import()` в RN бесполезны и ломают Jest 29 → синхронный `require`. Ловушка: импорт файла языка
  по умолчанию или как namespace выполняет все языки при старте (+2 МБ кучи).
- Сейчас на iOS язык из Intl всегда `en` (бандл объявляет только en). Значит, определение заработает только с
  нативными объявлениями в задаче запуска; до неё флаг держит `en`, и вреда нет.
- Флаги в приложении — конфигурация сборки (`env/resolve.js` → babel-плагин → `shared/config/env.ts`),
  `__DEV__` для окружения не используется (`env.ts`). Новый флаг — по тому же пути.
- Файлы: `@dr.pogodin/react-native-fs` уже есть. `config-cache.ts` пишет атомарно (во временный файл, затем
  перенос), но в Caches; выбор языка — в Documents (кэш ОС может очистить).
- `index.js` регистрирует headless-обработчики пушей до приложения → старт i18n должен работать вне React.
- `jest.setup.js` — CommonJS, глобальные фейковые таймеры. i18next 26 с `resources` / `initAsync:false`
  стартует синхронно, без `setTimeout`. 64 из 159 тестов сравнивают английский текст — английский не менять.
- ESLint: сейчас 0 ошибок и предупреждений. Запрет глубоких импортов → реестру пространств нужно исключение.
- `<Trans>` в RN: `transSupportBasicHtmlNodes: false`, `defaultTransParent: Text`.
- Жёсткое правило 5 build rules: экспорт без потребителя не мёржится. Поэтому в основу входит первый реальный
  потребитель — `shared/ui` (≈ 24 строки: BottomSheet, DobField, купоны и билеты, ResendTimer, StarPicker с
  плюралом, подпись PriceTag), а форматтеры, общие фразы, названия языков и стран переезжают вместе со своими
  потребителями (следующие задачи).
- Переводы `shared/ui` во многом совпадают с пространством `shared` веба (купон: «Auto-applied»,
  «Welcome offer», «Tap to apply», «CODE»/«SALE») — брать оттуда; регистр — как на вебе.
- Версии (npm, ≥ 2 недель): i18next 26.5.3 (2026-10-19), react-i18next 17.1.0 (2026-10-17), make-plural 8.1.0
  (2025-12-29), eslint-plugin-i18next 6.1.5 (2026-06-28) — те же, что у веба.

## Противоречия

- Build rules называют стек Redux Toolkit + RTK Query; в коде их нет (модульные хранилища +
  `useSyncExternalStore`). На задачу не влияет: язык живёт в i18next.
- В `package.json` нет скрипта `typecheck`, хотя build rules его упоминают. Проверка — `npx tsc --noEmit`.
