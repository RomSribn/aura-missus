# AURAT-0086-009 — fix: фильтр по Advisor без выбора

Дата: 2026-10-12. Проверка владельцем на dev (после `desk:setup`: метка создана,
9 definitions, 12 синков): **всё работает**, кроме одного — в фильтре по «Advisor» нет
опций, только текстовое поле, в отличие от остальных добавленных фильтров.

Причина: `advisor_name` заведён типом `text`; выпадающий список Chatwoot строит только
для `list` с `attribute_values` (как у `advisor_category`, `aura_session_status`).

Фикс: `advisor_name` → `list`, значения — имена **всех** адвайзоров каталога (включая
снятых: у их старых диалогов имя остаётся), в порядке `sortOrder`. Список собирает
`desk:setup` из таблицы `advisors`; при существующем `text`-definition команда
выровняет его (`updated`). Новый адвайзор в каталоге → перезапуск `desk:setup`, как и
для смены имени/цены (README).
