# AURAT-0083-013 — investigate: виджет в левом меню Chatwoot (2026-10-12)

Вопрос владельца: можно ли поставить виджет на уровень левого меню.

## Ответ: настройками — нет

- Dashboard Apps в 4.15.1 рендерятся **только** во вкладках диалога: единственный
  потребитель стора `dashboardApps` — `ConversationBox.vue` (grep по
  `app/javascript/dashboard`; остальное — API, стор, страница настроек).
- Левое меню (`components-next/sidebar/Sidebar.vue`) — жёстко заданный список
  разделов (Inbox, Conversations, Captain, Contacts, Companies, Reports, …) из
  роутов приложения; внешних ссылок/пользовательских пунктов нет, глобального
  конфига для них в `installation_config.yml` нет.
- Документация описывает Dashboard Apps только как вкладку в окне диалога; в
  поиске не нашлось ни штатной настройки, ни feature request на пункт в сайдбаре.

## Что возможно в обход (не рекомендую)

- **`DASHBOARD_SCRIPTS` дорисовывает пункт в сайдбар** (DOM-вставка ссылки/панели
  с iframe). Работает без патча исходников, но привязано к разметке Vue-
  компонента: любое обновление Chatwoot может сломать молча. Плюс SPA
  перерисовывает сайдбар — нужен MutationObserver.
- **Патч исходников Chatwoot** — запрещено условиями задачи.

## Смысловое ограничение

Вне диалога у виджета нет `appContext`: нет клиента и адвайзора. Уровень меню
подходит для другого экрана — общий календарь адвайзоров / «мои брони смены», —
то есть для того, что владелец отложил до флоу смен чаттеров. Для v1
(«брони и баланс текущего клиента») вкладка диалога — правильное место.

Ждёт решения владельца; код не менялся.
