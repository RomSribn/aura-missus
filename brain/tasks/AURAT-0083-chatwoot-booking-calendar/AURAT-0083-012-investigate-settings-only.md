# AURAT-0083-012 — investigate: можно ли без скриптов, одними настройками (2026-10-12)

Вопрос владельца: нет ли в Chatwoot способа добавить виджет второй вкладкой в
диалоге просто настройками, без скриптов.

## Ответ: вкладка — да, вход агента — нет

**Вкладка в диалоге — штатная настройка.** Settings → Integrations → Dashboard
Apps → Configure → «Add a new dashboard app»: имя + URL → в каждом диалоге
аккаунта появляется вкладка с этим именем рядом с «Messages».
- Документация: chatwoot.com/docs/product/others/dashboard-apps,
  chatwoot.com/docs/user-guide/applications.
- Исходник 4.15.1: роут `settings_integrations_dashboard_apps`
  (`integrations.routes.js:30-36`, `permissions: ['administrator']`, флаг
  `INTEGRATIONS`), API `POST /api/v1/accounts/:id/dashboard_apps`
  (`DashboardAppsController#create`, владелец = текущий пользователь).
- Настраивается **по аккаунту** (в аккаунте 1 и в аккаунте 2 отдельно) —
  глобальной настройки нет, это подтверждено ещё в `008`.
- → `deploy/chatwoot/register-agent-desk-app.rb` **не обязателен**: он делает
  ровно то же, что форма в UI. Его можно заменить инструкцией «добавить в UI».

**`DASHBOARD_SCRIPTS` нужен не для вкладки, а для входа (решение A).**
Документация и код дают iframe только `appContext` (`conversation`, `contact`,
`currentAgent{id,name,email}`) через `postMessage(..., '*')` — без подписи,
без токена; документация про аутентификацию агента ничего не говорит.
`meta.hmac_verified` в диалоге — это проверка личности *контакта* в
веб-виджете сайта, к агенту отношения не имеет.

Значит, «одними настройками» доступны только варианты, которые уже отвергались:
- доверять `currentAgent` из `appContext` — его может прислать любая страница,
  встроившая наш URL (`frame-ancestors` это ограничивает, но запросы к API
  можно слать и без iframe) → данные клиентов открыты любому, кто знает номер
  диалога;
- отдельный логин в виджете (бэкофис-стиль) — владелец отказался в `005` (A).

## Вывод

- Вкладку можно и нужно добавлять через UI — скрипт регистрации лишний.
- `DASHBOARD_SCRIPTS` остаётся единственным способом без отдельного логина
  проверяемо узнать агента; это тоже «настройка», но инсталляционная и на
  community-редакции задаётся только через `rails runner`.

Предложение владельцу: убрать `register-agent-desk-app.rb`, в README/AURAS-0004
описать добавление вкладки через UI. Ждёт решения.
