# AURAT-0083-022 — спека дополнения: «Занятость адвайзора» карточками по дням

Status: **draft — ждёт одобрения владельца**. Дата: 2026-10-12.
Решения владельца по `021`: **1a** — только адвайзор текущего диалога;
**2a** — имя и фото других клиентов показываем (Chatwoot их и так показывает),
нет фото → инициалы. Это меняет решение `009` «чужая бронь — только «занято»».

## Что видит чаттер

Блок «Занятость адвайзора» вместо полос по дням — **карточки броней по дням**
(дни в поясе браузера), горизонт прежний (14 дней), дни без броней не
выводятся; нет ни одной — «Броней на 14 дней нет». Карточка:

`16:06–16:11 · [фото|инициалы] Имя клиента [Trial] › [фото] Имя адвайзора · статус`

- **Время** — начало–конец брони.
- **Клиент** — `displayName`; нет имени → «Без имени». Фото — если у человека
  есть фото профиля, иначе кружок с инициалами (из имени; нет имени — «?»).
  Сессия удалённого аккаунта — «Удалённый аккаунт», без фото и ссылки.
- **Trial** — первая сессия, оплаченная кредитом $5 (`creditMinor > 0`).
- **Адвайзор** — фото и имя из каталога (одинаковые во всех карточках — так на
  референсе, оставляем ради единообразия с будущим экраном смен).
- **Статус** — «запланирована» / «идёт».
- Брони **текущего клиента** выделены.
- **Клик по карточке** открывает диалог этого клиента в Chatwoot
  (`<a target="_top">` на `/app/accounts/:account/conversations/:id`; аккаунт —
  из `appContext`). Проверяется в манор.

## BFF

- `advisor-calendar`: `busy[]` → `bookings[]` —
  `{from, to, status, trial, thisClient, chatwootConversationId | null,
  client: {name | null, avatarId | null} | null}`; у `advisor` + `avatarUrl`.
  Сумм денег по-прежнему нет.
- `SessionsRepository.listAdvisorBookings` — джойн conversation → user
  (`displayName`, `avatarId`), `status`, `creditMinor`,
  `chatwootConversationId`.
- **Фото клиента:** `GET /agent-desk/api/avatars/:avatarId` под сессией виджета
  — отдаёт только **текущее** фото какого-то пользователя (иначе 404),
  `cache-control: private`. Новый метод `AvatarService` «открыть по id для
  стола» (без проверки владельца — её заменяет сессия агента). `<img>` не
  шлёт Bearer → страница берёт байты `fetch`-ом и показывает через `blob:`.
- **CSP страницы:** `img-src 'self' blob: <origin ADVISOR_ASSETS_BASE_URL>`.
- В логах — ни имён, ни id фото.

## Клиент (`client/desk.ts`)

Рендер карточек вместо полос, инициалы, загрузка фото с кэшем `blob:` на
время жизни страницы (одно фото — один запрос), ссылка на диалог.

## Тесты

Репозиторий (форма джойна — через сервис-тесты), сервис (маппинг, удалённый
аккаунт, trial, thisClient), маршрут фото (чужой/старый id → 404, без сессии →
401), CSP в smoke, jsdom: карточки по дням, инициалы, фото через blob, ссылка,
пустой горизонт. Lint, typecheck, build.

## Вне объёма

Сводное расписание всех адвайзоров и «моя смена» — ждут флоу смен.
