# AURAT-0083-021 — investigate: «Занятость адвайзора» карточками по дням (2026-10-12)

Владелец: AURAT-0085 смёржен, бронь вторым пользователем прошла. Просит
посмотреть возможность показать занятость по дням списком карточек (как на
референсе): промежуток времени, аватар + имя клиента, аватар + имя адвайзора
(на референсе ещё бейдж «Trial» и статус справа).

## Данные — всё есть в BFF

| Поле карточки | Источник |
|---|---|
| время `HH:MM–HH:MM` | `sessions.startsAt/endsAt` (уже отдаём) |
| имя клиента | `users.displayName` через `conversation.userId` (может быть пустым → «Клиент» / последние цифры не показываем) |
| фото клиента | `users.avatarId/avatarKey` — **приватный** бакет (AURAD-0013); читается только `GET /v1/avatars/:id` под Firebase |
| имя/аватар адвайзора | `advisors.name/avatarKey` — **публичный** бакет `ADVISOR_ASSETS_BASE_URL` |
| «Trial» | `sessions.creditMinor > 0` (первая сессия с кредитом $5) |
| статус | `SCHEDULED/ACTIVE` (в календаре только живые) |
| переход в диалог клиента | `conversations.chatwootConversationId` → ссылка на диалог Chatwoot |

## Что меняется

- **Приватность (решение 009 меняется).** Сейчас чужая бронь — только «занято».
  Карточки с именем/фото другого клиента — это показ чужих данных. Для чаттеров
  нового в этом мало (все диалоги аккаунта им и так видны в Chatwoot, имя мы
  сами пишем на контакт — AURAT-0072), но это решение владельца.
- **Охват.** Во вкладке диалога адвайзор один → колонка адвайзора одинакова во
  всех карточках. Референс — сводное расписание **всех** адвайзоров; это ближе
  к отложенному экрану смен («моя смена»), но технически не зависит от смен.
- **Фото клиента.** `<img>` не умеет слать Bearer → нужен маршрут
  `/agent-desk/api/avatars/:id` под сессией виджета + `fetch` → `blob:` URL,
  CSP `img-src 'self' blob:`. Дешёвая альтернатива — кружок с инициалами (как
  на референсе у клиентов без фото).
- **Фото адвайзора.** CSP `img-src` + origin `ADVISOR_ASSETS_BASE_URL`.
- **Переход в диалог.** Клик по карточке → `window.top` на
  `/app/accounts/:id/conversations/:cwId` (кросс-ориджин навигация top из
  iframe без sandbox — по жесту пользователя разрешена; проверить в манор).

## Оценка

BFF: расширить `listAdvisorBookings` (джойн conversation→user, `creditMinor`,
`chatwootConversationId`), при «всех адвайзорах» — новый метод без фильтра;
DTO; маршрут аватаров (если фото). Клиент: рендер карточек по дням вместо
полос. Тесты на всех слоях. ~0.5–1 дня; без фото клиента — меньше.

Ждёт решений владельца (охват; имена/фото чужих клиентов).
