# AURAT-0083-025 — execute: сессии клиента теми же карточками (2026-10-12)

Владелец посмотрел превью (`024`) и попросил: строки в «Предстоящих» и
«Прошедших» сессиях клиента сделать такими же карточками, как в «Занятости
адвайзора».

## Сделано (не закоммичено, застейджено)

- `agent-desk.dto.ts` — `DeskClient {name, avatarId}`; в `overview` поле
  `client`; у `DeskClientSession` — `trial`; `DeskBooking.client` строится на
  `DeskClient`.
- `agent-desk.service.ts` — клиент диалога через `UsersService.findById`
  (параллельно с остальными чтениями), `trial = creditMinor > 0`;
  `agent-desk.module.ts` импортирует `AuthModule`.
- `client/desk.ts` — общий `SessionCard` + `renderDays` + `renderCard` для
  всех трёх списков: карточки по локальным дням, время, клиент (фото/инициалы,
  Trial), адвайзор (аватар), статус (с причиной завершения у прошедших).
  Выделены сессии с адвайзором этого диалога; ссылка — только у них и ведёт в
  этот диалог (номеров диалогов клиента с другими адвайзорами у страницы нет).
  Фото клиента — через текущий диалог, один запрос на всю страницу.
  `assets/desk.js` пересобран; из `desk.css` удалены стили старых строк.
- Тесты: сервис (клиент, trial), smoke, jsdom (+2: сессии клиента карточками
  по дням и ссылки; одно фото клиента на обе секции). Селекторы прежних
  проверок календаря ограничены его секцией.

## Проверки

typecheck (сервер + клиент), eslint, jest 111 / 1421, `nest build` — зелёные.
Превью (scratchpad, headless Chrome) переснято в светлой и тёмной теме.
