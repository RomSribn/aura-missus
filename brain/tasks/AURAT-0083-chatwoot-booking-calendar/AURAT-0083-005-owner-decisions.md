# AURAT-0083-005 — решения владельца по развилкам (2026-10-12)

Спека **не пишется**: владелец поставил виджет на паузу.

- **A — авторизация:** скрипт через `DASHBOARD_SCRIPTS` (инсталляционная настройка
  Chatwoot) передаёт в iframe токен сессии агента; BFF проверяет его у Chatwoot
  (`/api/v1/profile`) и выдаёт свою короткую сессию. Без отдельных логинов.
- **C — клик по окну:** в первой версии **только просмотр** (занятость + брони
  клиента); предлагать сессию чаттер продолжает токеном `::SESSION::`. Бронь за
  клиента не делаем — AURAD-0002 / AURAF-0013 не трогаем.
- **E — заметка за 5 минут:** упоминание assignee диалога; если никто не назначен —
  упоминание команды адвайзора (нужна настройка advisor → team id).
- **D — фронтенд:** из BFF, отдельный префикс с `frame-ancestors` только для
  `chat.aura-app.cc` (не оспорено).
- **B — расписание:** O1 остаётся. Слова владельца: «в дальнейшем будет расписание
  именно чаттеров; расписание адвайзоров — отдельное, актуальное, его не трогаем.
  Я бы пока не делал эту задачу, т.к. нужно продумать флоу того, как будут работать
  чаттеры посменно».

## Статус
