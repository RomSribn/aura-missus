## Проверено без токена

| Проверка | Ответ |
|---|---|
| `GET /health` | 200 |
| `GET /v1/definitely-not-a-route` | 404 |
| `GET /v1/me` | 401 |
| `PUT /v1/me/avatar` | **401** |
| `DELETE /v1/me/avatar` | **401** |
| `GET /v1/avatars/:id` | **401** |

401 против 404 — признак того, что маршрут зарегистрирован: гард в Nest
отрабатывает после роутинга, поэтому неизвестный путь возвращает 404 раньше
любой аутентификации. Контрольная строка в таблице ровно за этим и стоит.
