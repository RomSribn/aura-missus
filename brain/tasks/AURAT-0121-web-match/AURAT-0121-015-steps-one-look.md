# AURAT-0121-015 — Шаги: один вид на странице и в шторке

Date: 2026-10-23
Вместо мёржа владелец (скрины: шаги `/match` с линиями, в шторке — без):

> почему разные компонента на странице и в модалке? Добавь полосочки как на странице, так красивее

## Почему было разное

Компонент один (`BookingSteps`); в шторке — вариант `compact` без соединительных линий и с переносом
по правке владельца 4 к `009` (опасение за ширину 592 px в длинных языках).

## Сделано

- Вариант `compact` удалён: шаги одинаковые на `/match` и в шторке Book, с линиями.
- Ширина: линия — `flex: 0 1 28px`, `min-width: 10px`; шаг может сжиматься (`min-width: 0`), подпись
  без `nowrap` — при нехватке места сначала короче линии (до 10 px), потом подпись уходит на вторую
  строку; ничего не обрезается. По оценке, fr и lt в 592 px помещаются с укороченными линиями.

## Проверки

`npm run lint` — без замечаний; `npm run typecheck` — чисто; `TZ=America/New_York npm test` — 81
файл, 1428 тестов, зелёные; `npm run build` — собран.

## Проверка в маноре

lt и fr в шторке Book с `/match` при 761 px: линии видны (короче), подписи не обрезаны (из `010`).
