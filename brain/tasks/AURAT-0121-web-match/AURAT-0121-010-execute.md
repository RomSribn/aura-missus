# AURAT-0121-010 — Execute: шаги воронки (009, вариант А)

Date: 2026-10-23
Решение владельца по `009`: **вариант А** с правками 1–7 и тестами сверх 009. Ветка та же
(`feature/AURAT-0121-web-match`), мёрж части 1 ещё не делался.

## Сделано

- **`BookingSteps`** — `features/book-session/ui/booking-steps.tsx` (правка 6): пройденный шаг —
  путь назад (если он есть), текущий — `aria-current="step"`, будущие приглушены и не кликаются.
  Имя пройденного шага для скринридера — «{label}, done». `compact` — для шторки: без
  соединительных линий, `flex-wrap`, текст не обрезается (`white-space: nowrap` на шаге, перенос —
  между шагами) (правка 4). Только desktop (`only-desktop`). Шаги — `BOOKING_STEPS` в
  `config/booking.ts`; строки `book-session:steps.*` перенесены из `match-page` (24 языка).
- **Шаг 3 / 4** — `useBookSession().step`: `book`, пока не выбрано время (или «Now»), затем `pay`.
- **Признак воронки** — `bookSheetParams().funnel` (параметр диалога `funnel`); `useOpenBookSheet`
  принимает его необязательным, `/match` открывает шторку с `funnel: true`.
- **Шторка Book** (`widgets/book-sheet`): шаги — первым блоком под шапкой, × остаётся первым
  фокусируемым (правка 3). «✓ Choose advisor» — кнопка, закрывает шторку (назад к `/match`).
  «✓ Your question» — `<a href="/#ask">`, клик без модификаторов перехватывается и уходит через
  `onLeave` — запись шторки заменяется Home, один Back возвращает на `/match` (правка 1). Пока
  `pay.phase !== 'idle'`, оба пройденных шага — простой текст (правка 2). «✓ Book», когда текущий
  — Pay, не кликается (правка 5). При `booking.status === 'off'` шагов нет.
- **`/match`**: `BookingSteps at="choose"` — «✓ Your question» → `/#ask`; `FunnelSteps` и его
  конфиг удалены. Биллинг `off` (правка 7): у карточек нет Book session, шагов нет совсем; пока
  цены грузятся и при `unknown` Book виден.

## Тесты (сверх части 1)

- `booking.test` — блок «from /match: the funnel’s steps»: фокус на × и шаги под шапкой; Book →
  Pay при выборе слота, «✓ Book» не кликается; «Choose advisor» закрывает шторку на `/match`;
  «Your question» → Home с вопросом в поле, один Back → `/match`; во время оплаты (ответ брони
  висит) пройденные шаги неактивны, шторка и `/match` на месте; Booked — без шагов; шторка из
  профиля — без шагов.
- `book-now.test` — с `/match` «Now» переводит шаг с Book на Pay (`aria-current` переезжает).
- `home.test` — `/match`: шаги, «Your question» → `/#ask`, текущий — Choose advisor, кнопок в шагах
  нет, ссылка одна; биллинг off → нет Book session и нет шагов.
- jsdom считает имя «Your question , done» (пробел перед скрытой частью) — в тестах регулярка.

  набор зелёный. Кандидат в отдельную правку тестов (фиксированное время), вне задачи.
