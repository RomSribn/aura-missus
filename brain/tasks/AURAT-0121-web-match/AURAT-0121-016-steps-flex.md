# AURAT-0121-016 — Шаги: на странице не сжимаются, в шторке уступают место

Date: 2026-10-23
Вместо мёржа владелец (скрины: на `/match` «Choose advisor» в две строки и короткие линии; в шторке
перенос подписи при ещё длинной первой линии):

> сделай флексибл карточки с крошками с помощью стилей, чтобы на десктопе выглядело примерно как в
> прошлый раз, чтобы тайтлы не врапились, а в модалке пусть врапятся если места нет

## Причина

После `015` все шаги сжимались одинаково (`flex-shrink` пропорционально ширине): самый длинный шаг
«Choose advisor» терял больше всех и переносился раньше, чем укорачивались линии; на `/match` строка
шагов к тому же сжималась рядом с «← Home».

## Сделано

- По умолчанию (страница): строка шагов не сжимается (`flex: none`), подписи в одну строку
  (`nowrap`), линии — 28 px, как до `015`. Верхняя строка `/match` (← Home + шаги) при нехватке места
  переносит шаги под «← Home» (`flex-wrap`), а не сжимает их.
- `tight` (шторка Book): шаги могут сжиматься; линии уступают первыми (`flex-shrink: 999`, до 10 px),
  и только потом подпись уходит на вторую строку. Ничего не обрезается.

## Проверки

`npm run lint` — без замечаний; `npm run typecheck` — чисто; `TZ=America/New_York npm test` — 81
файл, 1428 тестов, зелёные; `npm run build` — собран. Вид — глазами в маноре: `/match` при 761–1440 px
(подписи в строку), шторка в en / fr / lt.
