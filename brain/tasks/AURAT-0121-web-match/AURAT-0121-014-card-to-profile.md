# AURAT-0121-014 — Карточка снова ведёт в профиль (уже «в воронке»), бронь — кнопкой

Date: 2026-10-23
Вместо мёржа (вопрос после `013`) владелец:

> тогда в целом, можно вернуть переход на профиль адвайзора по клику на карточку, убрать строчку
> about и переход на book будет по кнопке book

Решение `011` («вся карточка — бронь») заменено: профиль с `?from=match` больше не выпускает из
воронки (нет Free chat, ← к подбору, бронь со шагами — `013`), поэтому карточка — снова ссылка на него.

## Сделано

- `MatchCard`: имя — ссылка на `/advisors/:id?from=match`, её область растянута на карточку
  (`.link::after`), подвал с Book session — над ней (`position: relative; z-index: 1`), бейдж
  Best match не перехватывает нажатие. `onClick` на `article` и `eslint-disable` убраны.
- «About →» и строки `match-page:about` / `aboutLabel` (24 языка) удалены; страж WCAG 2.5.3 — снова
  только Book session.
- Биллинг off — карточка ведёт на обычный профиль (бронировать нечего).

## Тесты

`home.test`: клик по карточке (имени) → `/advisors/ivy?from=match`, шторки нет, «Back to your
matches», нет Free chat; у Mia ссылка `?from=match`; биллинг off — ссылка без `from` после ответа
pricing. Остальное из `013` — без изменений.
