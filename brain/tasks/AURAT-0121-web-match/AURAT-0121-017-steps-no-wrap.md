# AURAT-0121-017 — В шторке подписи шагов не переносятся

Date: 2026-10-23
Вместо мёржа владелец (скрин шторки: «Choose advisor» в две строки, справа свободно):

> в модалке choose advisor врапится, смотрится не красиво, оно не должно врапится, ибо место есть
> для контейнера

## Причина (проверено в headless Chrome на копии стилей)

Линия была `::before` шага с `flex: 0 999 28px; width: auto`: в естественную ширину шага браузер
считал её как 10 px, а не 28 — шаг получал ширину меньше нужной, линия сжималась до 10 px, а подпись
переносилась при свободном месте справа (en: 146 px свободно). После первой правки (ширина 28 px)
en стал в строку, но в fr / lt переносилась подпись первого шага: у него нет линии, сжиматься нечему,
и любая доля пикселя сжатия переносит текст.

## Сделано

- Линии — отдельные элементы ряда (`<li aria-hidden>` между шагами), не `::before`.
- Страница: как в `016` — линии 28 px, подписи в строку, ряд не сжимается.
- Шторка (`tight`): подписи никогда не переносятся; линии занимают оставшееся место — от 10 до 28 px
  (`flex: 1 0 10px; max-width: 28px`); если не хватает и при 10 px — целый шаг уходит во вторую
  строку (`flex-wrap`), ничего не обрезается.

## Проба (headless Chrome, системный шрифт вместо Hanken Grotesk, контент шторки 592 px)

Все 24 языка — один ряд, подписи в строку; линии: 28 px у большинства, fr 25, lv 26, bg 19, lt 16.
Шторка 520 px (lt) — шаг уходит во вторую строку, без обрезки. Страница lt при 700 px — 28 px, в строку.

## Проверки

`npm run lint` — без замечаний; `npm run typecheck` — чисто; `TZ=America/New_York npm test` — 81
файл, 1428 тестов, зелёные (в одном прогоне старый тест «a short balance…» упал по таймауту 5 с под
нагрузкой; отдельно — 2 из 2 зелёные, повторный полный прогон — зелёный); `npm run build` — собран.

## Проверка в маноре

Шторка с `/match` в en / bg / lt — один ряд, подписи в строку (шрифт Hanken Grotesk может сдвинуть
ширины на несколько процентов; запас у lt — 6 px на линию).
