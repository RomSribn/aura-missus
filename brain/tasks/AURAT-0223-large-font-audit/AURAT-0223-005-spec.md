# AURAT-0223-005 — spec: крупный шрифт, узкий экран и длинные языки по всем экранам

Status: draft — ждёт одобрения владельца.
Тип: task (вёрстка), отдельной фичи не нужно. Follow-up `AURAT-0222` (решение 3).
Слот: aura-app-manor slave-2, ветка `feature/AURAT-0223-large-font-audit`.

## Итог аудита (подробно — `004-context.md`, скриншоты — `AURAT-0223-before-NN-*.jpg`)

Проверено на Android 12 (emulator-5554):
- 360 dp при ×1.3 и ×2.0 (de), 384 dp при ×2.0 (de);
- el и fi при ×1.3.

Найдено 17 групп проблем.

**P0 — действие недоступно:**
- **вход** — при ×2.0 кнопки «Code senden» нет, экран не прокручивается (п. 1);
- **удаление аккаунта** — кнопки шторки за экраном (п. 2);
- **оплата пополнения** — кнопка срезана (п. 3);
- ещё 7 шторок устроены так же: старт / продление и отмена платной сессии, быстрая бронь, промокод, фото,
  дата рождения, вложения (п. 3a).

**P1 — читать нельзя:**
- слова рвутся посреди буквы: заголовки, ряды профиля, прошедшие сессии;
- профиль советника при ×2.0: имя срезано, пилюля закрывает цену, футер «Buch/en»; на el — уже при ×1.3;
- ссылки и заголовки уезжают за правый край — уже при ×1.3;
- баннер «Tägliches Ritual» режет подзаголовок при ×1.3;
- шапка чата: при ×1.3 кнопка «Jetzt buchen» в 2 строки отъедает место у имени;
- онбординг при ×2.0 прячет текст под кнопки.

**P2 / P3:** футеры растут без предела, поля фиксированной высоты режут подсказку, допустимые усечения в списках.

**В порядке:** CountBadge (таб-бар и строка чата) при ×1.0 / ×1.3 / ×2.0, подпись StatsCard, сама бронь после 0222.

**Оговорка.** На Android 14+ крупный кегль растёт нелинейно. Заголовки при ×2.0 на 5554 примерно на треть крупнее,
чем у клиента. Проблемы ×1.3 и структурные (нет прокрутки, фиксированная высота) от этого не зависят. ×2.0 «после»
перепроверю на API 36.

## Принцип (из 0222) и что предлагаю к нему добавить

Контент растёт полностью, хром — не больше ×1.3 (`theme.fontScale.chrome`). Сейчас в хроме: футер брони, промо-тикеты,
цена рядом с именем, бейджи. Предлагаю (решение 1):
- **подписи всех кнопок** ≤ ×1.3 — у `Button` это значение по умолчанию (`maxFontScale` есть с 0222). Сразу лечит
  футеры профиля советника, отзыва, Daily card, Edit profile, кнопки шторок, «Bewerten» в сессиях;
- **шапки**: «назад + заголовок» и шапка чата (имя, статус, «Jetzt buchen»);
- **ссылки в заголовках секций** («Alle ansehen», «Bewertung schreiben»), **пилюли** (статус советника), **баннер**
  «Tägliches Ritual»;
- **шапка профиля советника** (имя, роль, пилюля) — сворачиваемый заголовок, по сути хром.

**Display-заголовки (28–34 sp) ≤ ×1.3** (решение 2). Android 14 сам растит такой кегль примерно в 1,45 раза при ×2.0;
заголовок и без того крупный, а на ×2.0 он съедает пол-экрана и режет слова.

**Переносы с дефисом на Android** (решение 3): в общем `Text` — `android_hyphenationFrequency`, чтобы немецкие и
финские сложные слова («Telefonnummer», «Nutzungsbedingungen», «Pentaakkelien») переносились по слогам с дефисом, а не
рвались на случайной букве. Как это ведёт себя на Android 12 / 13+ и с нашими шрифтами, проверю первым шагом
(шаблоны переносов берутся из языка системы или приложения). Если на Android 12 переносы выходят плохими —
запасной путь: уменьшать кегль заголовка, пока самое длинное слово не влезет в ширину. iOS сейчас только на
английском (`AURAT-0190`) и в задачу не входит.

## Разбиение (решение 4)

Объём большой: ~25 компонентов и 9 шторок. Предлагаю три части по очереди. Части 2 и 3 опираются на общие
компоненты из части 1, поэтому параллельно с ней будут конфликты в `shared`.

### Часть 1 — AURAT-0223 (этот слот): P0 + общие рычаги

1. **Вход** (п. 1). Контент в ScrollView. Кнопка «Code senden» закреплена внизу над клавиатурой и видна всегда.
   Согласие 18+ со ссылками — в прокрутке, его можно дочитать. Номер в поле не режется: высота поля растёт.
2. **Шторки** (п. 2–3a). `BottomSheet` получает слот `footer`: кнопки закреплены внизу, тело прокручивается, если не
   помещается (высота ≤ окно минус отступ сверху). Перевожу все 9 шторок без прокрутки. Шторка удаления — первая,
   она нужна для стора.
3. **Онбординг** (п. 4). Слайд — колонка: иллюстрация сжимается, заголовок и текст целиком, низ (точки и кнопки)
   больше не наезжает. Если всё равно не влезает — слайд прокручивается по вертикали. «Überspringen» — в строке
   сверху, без фиксированной высоты, ≤ ×1.3.
4. **Кнопки ≤ ×1.3 по умолчанию** (решение 1). `Button.maxFontScale = theme.fontScale.chrome`, если не передано
   другое.
5. **Display-заголовки ≤ ×1.3 + переносы** (решения 2–3). `ScreenTitle`, заголовки онбординга и шторок, заголовки
   вкладок («Sitzungen», «Profil»). Переносы — в общем `Text`.

Ожидаемый эффект: P0 закрыты; почти все разрывы слов и раздутые футеры уходят по всему приложению.

### Часть 2 — новый ID: экраны (P1)

- **Профиль советника** (п. 6). Геометрия шапки считается с учётом шрифта, а не константами. Пилюля — одна строка,
  не шире экрана. Цена в StatsCard — `PriceTag.maxFontScale`. Свёрнутая шапка не режет имя.
- **Вкладка «Профиль»** (п. 7):
  - при крупном шрифте «Bearbeiten» уходит под имя;
  - телефон не рвётся посреди номера (неразрывные пробелы в отображении);
  - «Aufladen» переходит под сумму, если не помещается;
  - в меню значение («Deutsch») сокращается раньше подписи.
- **Прошедшие сессии** (п. 8). При крупном шрифте кнопка уходит под имя. «9. Nov.» и «1 Min.» не разрываются внутри.
- **Ссылки в заголовках секций** (п. 9). Если не помещаются рядом с заголовком, переходят на строку ниже.
- **Общая шапка «назад + заголовок»** в `shared/ui` (п. 10). Заменяет 6 копий (hard rule 3). Заголовок сжимается,
  до 2 строк, ≤ ×1.3.
- **Чат** (п. 11). Шапка: имя приоритетнее кнопки, «Jetzt buchen» в одну строку ≤ ×1.3. Поле ввода — `minHeight`
  и рост по строкам вместо фиксированной высоты.
- **Баннер «Tägliches Ritual»** (п. 12) — `minHeight` вместо `height: 148`, тексты ≤ ×1.3.
- **Отзыв** (п. 13). Звёзды на первом экране при ×2.0 — должно получиться само после частей 1 и 2; проверю.

### Часть 3 — новый ID: полировка и непроверенное

- Поля фиксированной высоты (п. 15): поиск советников, промокод.
- Усечения в списках (п. 16): страна в 2 строки, роль советника.
- Хвосты 0222 (п. 17): бейдж DurationPicker, пустое состояние SlotGrid.
- Живой аудит того, что требует брони: SessionDetail, Reschedule, BookReview / Booked, карточка «Anstehend»,
  платная сессия в чате, CancelSession. Плюс CreateAccount и HoroscopeCard. Для брони — решение 5.

## Строки

Новых и изменённых строк не жду: это вёрстка и ограничения. Если понадобится строка (например, подпись иконки
вместо текста), она будет во всех 24 языках, с `@max`.

## Проверка (для каждой части)

- tsc, lint (`--max-warnings 0`), jest — зелёные. Новые тесты:
  - кнопки по умолчанию ≤ ×1.3;
  - `footer` и прокрутка шторки;
  - на входе кнопка вне прокрутки;
  - перенос в `Text`;
  - логика переключения раскладок (чистые хелперы в `lib/`).
- Эмулятор «после», та же матрица (360 / 384 dp, ×1.3 / ×2.0, de / el / fi). Плюс ×1.0 en — вид не должен меняться.
- ×2.0 для заголовков — на API 36 (5556, когда свободен, или отдельный AVD).
- После проверок эмулятор возвращается в исходное состояние, как в этот раз.
