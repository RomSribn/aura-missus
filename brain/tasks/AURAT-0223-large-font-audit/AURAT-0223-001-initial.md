  SlotGrid пустое состояние — заголовок слева, текст по центру. Не проверено: CountBadge (таб-бар и строка
  чата) и подпись StatsCard на ×2 (их задел обход lineHeight в shared Text из 0222).
- Переиспользовать: `theme.fontScale.chrome = 1.3`, `Button.maxFontScale`, `PriceTag.maxFontScale`,
  `ticketType` в `shared/ui/offer`, обход межстрочного интервала на Android в shared Text.
  Принцип владельца: контент растёт полностью, хром (футеры, промо-тикеты, цена рядом с именем, бейджи) —
  не больше ×1.3.
- Эмулятор разрешён (как в 0222), но делится со Studytube: перед сменой font_scale / density / size —
  topResumedActivity и `adb reverse --list`; занятый Studytube не трогать; после проверки всё вернуть.
