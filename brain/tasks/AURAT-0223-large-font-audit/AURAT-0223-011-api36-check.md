## Результат по списку манора

**Межстрочный интервал крупных заголовков при шрифте выше ×1.3.** Найдено и исправлено.
- **Что было.** На Android 14+ крупный кегль растёт нелинейно (`FontScaleConverter`): 34 sp при ×2.0 = 41,5 dp,
  предел ×1.3 = 44,2 dp, то есть предел не срабатывает. А обход 0222 в `Text` всё равно снимал фиксированный
  интервал. Многострочные заголовки («Gib deine Telefonnummer ein», «Sprich mit begabten Beratern») выходили на ~6%
  свободнее, чем на HEAD: шаг 49,7 dp против 46,9 dp. Это находка F3 из ревью, подтверждена на устройстве.
- **Правка (`shared/ui/Text.tsx`).** На Android API ≥ 34 текст от `typography.displayFrom` (28 sp) сохраняет
  фиксированный интервал. Кегль и интервал там пересчитываются одинаково нелинейно, а предел при ×1.3–×2.0 почти не
  срабатывает. Мелкий текст с пределом (подписи кнопок и т. п.) на API 34+ по-прежнему снимает интервал: там рост
  почти линейный. На API < 34 и на iOS ничего не изменилось.
- **Проверка.** После правки шаг строк заголовков на API 36 при ×2.0 совпадает с HEAD строка в строку (`after-17`).
  Тесты: «display type keeps its fixed line height» и «smaller capped type still drops it» на API 34+.
  Тест 0222/0223 на API 33 зафиксирован явно.

**Немецкие переносы по языку приложения работают:**
- при ×2.0 на 360 dp — «Nutzungsbedin-gungen», «Datenschutzer-klärung»;
- на 384 dp — «Datenschutzerklä-rung» (`after-16`, `after-19`).

На Android 13+ шаблоны переносов берутся из языка приложения. На Android 12 (5554) — из системного, поэтому там
слова рвались без дефиса.

**Вход.** На 360 и 384 dp «Code senden» закреплена над клавиатурой; страна над полем, номер целиком; экран кода в
порядке. На HEAD при ×2.0 кнопка «Code senden» уходит под панель навигации, а номер обрезан — P0 на API 36 тоже
воспроизводится (`after-17`).

**Шторки удаления и пополнения.** Кнопки видны, на 360 dp тело прокручивается.

**Профиль советника, чат.** Всё в порядке. В чате на 360 и 384 dp аватар скрыт (решение владельца), имя
«Gifted Veronica» помещается целиком на 384 dp, «Jetzt buchen» — в одну строку. Поле ввода растёт.

**Подтверждение брони.** Ряды фактов столбиком, цены, согласие в закреплённом футере ≤ ×1.3 — в порядке.
- **Найдено новое.** Баланс тестового аккаунта стал 0 $, рядом с «Aura-Guthaben» появилась ссылка «Aufladen» и
  сжала подпись до «Aura-Guthab/en». Это класс пункта 7 аудита.
- **Правка (`features/store-topup`):**
  - `TopUpLink` ≤ ×1.3 (ссылка рядом с подписью = хром, решение 1);
  - в `PayWith` с крупным шрифтом ссылка стоит под подписью, с отступом под текст. Отступ — из констант ряда
    `ROW_PAD` / `ICON_SIZE` / `ICON_GAP`, они же в стилях.
- **Проверка.** После правки «Aura-Guthaben» целиком, «Aufladen» под ним (`after-19`). Тесты в `checkout-ui.test`:
  при ×1.0 рядом, при ×1.3 под подписью и ≤ ×1.3.

**×1.0 en, 411 dp — вид не изменился.** HEAD против ветки, 11 экранов, повторено после всех правок (`after-20`):
- отзыв, сессии, чат — без единого пикселя разницы;
- остальное — сдвиги на 1 физический пиксель (~0,4 dp): заголовки секций, «Top Up»;
- одно отличие намеренное: на экране брони имя советника больше не бледнеет сверху — постоянное затухание сняли
  по пункту 1 ревью манора.
