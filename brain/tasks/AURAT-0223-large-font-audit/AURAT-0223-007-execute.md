## Общие примитивы (shared)

- **Тема:**
  - `fontScale.display = 1.3`;
  - `fontScale.largeFrom = 1.25` — с какого шрифта ряды «имя + действие» складываются в столбик;
  - `typography.displayFrom = 28`;
  - `typography.headingFrom = 20`.
- **`Text`:**
  - текст ≥ 28 sp растёт не больше ×1.3, если вызывающий не задал свой предел (`0` — без предела);
  - текст ≥ 20 sp получает `android_hyphenationFrequency="normal"`; основной текст переносов не получает
    (условие манора);
  - обход межстрочного интервала из 0222 работает и для автоматического предела.
- **`Button`:**
  - подпись ≤ `fontScale.chrome` по умолчанию;
  - однословная подпись может переноситься с дефисом.
  - Подгонку размера (`adjustsFontSizeToFit`) пробовал и убрал. На устройстве Android подгоняет подпись и по высоте
    рамки, и «Review» в прошедших сессиях выходила меньше уже при ×1.0. Вариант «подгонять только после переноса»
    (`onTextLayout`) тоже срабатывал на промежуточном замере.
- **`Pill`:** подпись ≤ ×1.3; `sm` — одна строка с подгонкой, не шире родителя.
- **`OffChip`:** ≤ ×1.3.
- **`BottomSheet`:**
  - слот `footer` — действия закреплены под телом;
  - тело обычной шторки — `LegacyScrollView`, прокрутка и `waitFor` у жеста включаются только при переполнении
    (`body-fit.ts`);
  - вынос по бокам и снизу сохраняет тени карточек;
  - `keyboardShouldPersistTaps="always"` — как было без прокрутки;
  - замеры сбрасываются, когда шторка ушла, а не при открытии: шторка, открытая снова до конца закрытия, иначе
    теряла прокрутку.
- **`useScrollFade`** (новый, `shared/lib/scroll-fade.ts`). RN 0.85 рисует `fadingEdgeLength` с постоянной силой,
  прокручено или нет. Поэтому верх затухает, только когда прокручено вниз, а низ — только когда ниже ещё есть
  контент. Без этого при ×1.0 у шторок, входа и онбординга бледнели первые и последние строки.
- **Новые компоненты `shared/ui`:**
  - `StackHeader` (назад + заголовок; `compact` / `large`; 2 строки, ≤ ×1.3);
  - `SectionHeader` (заголовок + ссылка **или** заметка — тип-объединение; ссылка переносится под заголовок,
    ссылка и заметка ≤ ×1.3).
- **`shared/lib`:**
  - `useLargeText`;
  - `noBreakSpaces`;
  - `phoneDisplayLabel` — номер рвётся только после кода страны;
  - `wrappingPlaceholder` — Android `multiline`, подсказка поля переносится, а не режется;
  - у `FormField` опция `wrapPlaceholder`.

## Компромиссы и открытые вопросы (к ревью)

     срабатывает, а фиксированный интервал снимается) — косметика;
   - немецкие переносы по языку приложения.

   На Android 12 при ×2.0 «Datenschutzer/klärung» рвётся без дефиса: шаблоны английские. В стоковом Android 12 ×2.0
   нет, предел — ×1.3.

   - BookReview / Booked;

7. Вне задачи, найдено попутно:
