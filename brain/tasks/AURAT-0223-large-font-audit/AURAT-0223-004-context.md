# AURAT-0223-004 — context: аудит крупного шрифта, узкого экрана и длинных языков

2026-11-20, slave-2, ветка `feature/AURAT-0223-large-font-audit` (develop `6491581`, код не менялся).

## Как снимал

- **Эмулятор** — emulator-5554 (Xiaomi_Mi10T_Pro_API31, Android 12, 1080×2400). Оба эмулятора были заняты
  Studytube; 5554 владелец разрешил взять («Взять emulator-5554»). Aura там не было: debug-сборку 1.2.1 скопировал
  с 5556 (только `adb pull`; нативный код после неё не менялся — проверил `git log` по `android/` и `package.json`).
  Вошёл тестовым номером Firebase (`+34 611 111 111`, код из `admin/v2 …/config`; прочитано GET-запросом, ничего не меняли).
- **Metro** — из слота на :8090, `AURA_ENV=staging AURA_BILLING_ENABLED=true AURA_STORE_BILLING_ENABLED=true
  AURA_I18N_ENABLED=true`. `@aura/contracts` в слоте — 0.35.0, как в lock-файле.
- **Язык** — Android 12 не умеет `set-app-locales`, поэтому писал `files/aura-language.json` через `run-as`.
- **Матрица:**
  - 360 dp (density 480) — de при ×1.3 и ×2.0, все доступные экраны;
  - 384 dp (density 450, размер клиента из 0222) — de при ×2.0, критичные экраны;
  - el и fi при 360 dp ×1.3 — экраны с плотными рядами.
- **Возвращено:** density / size reset, `font_scale` удалён (был не задан), `aura-language.json` удалён, наш
  `adb reverse tcp:8090` снят (Studytube-овский 4200 не трогал), Studytube снова на переднем плане, Metro остановлен.
- **Временная правка** (`unread || 12` в `ChatListRow`, `|| 7` в `AuraTabBar`) — только чтобы показать CountBadge.
  Откачена, `git status` чистый.

**Оговорка про ×2.0.** На 5554 Android 12, и шрифт там растёт линейно. На Android 14+ крупный кегль растёт
нелинейно: RN 0.85 считает sp через `TypedValue.applyDimension`, а там на API 34+ работает `fontScaleConverter`.
Поэтому заголовки 28–34 sp на 5554 при ×2.0 примерно на треть крупнее, чем на телефоне с Android 14+. Текст
14–17 sp растёт почти одинаково. В стоковом Android ×2.0 появилось только в 14-й версии, до 13-й предел — ×1.3.
Отсюда:
- находки ×1.3 реальны для всех;
- находки ×2.0, которые зависят от размера заголовков, — худший случай; перепроверить на API 36 (5556 или
  отдельный AVD);
- находки ×2.0 о структуре (нет прокрутки, фиксированная высота) от этого не зависят.
