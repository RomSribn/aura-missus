# AURAT-0223-003 — understand

Пройти все экраны приложения на Android при крупном шрифте (×1.3, ×2.0), на узких экранах (360 / ~384 dp)
и в длинных языках (de + el / nl / fi / hu), собрать список поломок со скриншотами «до» и приоритетами,
предложить правки по принципу «контент растёт, хром ≤ ×1.3» и разбиение, если объём большой. Код — только
после одобрения спеки владельцем.
