# AURAT-0102-003 — understand

Владелец запускает этап 1 веб-клиента (`AURAD-0019`). BFF должен стать доступен
браузеру с веб-доменов: CORS по allowlist из env, проверка `Origin` на `/ws`, и
гостевое (без входа) чтение всего, что нужно каталогу и профилю советника —
список, профиль, отзывы, слоты, цена — без персональных полей. Решить, нужны ли
серверные фильтры каталога. Мобильное приложение ведёт себя как раньше;
`@aura/contracts` — только добавления. Ops (Firebase-домены, reCAPTCHA / App Check)
— пунктом владельцу, не кодом.
