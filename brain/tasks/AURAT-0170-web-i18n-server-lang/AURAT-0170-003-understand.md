# AURAT-0170-003 — understand

Дата: 2026-11-06

Владелец: сделать в вебе клиентскую часть «серверного шага 5» и затем таро. Конкретно:
1. Веб сообщает BFF язык интерфейса (`?lang=`) в JSON-запросах и загрузках — не в картинках/вложениях и не в сокете.
2. Оператор может выключить язык (`disabledLanguages` из `/v1/app-config`) — веб переходит на английский и не предлагает выключенный язык.
3. Системные строки чата (маркеры сессии) и заглушки у `spread` / `sessionInvite` веб рисует своими переведёнными словами, а не английским `content`.
4. Таро: имена карт будут приходить переведёнными (BFF `AURAT-0171`) — фразы с именем карты переписать так, чтобы имя стояло отдельно (падежи), и перезапрашивать карту дня / историю при смене языка. Надписи на самих картинках карт не трогаем (решение владельца).

Контракт v0.28.0 заморожен, но тега нет: до тега — локальный тип по спеке, переключение на тег — отдельным коммитом.
