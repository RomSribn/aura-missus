# AURAT-0196-006 — approval

Дата: 2026-11-07. **Одобрено** — спека `005` без правок (v2 не нужна), через координатора (сессия «Локализация i18n
для aura-app»). Замечаний координатора нет.

Владелец, дословно, на вопрос координатора «5 решений, исполнитель и я за А. Язык пишется до отправки в Chatwoot (не
теряется при повторе); «перевод включён» в ответе = переключатель И согласие текущей версии; колонки chatConsent*; язык
клиента в карточке Chatwoot — английским названием из списка (German); локаль агентов не трогаем. В работу?»:
«Все А, в работу (Recommended)».

- Решение 1 — А: язык пишется после `ensureConversation`, до поста в Chatwoot.
- Решение 2 — А: `chat.translationEnabled` = переключатель **и** согласие версии `CHAT_CONSENT_VERSION`.
- Решение 3 — А: колонки `chatConsentVersion` / `chatConsentGivenAt`.
- Решение 4 — А: `client_language` — английское название, тип `list`; `LANGUAGE_NAMES` → `common/language`.
- Решение 5 — А: локаль агентов кодом не трогаем.
- **Решение 6** (новое). Вопрос: «Когда люди должны увидеть галочку согласия чата (чувствительные данные в чате +
  ИИ-перевод Anthropic)? Сервер включает её полем chat в профиле.» Ответ владельца: «Сразу после 0196 (Recommended)».
  Значит, `ProfileResponse.chat` отдаётся сразу, без отдельного выключателя — как в спеке.
