# AURAT-0196-003 — understand

Дата: 2026-11-07

Сервер начинает хранить настройки чата человека по контракту v0.31.0 (`AURAT-0195-005` §4): язык чата (пишет только
отправка сообщения с её `?lang`), переключатель перевода и явное согласие (версия + время сервера). Отдаёт их в
`ProfileResponse.chat` на всех маршрутах профиля, принимает `PATCH /v1/me/chat-settings` (`409 chat_consent_required`),
показывает язык чаттеру атрибутом контакта `client_language`. Ничего не переводит: это модель данных и правила, на
которых задача 5 (конвейер) построит перевод. Без стека, миграция только файлом, без коммитов.
