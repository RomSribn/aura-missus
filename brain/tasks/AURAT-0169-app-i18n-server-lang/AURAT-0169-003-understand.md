# AURAT-0169-003 — understand

Владелец: сначала серверный шаг 5 (клиентская часть в приложении), затем таро; надписи на самих картах не трогаем.

Приложение говорит серверу свой язык (`?lang` в JSON-запросах и загрузке), слушается серверного выключателя языков
(`disabledLanguages` из `/v1/app-config`: выключенный язык → английский, в листе языка его нет), рисует маркеры сессии по
полю `Message.marker` (после мёржа `AURAT-0167` и тега `v0.28.0`). Затем — таро на языке пользователя: карта дня и карты
расклада перезапрашиваются при смене языка, фразы с именем карты выдерживают переведённые имена из `AURAT-0171`.
