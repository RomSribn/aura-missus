# AURAT-0198-003 — understand

Дата: 2026-11-08.

Владелец хочет, чтобы перевод чата заработал для чаттеров: человек пишет на своём языке — чаттер в Chatwoot видит
английский перевод (оригинал — по «View original»). Сервер должен уметь и обратное направление — ответ советника
переводится на язык человека (`pending` → `translated | failed`, событие, догонка), но у каждого направления свой
выключатель, по умолчанию оба выключены, включаются по очереди: сначала «человек → чаттер».

Задача — спека конвейера (задача 5 `AURAI-0012`) с предложением модели / бюджета профиля `chat` (решения 1, 2, 9 —
владельца), затем, после одобрения, код в слоте без стека и без платных вызовов. Плюс два пункта из ревью `0197`:
окончательный `failed` и порядок `translations`.
