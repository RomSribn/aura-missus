## Что поправить

1. **`hold()`: сбой `SET` посреди ожидания даёт `held`.**
   - Если хоть один `SET` уже вернул `taken === false`, следующая ошибка или таймаут значит «ключ всё ещё держат».
     Продолжать опрос, `held` не возвращать.
   - `held` по ошибке `SET` — только на первой попытке.
   - Тест.
2. **`hold()`: граница должна идти от текущего удержания, а не от начала ожидания.**
   - При каждом неудачном `SET NX` читать токен (bounded `GET`). Токен сменился → `until = now + holdMs + margin`.
   - Тест: A держит, B и C ждут. A поздно отдаёт ключ без строки, B его берёт. Время уходит за исходную границу C →
     C отвечает `none` только после строки B и сам не постит.
3. **`sendMessage`: повторять upsert после успешного поста 2–3 раза с коротким отступом.** Upsert идемпотентен по
   `chatwootMessageId`. Только потом бросать и оставлять удержание. Тест.
4. **Продлевать удержание прямо перед постом.** `desk.extend()`: сверка токена и `PEXPIRE` на `DESK_POST_HOLD_MS`
   одной Lua-командой, bounded. Тест.
5. **`giveBack`: сравнить и удалить одной Lua-командой**, bounded, вместо `GET` + `DEL`. Поправить тесты.
6. **`admit`: перед отказом `!mayProbe`-вызову при свободном локе перечитать `tripped`.**
   - `null` (проба только что закрыла) → пропустить с `probe: false`.
   - Тест.
7. **`chat.service.spec`: общая заготовка upsert отдаёт строку с чужим `chatwootMessageId`.**
   - Посторонние тесты из-за этого уходят в ветку «поглощён по ключу».
   - По умолчанию — своя строка.
   - Тест «translated → без заметки» должен падать, если логика заметки сломана.
