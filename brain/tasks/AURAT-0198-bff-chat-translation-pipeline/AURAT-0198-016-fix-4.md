# AURAT-0198-016 — fix-4 по проверке третьего захода (`015`)

Дата: 2026-11-08 · slave-1, та же ветка (третий заход смёржен: develop `105200a`). Исправлены пункты 1–7 `015`.
Застейджено, коммитов нет, платных вызовов нет.

## 1. Сбой `SET` посреди ожидания — не удержание

- В `hold()` есть флаг `seenHeld`. Он ставится, когда хоть один `SET NX` вернул «занято».
- После этого ошибка или таймаут `SET` значат «ключ всё ещё держат»: опрос, граница и сон продолжаются, `held` не
  отдаётся.
- `held` по ошибке `SET` — только на первой попытке: Redis недоступен, договариваться не о чем.

**Тест:** первый `SET` ждущего — «занято», дальше `SET` бросает. Через 600 мс ответа нет; появилась строка → `none`,
вызов перевода один.

## 2. Граница — от текущего удержания

- После каждого неудачного `SET NX` — bounded `GET` токена.
- Токен сменился (новый держатель) → `until = now + holdMs + запас`.
- Ошибка `GET` оставляет прежнюю границу.

**Тест:** сроки удержания укорочены (`holdTimings` — поле только ради теста), граница ≈ 1 с.
1. A держит ключ, B и C ждут.
2. A отдаёт ключ без строки на 700 мс. Один из B / C берёт его и получает английский из кэша A.
3. Второй ждёт ещё 600 мс — дальше своей первой границы — и отвечает `none` только после строки нового держателя.
4. Предупреждения `outlived` нет, вызов перевода один.

## 3. Повтор записи после успешного поста

- `ChatService.storeSent`: до 3 попыток upsert с отступом 100 мс × номер попытки. Upsert идемпотентен по
  `chatwootMessageId`.
- Только после третьей попытки отправка бросает и оставляет удержание истекать.

**Тесты:**
- две ошибки, затем успех → ответ строкой, пост один, удержание снято;
- три ошибки → бросает, upsert вызван 3 раза, удержание не снято.

## 4. Продление удержания перед постом

- `DeskTranslation` = ответ + `DeskHold { release, extend }`.
- `extend` — Lua `EXTEND_SCRIPT`: если `get == token`, то `pexpire` на `DESK_POST_HOLD_MS` (130 с). Bounded, не
  бросает.
- `ChatService` зовёт `desk.extend()` прямо перед `postUserMessage`.
- Без удержания (нет ключа, перевод выключен) — пустышка.

**Тесты:**
- порядок `extend` → `post`;
- после 5 с `extend` ставит срок `now + 130 с`;
- чужое удержание не продлевает.

## 5. Снятие одной командой

- `release` — Lua `GIVE_BACK_SCRIPT`: если `get == token`, то `del`. Bounded, вместо `GET` + `DEL`.
- `DeskCache` = `get` / `set` / `eval`.
- В спеке — `HoldStore`: `FakeStore` плюс эти два скрипта, атомарно.
- Прежние тесты («только своё», «SET не ответил, но дошёл») проходят на нём.

## 6. Проба закрыла предохранитель между двумя чтениями

- В `admit`: `!mayProbe()` и лок свободен → `tripped` читается ещё раз.
- `tripped` уже `null` → вызов идёт (`probe: false`). Иначе — отказ с перечитанной причиной.

**Тест брейкера:** `get` лока снимает `tripped`, как это сделала бы проба → `{ probe: false }`.
