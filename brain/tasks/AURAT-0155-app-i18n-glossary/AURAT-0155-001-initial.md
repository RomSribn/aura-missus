# AURAT-0155-001 — initial

Дата: 2026-11-04. Контекст: `aura-app-manor` slave-1, ветка `feature/AURAT-0155-app-i18n-glossary` от `develop`
@ `40d0ee7` (ветку завёл диспетчер; сессия — через `wts-run`).

Владелец: «запускай 1b и 1c параллельно на слейвах и другие задачи одновременно».

Диспетчер: это шаг **1b** фичи `AURAF-0023` — глоссарий, таблица обращения и память переводов из aura-web, чтобы
следующие задачи переноса строк переводили одинаково и одинаково с вебом. Основание: `AURAI-0010` §5, §9 и
Recommendation 1b; доказательства — `AURAI-0010-evidence.json` (темы `web-i18n`, `tooling-quality`).
Что ожидается (решает спека этой задачи, владелец утверждает):
- около 80 терминов предметной области (advisor, session, reading, balance, top up, promo code, tarot, free chat,
  reschedule…) по 24 языкам; разрешить 78 расхождений терминов внутри языков в переводах веба;
- явная таблица «ты/вы» по 23 языкам; решение по болгарскому (на вебе смешано);
- правила для переводчиков: не согласовывать с родом пользователя, бренды не переводить, греческие заглавные,
  ș/ț, NFC — уже записаны в `.claude/aura-build-rules.md` («Translations»), глоссарий на них ссылается;
- память переводов: способ (скрипт в `scripts/i18n/` приложения) подставить 23 перевода веба для строки, чей
  английский совпадает с вебом, со ссылкой на источник (`<web namespace>:<key>`);
- сверить с глоссарием уже переведённый `shared` (`src/shared/config/locales/`).
Не входит: правка переводов самого веба (это `aura-web-manor`, отдельной задачей).
