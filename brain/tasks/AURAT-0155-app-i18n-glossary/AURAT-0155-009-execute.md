## Решения по ходу
- `match` получил режим `exact` (сверх `word` / `stem` из спеки): у кнопок («Save», «Close», «Now»…) термин —
  только вся строка; без этого «You save $5» требовал «Speichern». Для `avoid` `exact` запрещён тестом.
- Советы сравниваются без диакритики (греческие ударения в падежах); `avoid` — строго, с диакритикой.
- Прогон глоссария по вебу поймал мою ошибку: el `avoid` «συνεδρίασ» (основа) ловил родительный «συνεδρίας» →
  целое слово «συνεδρίαση». Тест теперь ещё проверяет, что `avoid` не ловит каноническую форму.
- fr / pt / ro: разговор — «discussion» / «conversa» / «conversație», «chat» — только в «chat gratuit» (как вкладка
  веба); запрета на «chat» нет — оба слова законны в разных значениях.
- Запреты «Опитайте отново» и т. п. не ставил: в предложении это правильная форма; правило — таблицей.
- el: кнопка — существительное, «-στε» допустимо, где существительного нет («Δοκιμάστε ξανά»).
- Исходник для сборки JSON (компактный текст + сборщик) остался в scratchpad, в репо не идёт: дальше правится
  сам `glossary.json`.
