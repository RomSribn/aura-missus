# AURAT-0155-003 — understand

Дата: 2026-11-04.

Нужен общий словарь для всех будущих задач переноса строк приложения (шаги 2–3 `AURAF-0023`), чтобы 24 языка
переводились одинаково между слайсами и одинаково с aura-web. Три результата:

1. **Глоссарий** (~80 терминов предметной области × 24 языка) с разрешёнными расхождениями веба — какой вариант
   канонический в каждом языке; правила для переводчиков — ссылкой на «Translations» в build rules.
2. **Таблица обращения** «ты/вы» по 23 языкам (с решением по болгарскому — на вебе смешано).
3. **Память переводов**: скрипт в `scripts/i18n/` приложения — по английской строке находит совпадение в вебе и
   выдаёт 23 перевода с источником `<web ns>:<key>`; плюс сверка уже переведённого `shared` с глоссарием.

Правка переводов самого веба — не здесь. Порядок: спека → одобрение владельца → код.
