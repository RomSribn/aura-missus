# AURAT-0124-008 — Review fixes (ревью манора, образ из slave-1 прогнан локально)

Date: 2026-10-23

## Исправить

1. `/assets/`: `Cache-Control … immutable` — без `always`. Сейчас 404 на отсутствующий чанк
   уходит с `immutable` на год; при деплое Traefik ~1 с видит оба контейнера (новый `index.html`,
   чанк со старого → 404) — 404 застревает в кэше браузера, reload не помогает. У заголовков
   безопасности `always` остаётся.
2. `build.sh` — остальные правила `env.ts`: `VITE_BFF_WS_PATH` начинается с `/`;
   `VITE_PSP_ENABLED`, `VITE_FIREBASE_AUTH_TEST_MODE` — ровно `true` / `false`. Сейчас
   `VITE_PSP_ENABLED=False`, `VITE_BFF_WS_PATH=ws` проходят → белый экран. (Схема `env.ts` при
   сборке — правка `src` и падение локального `npm run build` без `.env`; не в этой задаче.)

## Стоит сделать

3. Origin — `^https?://[A-Za-z0-9.-]+(:[0-9]+)?$`: текущий `[^/[:space:]]+` пропускает
   `| & " ;` — ломают `sed`, строку nginx или дописывают директиву в CSP. И `RUN nginx -t` в
   финальной стадии: ошибка конфига роняет сборку, а не сайт (healthcheck нет).

## Красота

- «Пустое = не задано» без списка и `eval`: имена пустых `VITE_*` из `env` — новая переменная
  `env.ts` покрывается сама.
- `Dockerfile` стр. 2: директиву читают только выше первого комментария, пустой строки или
  инструкции.
- Вторая стадия — `AS final`, как в шапке.
- `headers.conf`: в шапке не литералы плейсхолдеров (`sed` заменяет и их) — «два плейсхолдера
  ниже».
- `/50x.html` дефолтного nginx отдаётся — `dist` в свою папку (`root /srv/aura`).
