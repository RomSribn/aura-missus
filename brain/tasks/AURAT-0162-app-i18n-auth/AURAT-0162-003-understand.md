# AURAT-0162-003 — understand

Перевести на 24 языка экраны входа — телефон, код, онбординг-слайдер, сплэш — и названия стран в выборе кода
телефона: страны на языке интерфейса, по алфавиту этого языка, поиск без учёта диакритики. Склейки из фрагментов
переписать (юридическая строка → `<Trans>`, «from {country}» — имя вне падежного слота), ошибки входа — по ключам,
горячие места вёрстки проверить псевдоязыком. Правило линтера — на `error` для перенесённых путей.
