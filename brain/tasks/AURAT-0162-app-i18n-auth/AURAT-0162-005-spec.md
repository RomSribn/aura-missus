# AURAT-0162-005 — spec: вход и названия стран на 24 языках

Тип: задача фичи `AURAF-0023` (шаг 3), строки `AURAF-0023-003` (частично — вход) и `AURAF-0023-005`.
Status: done 2026-11-05 (`develop` @ `7f58117`).

## Что получится

Человек, у которого телефон на немецком (или любом из 24), видит по-немецки сплэш, три слайда онбординга, экран
телефона, выбор страны и экран кода. Страны в выборе — по-немецки и по немецкому алфавиту; «osterreich» находит
«Österreich», «γερμανια» — «Γερμανία». До запуска (шаг 4) всё это видно только в dev (флаг `AURA_I18N_ENABLED`),
релиз остаётся английским.

## Как

### Строки
- Namespace на слайс: `<slice>/config/locales/{en,23 языка,index}.ts`, регистрация в `app/i18n/namespaces.ts`,
  `i18next/no-literal-string` на `error` для четырёх слайсов.
- Переводы — из веба, где английский совпадает (`translate.mjs scan … --web`), иначе по глоссарию и регистру языка.
- `@max` — кнопки (Skip, Send code, Get started, Continue), «change», заголовок листа; `@sensitive legal` — юридическая
  строка (попадает в `native-review`).
- Склейки:
  - юридическая — одна строка с `<Trans>`: `…agree to our <terms>Terms of Use</terms> & <privacy>Privacy Policy</privacy>.`;
    ссылки — компоненты с размером текста (как сейчас).
  - «Sent to {{phone}}» и «change» — две строки, как на вебе: «change» — отдельное действие, не продолжение фразы.
  - «Resend code in {{time}}» — уже в `shared`.
  - «нет SMS для страны» — имя страны вне падежного слота (решение 2).
- Заголовок «Enter your\nphone number»: перенос — часть перевода; язык ставит его, где ему удобно, или не ставит.
- `resendFailed` — ключом, как остальные ошибки; ошибки Firebase уже в `shared:auth.*` (`0157`) — проверю, что каждый
  `AuthErrorKey` имеет перевод во всех 24 (тип это гарантирует, тест — добавлю, если его нет).

### Названия стран
- Генератор `scripts/i18n/generate-country-names.mjs` (по образцу `generate-language-names.mjs`): из Node ICU
  (`Intl.DisplayNames`, CLDR 48) пишет файл на язык — `src/shared/config/country-names/<lang>.generated.ts`, объект
  `{ iso2: name }` **в порядке алфавита этого языка** (`Intl.Collator(lang)` при генерации — на устройстве порядок не
  зависит от ICU телефона). Дыры CLDR (`mt` × `IO`) — английским названием.
- ga и mt — сортировка без начального артикля (`an` / `na` + `t`/`h-`; `il-`, `l-`, `iċ-`, `id-`, `in-`, `ir-`, `is-`,
  `it-`, `ix-`, `iż-`, `iz-`): «an Ghearmáin» стоит под G, «il-Ġermanja» — под Ġ. Название показывается как в CLDR.
- Загрузка — только активного языка: `require`-загрузчики, как у namespaces (+~5 КБ кучи вместо ~112 КБ).
  `shared/lib` даёт `useCountryNames()` → `{ nameOf(iso2), sort(list), matches(iso2, needle) }`.
- `shared/config/countries.ts` теряет `name` и `search` (остаются `iso2`, `dial`); английские названия — такая же
  сгенерированная таблица `en`.
- Поиск: свёртка один раз на язык (NFD, без `\p{M}`, карта ł ø đ ħ ß æ œ, нижний регистр), иголка сворачивается так
  же; совпадение по названию на языке интерфейса, по английскому названию (решение 3), по ISO и по коду (+49).
- Drift-тест против Node ICU (как `language-names.test.ts`), тесты свёртки (ö, ł, тоны el), сортировки ga/mt.

### Вёрстка
- Псевдоязык (+40 %) и самые длинные языки (de, fi, hu, el, ga): заголовок, кнопка Send code, «I already have an
  account», строка «Sent to … · change» (сейчас в одну строку — разрешу перенос), строки листа (48 pt, имя в одну
  строку с обрезкой — «Ηνωμένες Πολιτείες», «Sjedinjene Američke Države» влезают). Проверка — тестами/снимками в
  слейве, на устройстве — в маноре после мёржа.

## Решения владельца
1. **create-account** — в задачу «профиль и аккаунт» (рекомендую) или сюда.
2. **«We can't text numbers from {{country}} yet.»** — рекомендую «{{country}}: we can't text numbers there yet.» —
   имя в именительном в начале, переводчику не нужен падеж. Английский текст меняется.
3. **Поиск страны и по английскому названию** — рекомендую да: немец, набравший «Germany», найдёт страну.

## Не в объёме
- create-account (если решение 1 — «профиль»), остальные экраны.
- Нативные объявления языков, включение флага — шаг 4.
- Язык SMS — уже `setLanguageCode(currentLanguage())` (`0157`).
