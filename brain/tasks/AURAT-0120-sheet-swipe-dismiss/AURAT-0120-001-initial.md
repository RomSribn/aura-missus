## Запрос владельца (дословно)

«запуcти задачу, чтобы сделать возможность свертывать наши модалки свайпом, на ИОС кажется
нативный компонент для этого есть, посмотри какой самый лучшийц вариант по best practice делать
это»

- Все наши шторки (`shared/ui/bottom-sheet/BottomSheet`) должны закрываться свайпом вниз.
- Нужно выбрать лучший по best practice способ. На iOS, возможно, есть нативный компонент.
