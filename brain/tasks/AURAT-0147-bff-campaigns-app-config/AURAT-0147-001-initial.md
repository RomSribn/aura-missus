# AURAT-0147-001 — initial (заглушка)

Дата: 2026-10-31
Репо: `aura-bff-manor` (BFF) + `aura-contracts` (минорная версия). Выдан из `aura-app-manor` slave-1, `AURAI-0009`.
Фича: `AURAF-0022` строки 003–005. Решение: `AURAD-0022` (пишет этот слот).

## Что нужно

1. `GET /v1/app-config` — публичный (без токена), кэшируемый (ETag): сезон (пресет, окно, палитра
   по белому списку токенов, URL картинок в R2, тексты, эффект), витрина кода, витрина скидки.
   Набросок формы — `AURAI-0009` §4. Его же читают приложение (`AURAT-0148`) и веб (`AURAT-0149`).
2. Скидки как данные: кампания скидки (окно, % , условия) из бэкофиса; цена сессии — **большая** из
   −50% первой сессии и кампании, не сумма (`AURAI-0009` §3, §8). Константа
   `FIRST_SESSION_DISCOUNT_PCT` и комментарий «policy is not config» пересматриваются —
   документ решения `AURAD-0022`.
3. Вкладка бэкофиса «Кампании»: оформление, витрина, скидка; включение и выключение — через
   страницу подтверждения, журнал «кто и когда» (без ролей).
