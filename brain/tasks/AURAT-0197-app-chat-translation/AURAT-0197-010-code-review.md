# AURAT-0197-010 — code review координатора

Дата: 2026-11-08 · от координатора (сессия «Локализация i18n для aura-app»). Владелец на «Передать исполнителю?»:
**«Передавай все (Recommended)»**.

Верно: монотонное слияние, `?lang`, правило показа, FSD, текст согласия. Блокирующих нет.

1. **[важно]** Повтор неотправленного обходит согласие (`use-chat-thread.ts` `retry`): сообщение не ушло до галочки →
   появилась карточка → «повторить» → ушло без согласия. Правка: `retry` выходит при `consent.required`, кнопки
   повтора в пузыре нет, пока галочка не поставлена. Тест.
2. **[важно]** Профиль не загрузился при старте → галочки нет весь запуск (`load` ставит `error`, перечитывает только
   смена аккаунта / экран профиля). Правка: при открытии треда и возврате в foreground при `status === 'error'` —
   `profileStore.load()`. Тест.
3. **[вероятно]** 409 у переключателя при расхождении версий — переключатель молча откатывается. Правка: на 409 тоже
   `failed`.
4. **[вероятно, редко]** Быстрые нажатия — ответы в обратном порядке, стор пишет любой. Правка: отметка попытки или
   перечитать; можно `pending` — блокировать переключатель на время запроса.
5. **[мелочь]** Ошибка переключателя в `ProfileMenu` — без live region, диктор не зачитает.
6. **[мелочь]** `message.translated` для незнакомого сообщения отбрасывается — окно при переподключении. Дёшево:
   держать отброшенные в маленькой карте и применять при слиянии через `mergeTranslation`.

Пробелы: `accessibilityLabel` кнопки «Show» по состоянию (язык); тесты — предел `TRANSLATION_ROUNDS_MAX` и поколение
посреди раундов, переводы из `refreshSpreads`, повторный `message.new` известного не трогает непрочитанные; согласие —
404, уход с экрана во время запроса, двойное нажатие, путь повтора; псевдоязык в `translation.test`; переключение
«оригинал / перевод» через `use-chat-thread`.

Вердикты: `@max 16` у `elsewhere` — ок; отброс незнакомого события — ок с оговоркой (п. 6). Задача 5 BFF (failed не
