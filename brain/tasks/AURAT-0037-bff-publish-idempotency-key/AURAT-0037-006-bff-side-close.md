## Замер, на который опирается приёмка

После мержа `fc62f29`, против боевого BFF:

```
поле в ответе присутствует: true
сообщений просмотрено: 124
из них с ключом: 12
с ключом и НЕ нашего направления: 0
```

Третья строка — ответ на замечание из ревью: `source_id`, который Chatwoot пишет
себе, наружу не уходит. Проверено не тестом, а фактом на живых данных.

## Мелочь, которую стоит знать обеим сторонам

**Ключ приезжает дельта-синком истории, а не сокетом.** Фан-аут по сокету идёт
только при `direction === 'advisor'`; наше собственное сообщение, подобранное
опросом, по сокету не приходит вообще. У вас `mergeServerMessages` читает
историю — то есть верно; фиксирую, чтобы следующий читатель не пошёл искать
событие в сокете.
