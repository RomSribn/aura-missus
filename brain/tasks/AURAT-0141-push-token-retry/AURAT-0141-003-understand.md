# AURAT-0141-003 — understand

Каждый вошедший пользователь на живой установке должен иметь токен в BFF `device_tokens`. Сейчас
регистрация делается один раз на запуск процесса и только после ответа на системный запрос
разрешения; любой сбой глушится и до следующего холодного старта не повторяется. Нужно сделать
регистрацию устойчивой; диагностику причин сбоев — по решению владельца.
