# AURAT-0195-008 — fix: JSDoc порядка выкатки версии согласия

Дата: 2026-11-07 · Ревью кода координатором: по спеке, замечаний по сути нет; одна правка до коммита.

**Замечание:** `ChatSettingsPatchRequest.consentVersion` ограничен `.max(CHAT_CONSENT_VERSION)`, поэтому сервер на
старых контрактах ответит `400` на версию согласия новее своей. Это надо описать.

**Сделано** (`src/chat-settings.ts`, только JSDoc):
- у `CHAT_CONSENT_VERSION`: новая версия выходит сначала на сервере, потом в клиентах. Клиент, получивший `400`,
  опережает сервер: он показывает текст версии, которую знает сервер, или просто не включает перевод. Чат из-за
  этого не блокируется;
- у `consentVersion`: потолок — версия пакета на сервере, ссылка на правило выше.

**Проверки:**
- контракты: `typecheck` и `build` чистые;
- dist заново подложен в BFF slave-2: `typecheck` чистый;
- `compat.cjs` — 23 из 23.

Застейджено, без коммита.
