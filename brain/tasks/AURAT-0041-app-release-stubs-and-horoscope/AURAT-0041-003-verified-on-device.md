# AURAT-0041-003 — Проверка на устройстве: два дефекта, которых не видели ни ревью, ни тесты

Дата: 2026-08-28
Стенд: Samsung SM-A505FN по проводу, debug-сборка против **боевого** BFF,
оба billing-флага включены.

## Две особенности стенда, не дефекты кода

- Debug не встаёт поверх релизной подписи (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`)
  — релизная сборка versionCode 11 снесена по решению владельца.
- Устройству по проводу нужен `adb reverse tcp:8081 tcp:8081`; `run-android`
  не успел его поставить, упав на установке. Слетает при сбое Metro — красный
  экран «Unable to load script» означает именно это, пересборка не нужна.

**Отдельная ловушка, стоившая получаса.** Metro умер по SIGTERM, порт 8081
занял другой процесс без переменных окружения, и Babel вшил в бандл дефолтный
`dev`-таргет (`http://192.168.31.55:3000`) вместо прода. Симптом — «бэкенд не
грузится», и он **неотличим от проблемы с сетью**: владелец заподозрил DNS.
Разрешается замером, а не рассуждением:

```
grep -o "https://bff\.aura-app\.cc\|http://192\.168" bundle.js
```

скачав бандл прямо с Metro. Заодно: живой процесс на 8081 — не обязательно
твой, аптайм проверять стоит сразу.

## Два дефекта, оба старше этой ветки

1. **Юридические ссылки рисовались 16pt внутри 12pt предложения.** Shared
   `Text` подставляет каждому экземпляру `fontSize` своего варианта, поэтому
   вложенный `<Text>` **не наследует** размер родителя и падает на дефолт
   `body`. Ловушка общая для всего проекта, не только для этого экрана.
2. **Сплэш никогда не смотрел на сессию** — `// TODO: Check if user has seen
   onboarding` и безусловный `replace(ONBOARDING)`. Каждый холодный старт гнал
   вошедшего пользователя заново вводить телефон и получать **настоящую SMS за
   деньги**. Это было дороже всех семи заглушек из списка владельца вместе.

   Чинится не так, как кажется: наивная правка через `getCurrentUser()` по
   таймеру **не сработала бы именно на холодном старте** — сессия
   восстанавливается асинхронно и в этот момент читается как «не вошёл».
   Ждём первый ответ `onAuthStateChanged`, с 3-секундным потолком, чтобы
   неотвечающая сессия стоила лишнего прохода онбординга, а не вечного сплэша.

Оба невидимы для ревью и юнит-тестов по своей природе: первый — вопрос
рендеринга на реальном экране, второй проявляется только на втором запуске.

## Проверено глазами, все пункты

Тагляйн сплэша; созвездие вместо веера карт на слайде 2; Home без баннера таро
и **без секции гороскопа**, с живыми советниками и «Continue your chat»;
Advisors без пилюли EN; профиль советника без сердечка; меню профиля из двух
строк; баланс и Top Up; обе юридические ссылки открывают живые страницы;
вход не спрашивается на каждом старте.

**Подтверждено главное проектное решение:** маршрут гороскопа отдаёт 404,
секция не рисуется, остальное приложение этого не замечает.
