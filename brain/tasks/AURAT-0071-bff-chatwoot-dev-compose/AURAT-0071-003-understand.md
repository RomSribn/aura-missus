# AURAT-0071-003 — Что нужно

Дата: 2026-09-14

На одном хосте в сети `coolify` будут два Chatwoot, развёрнутые из
`RomSribn/aura-bff`: прод из `main` (`chat.aura-app.cc`) и dev из `develop`
(`chat-dev.aura-app.cc`). Нужно, чтобы dev-экземпляр получил **свой** сетевой
alias и **свой** `FRONTEND_URL`. Прод-BFF должен и дальше попадать только в
прод по `chatwoot-rails`, а прод-экземпляр по поведению не должен измениться.
Выбранный путь проверяется в слоте без запуска: чтением кода Coolify 4.3.19 и
`docker compose config`.

Сопутствующее: комментарии в compose, которые описывают один экземпляр на все
окружения, и ответ, чем провижинить dev-inbox в отдельном экземпляре
(`provision-prod.rb` запрещает имя `Aura (dev)` и по умолчанию берёт
прод-имена).

Вне слота, в маноре: создать dev-приложение в Coolify, DNS, бакет R2,
провижининг.
