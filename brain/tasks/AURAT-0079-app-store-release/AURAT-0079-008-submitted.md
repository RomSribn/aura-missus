## Две вещи, которые API не умеет

1. **Покупки в заявку через API не кладутся.** У `reviewSubmissionItems` нет
   связи для них (проверены `inAppPurchase`, `inAppPurchaseV2`), у самого
   продукта — тоже. Делается только в консоли: **In-App Purchases → Edit →
   отметить все → Add for Review → выбрать уже существующую черновую заявку**.
   Если выбрать «Create New Submission», покупки уедут отдельно от приложения.

   **Уточнение от 2026-10-08.** Это верно только для заявки, собираемой с
   нуля. После ответа на сообщение ревьюера покупки **прицепляются сами**:
   проверено на третьем заходе — в `Items Submitted` снова пять позиций,
   руками ничего не добавляли. Ручная возня нужна один раз, при первой
   сборке заявки.
2. **App Privacy** заполняется только руками.

## Заметки для ревьюера (суть)

Написано то, без чего приложение читается как сломанное: ответы приходят **от
живых операторов** и могут занять минуты; пополнение у ревьюера идёт **в
песочнице и бесплатно**; **не удалять аккаунт** — удаление необратимо и заберёт
учётку тестового номера. Плюс строка, что советники — персоны команды, со
ссылкой на Terms.
