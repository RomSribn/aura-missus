# AURAT-0151-003 — Понимание

Дата: 2026-11-01

Пока у оператора живая скидка кампании, цены в каталоге (списки и плитки советников, Home, рейл,
профиль, карточки `/match`) показываются зачёркнутыми со ставкой со скидкой — как уже делается для оффера
первой сессии. Действует одна скидка, большая из двух (ничья — кампания), как считает сервер; бронь не
меняется — там цифры уже с сервера. Билеты (`SeasonTicket`) не меняются.
