# AURAT-0151-005 — Спека (одобрена с правкой `-006`; задача done — `-010`)

Дата: 2026-11-01
Тип: task — дополнение строки `AURAF-0022-007` (веб). Новой фичи нет, контракт не меняется (`v0.27.0`).
Отменяет фразу `AURAT-0149-005` §4 «цены на списках скидку кампании не показывают».

## 1. Что увидит человек

Пока у оператора живая скидка кампании, каждая цена каталога — зачёркнутая обычная ставка и рядом ставка
со скидкой, как сегодня у оффера:

| Место | Сейчас | После |
|---|---|---|
| Строка и плитка советника (Advisors, Home) | оффер | действующая скидка |
| Рейл советника (Home, desktop) | оффер | действующая скидка |
| Профиль советника — шапка, боковая карточка, панель на телефоне | оффер | действующая скидка |
| Карточка `/match` | оффер | действующая скидка |
| Ставка в подзаголовке шторки брони (правка владельца, `-006`) | оффер | действующая скидка; итог и строка скидки — по-прежнему от сервера |

**Какая скидка действует** — как сервер (`priceBlock`, `AURAT-0147`): большая из двух, никогда не сумма.

```
оффер = offerPct страницы (уже «оффер, как его оценил сервер / кошелёк»), иначе нет
кампания = app-config.discount, живая по своему endsAt (useSeason), иначе нет
кампания есть и её pct ≥ оффера (или оффера нет)  → КАМПАНИЯ   (ничья → кампания)
иначе оффер есть                                   → ОФФЕР
иначе                                              → без зачёркивания
```

Ставка со скидкой — `discountedMinor(price, pct)` = `floor(price · (100 − pct) / 100)`, тот же floor, что
у сервера. Это превью: бронь пересчитывает сервер (правило 7), брони и её цифры не меняются.

**Подпись.** Коралловый чип остаётся коротким: «−50%» / «−20%» (рядом с именем в строке места на
название нет; название кампании уже видно на билете DISCOUNT той же страницы — «Winter sale · 20% OFF
sessions»).
- выиграл оффер — как сейчас: чип «−50%», доступное имя «50% off your first session»;
- выиграла кампания — чип «−20%», доступное имя и подсказка (`title`) «20% OFF · Winter sale»
  (`label` с сервера), без слов о первой сессии;
- скидки нет — ни чипа, ни зачёркивания.

Кампания гаснет по `endsAt` сама (таймер `useSeason` уже есть) — цены возвращаются без перезагрузки.
Биллинг выключен — сервер шлёт `discount: null`, скидки кампании нет.

## 2. Как устроено

- **`entities/season/lib/price-discount.ts`** — одна чистая функция
  `priceDiscount(offerPct, campaign) → PriceDiscount | null` (правило выше; комментарий «as aura-bff
  `priceBlock`, AURAT-0147»). Парная функция в приложении — дополнение `AURAT-0148`, то же правило.
- **`entities/season/model/use-price-discount.ts`** — `usePriceDiscount(offerPct)`: берёт живой
  `discount` из `useSeason()` и зовёт функцию. Страницы передают свой `offerPct`, как уже делают для
  `useSeasonTicket` — без кросс-импорта `entities/wallet`.
- **Тип `PriceDiscount`** `{ pct: number; label: string | null }` (`label` = название кампании, `null` —
  оффер) — в `shared/lib`, потому что его принимают `entities/advisor` и `shared/ui` (сущности не
  импортируют друг друга).
- **`OffChip`** получает необязательный `label`: есть — доступное имя и `title` «{{pct}}% OFF · {{label}}»
  (новый ключ `shared` → `offer.chipCampaignLabel`, на всех 24 языках), нет — как сейчас.
- **`AdvisorRow`, `AdvisorTile`, `AdvisorCard`, `MatchCard`** — проп `offerPct` заменяется на
  `discount: PriceDiscount | null`. Модели страниц (`use-advisors-page`, `use-home-page`,
  `use-advisor-page`, `use-match-page`) и `AdvisorRail` считают `discount = usePriceDiscount(offerPct)`.
- **`offerPct` остаётся** там, где он про оффер: билет (`SeasonTicket` / `useSeasonTicket`), «How Aura
  works» на Home, отступ `withOffer` на `/match`, приглашение в чате, карточки сессий.

## 3. Проверки (слот)

Vitest:
- `priceDiscount`: только оффер; только кампания; оффер > кампании → оффер; кампания > оффера →
  кампания; **ничья 50 = 50 → кампания**; ничего → `null`.
- `usePriceDiscount`: кампания по `endsAt` гаснет → снова оффер / `null`.
- `AdvisorRow` / `AdvisorTile`: кампания — зачёркнута обычная ставка, ставка со скидкой floor
  (напр. 199 ¢ −20 % → 159 ¢), чип «−20%» с именем «20% OFF · Winter sale»; оффер — как сейчас; нет
  скидки — без `<s>`.
- `OffChip` с `label` и без; существующие тесты страниц, которые передают `offerPct`, — на новый проп.
- i18n-полнота (новый ключ ×24), `lint`, `typecheck`, `build`.

Манор после мёржа, против bff-dev (кампания winter −20 % «Winter sale»): аккаунт с оффером — везде
«−50%», зачёркнуто к −50 %; аккаунт с потраченным оффером — «−20%», «20% OFF · Winter sale» в имени чипа,
зачёркнуто к −20 %; гость — как аккаунт с оффером.
