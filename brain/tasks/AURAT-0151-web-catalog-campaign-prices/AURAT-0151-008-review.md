Ревью — сессия манора (manor-70): блокеров нет; M1 — до мёржа, L2 — сразу, остальное — позже.
Проверено манором: правило совпадает с `priceBlock` (сравнение процентов не расходится с центами),
все поверхности, ключ ×24, FSD, memo.

## Сделано
- **M1 — кампания ≥ оффера гасла, а оффер на цены не возвращался без перезагрузки.** Пока сервер
  отдаёт блоки кампании, `offerPctFromPricing` → `null`; `useSeason` гасил `discount` по `endsAt`, но
  pricing никто не перечитывал → `priceDiscount(null, null)` → полная цена, а итог шторки — от старого
  pricing. Исправление: `entities/season/model/use-campaign-reprice.ts` — после первого ответа
  `app-config` любое изменение живой скидки (гаснет по `endsAt`, включили / выключили / сменили %)
  → `invalidateTags(['Pricing'])`. Смонтирован в `useSeasonDocument` (один раз, `AppRoot`).
  Тест: аккаунт с живым оффером, кампания −60 % до `endsAt`, после — стаб pricing отдаёт блоки оффера
  → чип снова «−50%» (параметр `wallet` в `stubBff` теперь используется; `pricing` — функция).
  `season.test.tsx` монтирует `useSeasonDocument` так же, как `AppRoot`.
  **В маноре на winter −20 % это не проверить** — там выигрывает оффер; M1 покрыт только тестом.
- **L2 — ставка шторки и итог из разных источников.** `usePriceDiscount(offerPct, priced?)`: шторка
  передаёт `booking.campaign` (кампанию из pricing) — она первее живой из `app-config`. Тест: шторка
  без `app-config`, pricing с кампанией −20 % → ставка зачёркнута $2.00 → $1.60.
- Мутационная проверка: без инвалидации падает тест M1, без `priced` — тест L2.
- `lint` (eslint + Steiger) ✓, `typecheck` ✓, prettier ✓, `npm test` 107 / 1886 ✓, `build` ✓.

  (тот же `discountedMinor`): ceil на поминутной ставке или оставить сознательно.
