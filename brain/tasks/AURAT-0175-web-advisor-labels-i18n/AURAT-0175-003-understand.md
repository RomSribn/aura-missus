# AURAT-0175-003 — understand

Дата: 2026-11-07

Сервер теперь отдаёт `Advisor.role` / `specialties` на языке `?lang` и новое `Advisor.topics`. Веб должен:
(1) подбирать советников на `/match` по `topics`, а не по английским словам в `specialties` — иначе «also» пустеет у
неанглийских посетителей; (2) держать язык в ключе кэша каталога, чтобы смена языка перечитывала каталог и опоздавший
ответ не ложился поверх; (3) встать на контракты `v0.29.0`, фикстуры — с `topics`. Глоссарий v3 — копией из
приложения, когда `0174` его закоммитит. Новых строк, по плану, нет.
