# AURAT-0175-017 — fix: плитки ряда выравниваются по самой высокой

Дата: 2026-11-07 · Правка `016` застейджена, не закоммичена; координатор проверил её без замечаний и с одним
наблюдением: если в одной плитке «Buchen» ушёл на вторую строку, а в соседней нет, верхние кнопки ряда — на разной
высоте (кнопки прижаты книзу, а блок действий выше).

Владелец (на вопрос о коммите и мёрже): «сделай что-то с этой разной высотой, можно ли выравнивать плитки по самой
длинной в линии?»

Решение: CSS subgrid — плитка занимает в сетке три строки (фото, текст, кнопки), общие для всего ряда; каждая строка
— по самой высокой плитке; кнопки — по верху своей строки. Без поддержки subgrid — нынешняя flex-растяжка.
