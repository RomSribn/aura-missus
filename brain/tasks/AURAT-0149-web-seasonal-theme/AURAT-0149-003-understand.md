# AURAT-0149-003 — understand

Веб читает `GET /v1/app-config` (публичный, без токена) до первого рендера и, пока оператор
держит сезон, перекрашивает пять мест из сдачи `SEASONAL.md`: новый hero на Home (с эффектом
частиц), билет на месте `CouponTicket` (один билет: welcome / скидка / код), орб, баннер Daily
ritual и активный пункт навигации. Цвета — данные (17 токенов → `--season-*`), без сезона всё
как сегодня, вспышки дефолтной темы нет.

Публичный код кампании открывается ссылкой `/promo/:code`: гость → вход с причиной `promo` →
после входа код гасится тем же `POST /v1/wallet/promo-codes/redeem`; вошедший — сразу шторка
промокода с кодом. В брони — подпись скидки кампании из `SessionPricing.blocks[].discount`
вместо зашитого «First Session».

До тега `@aura/contracts v0.27.0` — локальный тип по спеке `AURAT-0147-007` + `-010`, после тега —
контракт (отдельный коммит).
