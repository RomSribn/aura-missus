# AURAT-0097-006 — Решения владельца

Дата: 2026-10-18

На три открытых вопроса из `005` владелец выбрал рекомендованные варианты:
1. Удалённое сообщение **исчезает без следа** — без плашки, `Message` не меняется.
2. Удаление действует **в обе стороны**: сообщение пользователя, удалённое
   оператором, тоже пропадает в приложении (в BFF фильтра по направлению нет).
3. Потеря удаления при простое BFF — **запись в TECH-DEBT**, бэкстоп не строим.

`AURAF-0018` и `AURAT-0098-001` с этим согласованы. Явного «го» на код ещё
нет; код приложения в любом случае ждёт тег `aura-contracts` `v0.22.0`
(`AURAT-0098`, часть A).
