# AURAT-0097-003 — Понимание

Дата: 2026-10-18

Оператор (чаттер) удаляет сообщение в дашборде Chatwoot → у пользователя в
чате приложения это сообщение тоже исчезает: живьём (если чат открыт), в
истории после перезапуска/на другом устройстве, в превью последнего сообщения.

Удаление инициирует только Chatwoot (пользователь в приложении сам ничего не
удаляет — владелец об этом не просил). Результат этой задачи — спека фичи
`AURAF-0018` и две подробные задачи: приложение (`AURAT-0097`) и BFF
(`AURAT-0098`, исполнимая в `aura-bff-manor`). Кода до одобрения нет.
