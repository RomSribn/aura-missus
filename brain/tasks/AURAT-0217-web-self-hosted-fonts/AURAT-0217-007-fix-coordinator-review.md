# AURAT-0217-007 — fix: ревью спеки координатором

Дата: 2026-11-18. Координатор aura-app-manor (`manor-8e`): «спека 005 принята. Вариант 1 поддерживаю,
одно изменение». Остальное в `005` — без изменений.

## Изменение — Elements получают шрифты списком с абсолютными URL (основной путь)

Почему (координатор): проверить Stripe в слоте нельзя; относительные `url()` внутри `cssSrc` разрешатся
во фрейме `js.stripe.com`, и если Stripe не пересчитывает их от адреса CSS — 404, узнаем только на web-dev
после мёржа.

Вместо п. 4 `005`:

- `build_fonts.py` пишет рядом с `fonts.css` второй выход — список лиц Hanken для Elements:
  `src/features/pay/config/stripe-fonts.json` — `{ family, path, weight, unicodeRange, display }` на каждое
  лицо (латиница + el/bg, веса 400/500/600/700). Один генератор — `fonts.css` и список не расходятся.
- `features/pay`: `fonts: [{ family, src: \`url(${origin}${path})\`, weight, unicodeRange, display }]`,
  `origin` — `window.location.origin`, сборка списка — чистая функция в `lib/`, вызов — в `model/`
  (`ui/` только передаёт готовое). `STRIPE_FONT_CSS` удаляется.
- Тест (п. 7 `005`): `stripe-fonts.json` = лица Hanken из `fonts.css` (семейство, файл, вес, диапазон);
  `--check` сборки тоже его сверяет.
- CORS на `/fonts/` остаётся: файлы грузятся во фрейме Stripe.

## Проверка манора — добавлено

- DevTools → Network внутри фрейма Stripe (шаг оплаты и ряд кошельков): woff2 с нашего домена, 200, без
  ошибок CORS.
