# AURAT-0213-003 — Understand

Date: 2026-11-12

Третий режим старта пополнения картой — `ui: 'elements'`: та же Checkout Session с
`ui_mode: 'elements'`, чтобы веб сам рисовал шторку из Stripe Elements (кошельки, выбор валюты, шаг
карты). Деньги, вебхук, сверка, статус, отмена — без изменений; тела `hosted` и `embedded` — байт в
байт. Плюс контракты `v0.34.0` и, по решению владельца, лимит частоты старта на пользователя — веб
будет создавать сессию заранее (открытие шторки, смена длительности).
