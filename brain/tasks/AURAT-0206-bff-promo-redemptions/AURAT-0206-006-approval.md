# AURAT-0206-006 — approval

Дата: 2026-11-11. **Одобрено** владельцем («Да, в работу») после правок по ревью:

1. Определение «Сессий после» было неверным («оплаченные целиком промо-кредитом»): промо —
   кредит на балансе, сессия на нём списывается как обычно; `costMinor = 0` даёт только скидка
   первой сессии / кампании. **Решение владельца: только оплаченные** — `status <> CANCELLED AND
   costMinor > 0`.
2. «Позже погашения» для сессии — `sessions.createdAt` (бронь), не `startsAt`.
3. Удалённые аккаунты в сводке «Сессий после» не считаются (сессии отвязаны, проводки у
   бесплатной нет) — подпись «без удалённых» под карточкой.
4. Пейджер ведёт на якорь `#redeemers`.
5. К сведению (без изменений): ролей нет — контакты видит любой оператор; возвращённые стором
   пополнения в «Пополнили после» засчитываются — конверсия чуть завышена.

Спека обновлена: Status `in-progress`, раздел «Решение владельца».
