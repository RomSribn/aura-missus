# AURAT-0218-011 — Ревью кода манора: три правки

Дата: 2026-11-18. `manor-8e`: блокирующих нет, код совпадает со спекой v2. lint, `tsc -b` и vitest
(126 файлов, 2032 теста) у манора зелёные.

1. **Имя компонента.** `TermsConsent` совпадает с типом `TermsConsent` из `@aura/contracts`, а этот тип
   придёт в ту же фичу в части B. Переименовать: `TermsAgreement`; подсказку — по смыслу.
2. **`card-choice.tsx`:** IIFE `const body = (() => { switch … })()` внутри рендера → вынести
   в отдельный компонент или именованную функцию.
3. **Повтор логики.** Связка «`!card.agreed` → `disabled` + `describedBy` + подсказка» повторена в
   `CardChoice`, `ChoiceBody` и `PaymentBody` → собрать в один хук `{ locked, hintId, describedBy }`.

Принято без правки: 404 видна только после отметки (в проде `VITE_PSP_ENABLED=false` прячет
карточную часть целиком).
