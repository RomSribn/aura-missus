# AURAT-0153-005 — spec (approved 2026-11-02)

Тип: задача (без новой фичи), часть `AURAF-0020` (вход по телефону на вебе).

## Что делаем

Страна, с которой открывается выбор, определяется по порядку; берётся первая страна, куда можно
отправить SMS (`SMS_REGIONS`):

1. Номер, на который код уже отправлен (кнопка «change») — как сейчас.
2. **Часовой пояс браузера** → страна по таблице `config/time-zone-regions.ts`. В таблице только
   пояса 35 SMS-стран из IANA `zone.tab` и их старые имена (`Europe/Kiev`, `America/Indianapolis`, …).
   Пояс другой страны (например, `Europe/Moscow`) не даёт ответа, и проверка идёт к шагу 3.
3. Регион локали из `navigator.languages` — как сейчас.
4. Испания (`DEFAULT_COUNTRY`) — как сейчас.

Почему часовой пояс раньше локали: в браузере регион локали часто пустой или стоит `en-US`
по умолчанию, а часовой пояс почти всегда совпадает со страной, где человек живёт.

## Код

- `features/auth-by-phone/config/time-zone-regions.ts` — новая таблица «IANA-пояс → `CountryCode`»,
  только для `SMS_REGIONS`, с комментарием об источнике. Тест: каждая страна из `SMS_REGIONS` есть в
  таблице хотя бы одним поясом, и в таблице нет стран вне `SMS_REGIONS`.
- `lib/countries.ts`: у `preferredCountry` новая сигнатура `({ timeZone, locales })`, функция
  остаётся чистой; тесты на каждый шаг порядка.
- `model/use-phone-step.ts`: читает `Intl.DateTimeFormat().resolvedOptions().timeZone` с защитой
  (`try` / `undefined`).
- Строк нет → переводы не нужны. Контракт и BFF не меняются.

## Согласование с приложением (`AURAT-0152`)

Порядок источников надо держать одинаковым на двух сторонах. Таблицу поясов кладём в приложение
тем же списком: Hermes отдаёт `resolvedOptions().timeZone`. Решение записывается в brain до мёржа,
и сессия `AURAT-0152` его перенимает.

## Не делаем

IP-геолокацию (нужны BFF и contracts, отдельная задача) и запоминание страны в `localStorage`
(в приложении такого нет).

## Проверка

`lint`, `typecheck`, `test`, `build` в slave-1. В маноре: открыть вход в Chrome с переопределённым
часовым поясом (DevTools → Sensors → Location: Berlin / Kyiv / Moscow) — выбор открывается на
DE / UA / (локаль или ES).
