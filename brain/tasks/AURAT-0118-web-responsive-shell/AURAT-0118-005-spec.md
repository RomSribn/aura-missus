## Что делаем

### 1. Скролл при переходе (NAVIGATION §0) — `app`

Поведение:

| Переход | Скролл |
|---|---|
| Новая страница — ссылка, кнопка, таб, `navigate()` (PUSH / REPLACE, другой `pathname`) | наверх |
| Back / Forward (POP) | туда, где человек был на этой записи истории |
| Внутри страницы — фильтры и сортировка (`?cat=` …), `?id=` сессий, `?book=1`, запись диалога в history, `/chats` → свежий тред на desktop (тот же экран) | не трогать |
| С якорем (`/#ask` из Get started) | не трогать — к полю Ask скроллит сама `features/ask-question` |

Как: хук `usePageScroll()` в `app/layouts/app-layout/` (вызывается из `AppLayout`). Позиции —
в памяти по `location.key`, пишутся пассивным слушателем `scroll` (так позиция уходящей страницы не
теряется, даже если новая короче); применяются в `useLayoutEffect` — до отрисовки, раньше пассивных
эффектов страниц. `history.scrollRestoration` не трогаем (перезагрузку восстанавливает браузер).
Почему не `ScrollRestoration` React Router: он сбрасывает наверх при каждой новой записи истории,
включая внутристраничные смены URL (их ~20 мест), — пришлось бы помечать каждое
`preventScrollReset` и помнить об этом в каждой будущей задаче.

Ограничение: при Back на страницу, чьи данные кэш уже выбросил (RTK Query, 60 с без
подписчиков), страница сначала короткая — позиция обрежется. Не лечим.

### 2. Безопасная зона iPhone и запас под панели — `shared/config/tokens.css`, `app`, `pages/chats`

- Токены: `--tabbar-h` — реальная высота таб-бара без отступа (меряется по CSS: 6 + таб 44+ + 6 +
  граница); новые `--tabbar-space: calc(var(--tabbar-h) + env(safe-area-inset-bottom))` и
  `--actionbar-space` — то же для панели профиля (`--actionbar-h` — её реальная высота вместо 220px).
- `app-layout.module.css`: `main` резервирует `--tabbar-space`; толкаемый экран — `--actionbar-space`
  **только если у него есть панель**; без панели — только безопасную зону.
- `route-handle.ts`: `pushed` по-прежнему прячет таб-бар; новый флаг `actionBar` — экран держит
  фиксированную панель (профиль советника). `/checkout` (страница подтверждения оплаты, панели нет)
  — `pushed` без `actionBar`.
- `chats-page.module.css`: высоты списка на телефоне — от `--tabbar-space`.
