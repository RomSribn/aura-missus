# AURAT-0118-023 — Фон под открытой шторкой не прокручивается

Date: 2026-10-21

## Слова владельца

> сделай теперь так же, чтобы при открытой модалке нельзя было скроллить контент который за ним

## Разбор

`useModal` ставит `body { overflow: hidden }` — iOS Safari касанием всё равно прокручивает страницу.
`body { position: fixed }` (другой привычный способ) сломал бы подол — он стоит в координатах страницы
(`018`). Взят способ `body-scroll-lock` / `react-remove-scroll`: отменять жест, а не фиксировать страницу.

## Сделано

- `shared/lib/use-modal.ts`: пока диалог открыт — `touchmove` на документе (`passive: false`) отменяется,
  если между касанием и диалогом нет прокручиваемого элемента (диалог или его потомок с
  `overflow-x|y: auto|scroll` и содержимым больше коробки); два пальца (зум) — не трогаем.
- `sheet.module.css`: `overscroll-behavior: contain` у слоя (desktop прокручивает слой) и у шторки —
  докрученная до края, не передаёт прокрутку странице.
- Тесты `sheet.test.tsx` (+2): жест по странице, скриму и непрокручиваемому месту шторки отменён, по
  прокручиваемой полосе внутри — нет, двумя пальцами — нет; после закрытия страница снова прокручивается.
- Проверки: lint, typecheck, prettier — чисто; 77 / 1334 — зелёные. Коммит в ветку.
