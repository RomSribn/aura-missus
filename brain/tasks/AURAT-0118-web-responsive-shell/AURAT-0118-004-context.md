## Пробелы

1. **Скролл при переходе.** NAVIGATION §0: «→ route: navigate (push), scroll to top». В коде нет
   ни `ScrollRestoration`, ни сброса: data router без него не трогает скролл — пролистанный каталог →
   тап по плитке → профиль открывается прокрученным вниз; Back возвращает куда придётся (браузер
   восстанавливает до того, как React отрисовал прежнюю страницу). Тонкость: внутристраничные
   смены URL (фильтры `?cat=`, `?id=` сессий, `?book=1`, запись диалога в history, `/#ask` →
   снятие хеша) **не** должны прыгать наверх — поэтому стандартный `ScrollRestoration` по
   `location.key` не подходит как есть (каждая такая смена — новый ключ → наверх).
2. **Безопасная зона iPhone.** `index.html` — `viewport-fit=cover`, поэтому
   `env(safe-area-inset-bottom)` ≈ 34px. Таб-бар его в свою высоту добавляет (~60px + 34), а запас
   под него — нет: `main { padding-bottom: var(--tabbar-h) }` (72px) и высота списка чатов
   `100dvh − nav − tabbar` → низ страниц и последней строки списка чатов (~20px) уходит под
   таб-бар. Обратная сторона: толкаемые экраны резервируют `--actionbar-h: 220px` (взято из
   прототипа, где там PayActions из нескольких кнопок), а панель профиля ~75px → ~145px пустоты
   внизу; на `/checkout` (толкаемый, но без панели — страница подтверждения оплаты) запас не нужен
   вовсе.
3. **Текст GuestGate.** Сейчас — буквально README («Your chats live here · Log in or sign up»):
   заголовок по странице, абзац «Log in or sign up» один на все, кнопка «Log in». Прототип
   (`web-app.jsx` `GuestGate`) — заголовок, **строка по странице** и кнопка **«Log in or sign up»**:
   chats — «Log in to message advisors — the chat is free.», sessions — «Log in to see and manage
   your booked readings.», me — заголовок «Your profile», «Log in to manage your account and
   payments.». README и прототип не спорят (README даёт сокращение «заголовок · кнопка»), но код
   совпадает ни с одним — решение владельца (`005`, решение 1).
4. **Тесты.** `app-shell.test.tsx` проверяет gate по заголовку и кнопке, но не то, что у гостя на
   приватной странице в шапке нет баланса, бейджа и аватара, и не `/booked/:id`; скролла не
   проверяет ничего.
