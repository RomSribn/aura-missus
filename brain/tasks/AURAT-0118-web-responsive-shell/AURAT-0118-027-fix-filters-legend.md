## Диагностика

Временная плашка (только dev, не коммитилась; удалена): высота шторки 588 ↔ 538 при неизменных
`maxH` (713px), отступах, `--keyboard-inset` / `--visible-h` / `--keyboard-up` и `visualViewport`. Разница —
в теле фильтров (`filters-body` `.root`): 415 ↔ 365, хотя все его потомки на тех же местах («Reset filters»
кончается на 460px от верха шторки в обоих состояниях). В высоком состоянии `.root` на 50px выше
содержимого = 2 × (legend 15px + `margin-bottom` 10px) — WebKit при расчёте собственной высоты flex-элемента
второй раз учитывает отрисованные `<legend>` обоих `<fieldset>`; от рендера к рендеру по-разному.
Не регрессия задачи: разметка — с `AURAT-0103`; на первых скриншотах владельца (Image 18/19, до
`flex-shrink: 0`) тот же скачок ~51pt выглядел как «сжатие».

## Сделано

- `filters-body.module.css`: `.group legend { float: left; width: 100%; margin: 0; padding: 0 }` — плавающий
  legend не «rendered legend», а обычный элемент колонки (float во flex ничего не делает); отступ под ним —
  `gap` группы (10px, как был `margin-bottom`). Вид тот же. `review-sheet` — legend `visually-hidden`
  (абсолютный) — не затронут.
- Шаги `025`, `026` (предел шторки: только при наборе — видимая высота; без клавиатуры — `92svh`; без
  сжатия содержимого) остаются — они верны сами по себе, но причиной этого скачка не были.
- Тесты каталога, фильтров, шторки — 38/38; lint, prettier — чисто. Коммит в ветку.
