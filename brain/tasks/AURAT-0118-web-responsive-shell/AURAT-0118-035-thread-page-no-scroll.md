# AURAT-0118-035 — Страница не прокручивается, пока открыт тред

Date: 2026-10-21

## Слова владельца (проверка `1f4187b`, со скрином Telegram Web для сравнения)

> Поле все равно улетает вверх, потом с задержкой опускается к клавиатуре. Как будто инпут не прилеплен к
> клавиатуре, в телеграм веб все работает плавно, инпут как будто так же плавно работает вместе с
> клавиатурой в унисон. Так же, отступ при открытой клавиатуре там меньше, можно сказать что его нет

## Разбор

- Низ поля ввода у нас и у Telegram на одной высоте (≈1030–1035px на скрине) — над адресной строкой
  Safari. Под ней у Telegram — белая полоса и панель iOS ˄˅✓, отступ не читается; у нас — фон под полем.
- Движение: у Telegram `html, body { overflow: hidden; height: 100% }` — документ не прокручивается, и iOS
  поднимает поле панорамой видимой области вместе с клавиатурой. У нас документ прокручиваемый — iOS сначала
  резко прокручивает его к полю («улетает»), потом высота догоняет.

## Сделано

`chats-page.module.css` (≤ 760): `html:has(.threadOpen), body:has(.threadOpen) { height: 100%; overflow:
hidden; overscroll-behavior: none }` (проверено в сборке). Только CSS; lint, prettier, build — чисто.
Коммит в ветку.
