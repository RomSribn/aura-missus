# AURAT-0118-019 — Подол над слоем шторки

Date: 2026-10-21

## Проверка владельца (`a62f87a`)

> теперь на модалке по вводу номера все окей при первом заходе, когда кидает на модалку ввода кода, то
> клавиатура когда показывается, нет нижней заливки, все в сером фоне. так же когда мы возвращаемся
> назад, то модалка с вводом номера опять не имеет подола

## Разбор

Каждый шаг входа — своя `<Sheet>` (новый слой). Шторка, открытая при уже поднятой клавиатуре, получает
fixed-слой, который iOS рисует и ниже видимой области; его полупрозрачный скрим (`z-index` слоя 100)
лежал поверх подола (99) — серая заливка без страницы. При первом открытии iOS слой туда не рисовал —
подол был виден.

## Сделано

`sheet.module.css`: подол — `z-index: 101` (над слоем); с шторкой пересекается на 1px того же `--paper`,
указатель не перехватывает. Коммит в ветку.
