# AURAT-0118-031 — Тред чата на телефоне — во весь видимый экран

Date: 2026-10-21

## Слова владельца

> посмотри, чего когда открыта клавиатура, такой большой отступ от клавиатуры? Можно ли его убрать? И так
> же когда клавиатура сворачивается, то страница остается смещенной

## Причина

На телефоне открытый тред — часть страницы высотой `100dvh − nav`. С клавиатурой iOS прокручивает
страницу к полю ввода, но ниже поля страница кончается — поле останавливается у конца документа, под ним
пустота до клавиатуры. После закрытия iOS 26 не возвращает прокрутку (тот же баг, что со шторками).

## Решение владельца

«Тред во весь экран» (вопрос с двумя вариантами; второй — оставить шапку сайта, менее надёжно).

## Сделано

- `chats-page.module.css` (≤ 760): `.threadOpen` — `position: fixed`, `bottom: var(--keyboard-inset)`,
  `height: var(--visible-h)`, `z-index: 40` (над шапкой сайта 20, под диалогами 100). Шапка треда (назад,
  советник, бронь) сверху, сообщения прокручиваются внутри, поле ввода — на клавиатуре.
- `use-visible-viewport.ts`: принимает элемент (корень страницы чатов появляется после данных — ref на
  монтировании пуст) и опцию `fullScreen` — при закрытии клавиатуры (видимая высота растёт) окно
  возвращается к началу, если iOS оставил его прокрученным. Экспорт из `@/shared`. `Sheet` — элемент
  через `useState`.
- `use-chats-page.ts`: элемент корня — `useState`, хук работает, пока открыт тред; в UI сеттер
  отдаётся отдельно (`bindRoot`) — правило `react-hooks/refs` иначе считает весь объект страницы ref'ом.
- Тесты хука (+2): `fullScreen` — `scrollTo(0, 0)` при закрытии клавиатуры; шторка — без прокрутки.
- Проверки: lint, typecheck, prettier — чисто; полный прогон 77 / 1336 — зелёный. Коммит в ветку.
