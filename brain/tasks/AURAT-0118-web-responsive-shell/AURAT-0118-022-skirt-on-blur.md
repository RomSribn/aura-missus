# AURAT-0118-022 — Подол прячется при потере фокуса

Date: 2026-10-21

## Слова владельца

> да, прячь подол при потере фокуса

## Сделано

- `use-visible-viewport.ts`: `--keyboard-up` (1 / 0) на элементе — `focusin` на поле, которое поднимает
  клавиатуру (textarea, input кроме button/checkbox/radio/…, contenteditable) → 1; `focusout`, если фокус
  уходит не в такое поле (Done на клавиатуре, кнопка) → 0; переход к следующему полю — без изменений.
  При открытии — 1, если поле внутри уже в фокусе (следующий шаг входа с `autoFocus`).
- `sheet.module.css`: высота подола × `var(--keyboard-up, 1)` — исчезает сразу при потере фокуса, не
  дожидаясь `resize` от iOS. Без анимаций.
- Тесты хука (+2): фокус в поле → 1, к следующему полю → 1, на кнопку → 0; шаг с полем в фокусе → 1.
- Проверки: lint, typecheck, prettier — чисто; полный прогон — зелёный. Коммит в ветку.
