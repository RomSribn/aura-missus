# AURAT-0118-030 — Fix: зум при фокусе в поле ввода чата

Date: 2026-10-21

## Слова владельца

> на странице чата, когда мы открываем клавиатуру для печати, т.е. тапаем на окно ввода текста, у нас
> зум происходит, убери этот зум

## Причина

iOS Safari приближает страницу к полю, у которого шрифт меньше 16px, когда оно получает фокус. Поле
ввода чата (`features/send-message/ui/composer.module.css` `.input`) — 14.5px.

## Сделано

- `composer.module.css` (≤ 760): `.input { font-size: 16px }`. Desktop — 14.5px, как в хендоффе.
- `maximum-scale` / `user-scalable=no` во viewport не ставим — запрет зума ломает доступность.
- Остальные поля уже ≥ 16px: Ask (16), `shared/ui/Field` (16), телефон (19) и код (скрытое поле 16) входа,
  отзыв (`font: inherit` от `body` — 16).
- Тесты чата и отправки — 13/13; lint, prettier — чисто. Коммит в ветку.
