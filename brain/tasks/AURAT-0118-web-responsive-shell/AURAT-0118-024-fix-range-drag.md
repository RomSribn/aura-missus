# AURAT-0118-024 — Fix: ползунок цены в Filters снова тянется

Date: 2026-10-21

## Слова владельца

> почему-то сломалась прокрутка рейнджа цен в модалке фильтров на странице advisors, грани не доступны
> для зажатия пальцем, т.е. drag

## Причина

Регрессия `ce85736` (`023`): блокировка отменяла `touchmove` везде, где нет прокрутки, а ползунки цены —
два `<input type="range">` (`features/advisor-filters/ui/filters-body.tsx`), чьи ручки iOS тянет теми же
`touchmove`.

## Сделано

- `use-modal.ts`: `scrollsInside` → `takesDragInside` — жест пропускается и по `input[type=range]` внутри
  диалога (браузер тянет ручку, страница не прокручивается). Других своих drag-обработчиков в коде нет
  (поиск `touch-action` / `onPointerMove` / `onTouchMove` пуст).
- Тест `sheet.test.tsx`: жест по ползунку внутри шторки не отменяется.
- Проверки: lint, typecheck, prettier — чисто. Коммит `1d60727` ушёл до конца полного прогона (ошибка в
  цепочке команд): в том прогоне упали `booking.test.tsx` «/checkout leads to the draft’s sheet…» и
  `psp.test.tsx` «a reload of the return page…» — таймауты ожидания шторки (5–10 с) при load average ~55
  на машине; оба файла отдельно — 30/30, затем два полных прогона подряд — 77 / 1334 зелёные. Тесты на
  касания эти сценарии не трогают.
