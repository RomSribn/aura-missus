# AURAT-0118-034 — Тред: без задержки и белая полоса под адресной строкой

Date: 2026-10-21

## Слова владельца (проверка `e0f30e8`)

> Как будто ничего не поменялось. Только шапка перестала прыгать, но с клавиатурой ситуация такая же.
> Удалось запечатлеть момент глитча, сразу же после открытия клавиатуры и закрытие клавиатуры работает в
> обратном порядке

Скрины: (1) сразу после открытия — поле ввода у верха экрана, ниже пусто; (2) после — поле над плавающей
адресной строкой Safari, под ней до клавиатуры — бежевая полоса.

## Разбор

- (2) Страница кончается там, где iOS 26 считает конец видимой области, — над адресной строкой. Под ней
  Safari рисует фон `body` (paper), а панель ввода белая (`--card`) — отсюда «полоса».
- (1) iOS панорамирует к полю, а высота страницы подгонялась через 100 мс (задержка для шторок) — перелёт
  и возврат.

## Сделано

- `use-visible-viewport.ts`: при `fullScreen` значения применяются сразу на каждое событие (страница не
  двигается, только кончается); для шторок задержка остаётся.
- `chats-page.module.css` (≤ 760): `body:has(.threadOpen) { background: var(--card) }` — полоса под адресной
  строкой цвета панели ввода (проверено: в сборке `body:has(._threadOpen_…)`).
- Полный прогон: дважды подряд упал `booking.test.tsx` «a short balance…» (ожидание закрытия шторки, 4 с) при
  load average ~22–25; без изменений — 1339 / 1339; с изменениями ещё два прогона — 1339 / 1339 (в одном —
  известная необработанная `_location` jsdom, была и до задачи). Хук в jsdom не работает (нет
  `visualViewport`) — путь теста не затрагивается. Lint, prettier — чисто. Коммит в ветку.
