# AURAT-0118-033 — Тред как основной чат Telegram Web A

Date: 2026-10-21

## Слова владельца (проверка `9975d77`)

> отступ есть, в отличие от телеграма, у нас когда клавиатура двигает поле ввода, мы видим большой
> отступ, а после он резко схлопывается в изначальное положение, появляется глитч. Он сдвигает как будто
> всю страницу вверх, вместе с шапкой, потом шапка опускается на место фиксированное

## Разбор

`9975d77` взял приём поиска Telegram Web A (`MiddleSearch`), а основной чат там устроен иначе: не
fixed и не двигается скриптом — высота всей страницы `--vh` = `vv.height + vv.pageTop`
(`util/windowSize.ts`, `App.module.scss`), `html, body { overflow: hidden }`. iOS сам панорамирует страницу
вместе с клавиатурой; поле ввода в конце страницы встаёт на клавиатуру. У нас fixed-тред переставлялся
через 100 мс после панорамы iOS — сдвиг всей страницы и резкий возврат.

## Сделано

- `chats-page.module.css` (≤ 760): `.threadOpen { height: var(--visible-bottom, 100dvh) }` — обычная часть
  страницы до низа видимой области (`pageTop + height`); fixed / top / z-index убраны.
- `app-layout.module.css` (≤ 760, `noTabBar` — только тред): шапка сайта скрыта (как решено в `031`),
  `main` без `min-height` — страница = тред.
- Хук без изменений: `--visible-bottom` уже был; `fullScreen` — сброс прокрутки на blur и 100 / 300 / 600 мс.
- Полный прогон 77 / 1339 — зелёный; lint, prettier — чисто. Коммит в ветку.
