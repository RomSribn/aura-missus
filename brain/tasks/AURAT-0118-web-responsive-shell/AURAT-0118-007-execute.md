## Что сделано (aura-web)

1. **Скролл при переходе** — `app/layouts/app-layout/use-page-scroll.ts`, вызывается из `AppLayout`.
   Другой `pathname` (PUSH / REPLACE) → наверх; POP → сохранённая позиция записи (нет записи — браузер);
   тот же `pathname` (параметры URL, запись диалога) или якорь (`/#ask`) → не трогаем. Позиции пишутся
   пассивным `scroll` и при входе на запись (запись без прокрутки возвращается наверх), хранятся
   последние 50 (`KEPT_POSITIONS`, дополнение владельца 2); запись, с которой открылось приложение,
   запоминается при монтировании (правка владельца на ревью). Применяются в `useLayoutEffect` — до
   отрисовки и до эффектов страницы (якорь `#ask` скроллит после).
2. **Безопасная зона и запас под панели** — `tokens.css`: `--tabbar-h: 60px`, `--actionbar-h: 72px`
   (было 72 / 220), новые `--tabbar-space` / `--actionbar-space` (+ `env(safe-area-inset-bottom)`).
   Таб-бар и панель профиля — `min-height` по ним (таб: `line-height: 14px`, чтобы высота была
   известна). `main`: таб-бар → `--tabbar-space`; толкаемый → только безопасная зона; с панелью —
   `--actionbar-space`. Флаг маршрута `actionBar` (`route-handle.ts`, `hasActionBar`) — у профиля
   советника; `/checkout` — `pushed` без него. Список чатов на телефоне — от `--tabbar-space`.
3. **GuestGate** (решение 1 = A) — `guest-gate.tsx`: строка `gate.pages.<page>.text`; namespace `app`:
   `gate.cta` = прежний перевод «Log in or sign up» (`gate.text` удалён), `gate.pages.*.text` — новые,
   `gate.pages.me.title` = «Your profile» (перевод взят из `me-page:title` каждого языка). 24 языка.
4. **Тесты** — `use-page-scroll.test.tsx` (8): новая страница сверху; `/chats` → `/chats/:id` — тред
   сверху, не со скроллом списка (дополнение владельца 1); параметры URL и диалог — без скролла; якорь —
   без скролла; Back / Forward — на место; запись без прокрутки, в том числе первая, — наверх (перед Back —
   `mockClear`, чтобы не засчитать прежний вызов; без запоминания при монтировании тест падает — проверено);
   помнятся 50, старшая — браузеру.
   `app-shell.test.tsx`: гость на `/chats`, `/chats/:id`, `/sessions`, `/booked/:id`, `/me` — заголовок,
   строка, кнопка; в шапке нет баланса, бейджа и Profile при замоканных «есть» (и контрольный тест, что
   вошедшему они видны); немецкий — новые строки. `vitest.setup.ts` — заглушка `window.scrollTo` (jsdom).

## Ограничения (не лечим в этой задаче)

- **«Show more» в каталоге.** Сколько страниц по 24 раскрыто — состояние компонента
  (`use-advisors-page.ts`, `useState`), не URL. Back из профиля на `/advisors` монтирует каталог заново
  с первыми 24 — страница короче, сохранённая позиция обрежется у её низа, а не у плитки, с которой
  ушли. Лечится числом страниц в URL / `sessionStorage` или бесконечной прокруткой (бэклог 014–016).
- **Узкий экран: свой скролл у списков.** Хук ведёт только скролл окна. На телефоне список `/chats`
  прокручивается внутри своего блока (`.list`, `overflow-y: auto`, высота от `--tabbar-space`) — Back
  из треда возвращает список к его началу. Так же — тред (свой скролл, прижат к низу) и колонки на
  desktop (список, рейл).
- **Данные, выброшенные из кэша.** Back на страницу, чьи данные RTK Query уже выбросил (60 с без
  подписчиков): сначала короткая страница — позиция обрежется.
