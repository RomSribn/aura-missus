# AURAT-0118-036 — Тред не подгоняется под клавиатуру (как Telegram Web K)

Date: 2026-10-21

## Слова владельца (проверка `3ee60e4`)

> Все так же. Мб проблема именно в шапке, которая фиксед? Давай попробуй просто шапку прибить к верху,
> чтобы она тоже съезжала на верх, как в телеграме

## Разбор

В треде шапка не `sticky` / `fixed` — «прибитой» её делала подгонка высоты страницы под видимую область
(`--visible-bottom`) на каждом событии: шапка оставалась на месте, поле ввода догоняло клавиатуру после её
анимации.

## Сделано

`chats-page.module.css` (≤ 760): `.threadOpen { height: 100dvh }` — тред на один экран, высоту под
клавиатуру не меняем; iOS панорамирует всю страницу (шапка уезжает вверх) вместе с клавиатурой, поле ввода
остаётся на ней (как Telegram Web K). Хук на странице чатов остаётся ради сброса прокрутки на blur
(`fullScreen`) и `--keyboard-up` для отступа под композером. `html` / `body` без прокрутки, фон `--card` — как
в `034`, `035`. Lint, prettier — чисто. Коммит в ветку.
