## Как (веб)

1. **Порт пополнения обобщается.** Сейчас `settleTopUp` после зачисления всегда бронирует. Станет:
   зачисление ждётся отдельно, а что делать после — задаёт цель. Цели три:
   - `book` — бронь тем же ключом (как сейчас, поведение Book не меняется);
   - `topUp` — ничего, готово;
   - `extend` — продление тем же ключом.
   `useCardCheckout` принимает цель вместо `PayAttempt`. Сессия Stripe, debounce 300 мс, 429,
   истечение, запись попытки только при `confirm` — как сейчас.
2. **Запись попытки (`pending-store`) знает цель.** Старая запись без цели читается как `book`.
   `/checkout` после банка: `book` — как сейчас; `topUp` — экран «Balance topped up»; `extend` —
   решение 4. Back из банка (`041`) для пополнения: из bfcache — на `/checkout` как шаг назад, как Book.
3. **Шторка пополнения** — диалог `topup` в `features/pay` (`TopUpSheet`, `useOpenTopUp`). Сумма
   меняется → новая сессия Stripe, старая закрывается (как смена длительности в Book). BFF ответил 404
   (оплата выключена на BFF) → строка «Top up in the Aura app».
4. **Продление** собирается слоем выше двух фич — новый виджет `widgets/extend-sheet` (как
   `widgets/book-sheet`). `features/extend-session` отдаёт модель и части шторки, `features/pay` —
   форму. Ключ:
   - попытка продления (ключ, минуты, `endsAt` до) сохраняется до `confirm` Stripe;
   - Stripe отказал → попытка снимается, ничего не списано;
   - зачислено → `extend` тем же ключом; ответ потерян → блок заперт, как сейчас (`AURAT-0114`);
   - сессия кончилась, пока платили → шторка не закрывается молча: «The session has ended. $X is on
     your balance.» и Done.
   Окно второго списания при «Choose another block» — как принято в `AURAT-0114-007`, без изменений.
   Блок, которому не хватает больше $120, выключен, как сейчас.
5. **Шапка:** `BalanceChip` получает часть «Top up» (кнопка) — её собирает `app`. Профиль —
   `BalanceCard` с кнопкой.
6. **Строки** (24 языка): шторка пополнения (заголовок, подзаголовок, текущий баланс, сумма для
   экранного чтеца, готово, новый баланс, Done, «в приложении» при 404), Top up в шапке и профиле,
   `/checkout` для пополнения и продления, шторка продления после зачисления, новый `tooMuch`.
   Уходят: `me-page` `balance.topUp`, `payments.card`, `payments.applePay`.
7. **Тесты** (Vitest, мок Stripe как в `AURAT-0212`):
   - шторка пополнения: сумма → сессия; смена суммы → новая сессия и `cancel` старой; кошелёк →
     «Balance topped up»; отказ карты → текст Stripe; 404 → строка приложения; без флага — нет кнопки;
   - продление: блок дороже баланса выбирается; оплата → `extend` тем же ключом; отказ → попытка
     снята; потерян ответ `extend` → блок заперт; сессия кончилась → «on your balance»;
   - `/checkout`: запись `topUp` и `extend`; старая запись без цели — бронь;
   - Book без изменений (существующие тесты зелёные).
