# AURAT-0111-003 — Understand

Дата: 2026-10-20

1. BFF: `GET /v1/sessions/:sessionId` — одна своя сессия (чужая/несуществующая — 404), ответ
   той же DTO, что в списке; за `BillingEnabledGuard`. Нужен вебу (`AURAT-0110`, Booked после
   перезагрузки и `/sessions?id=`) вместо списка до 100.
2. `@aura/contracts` — новый тег после `v0.22.0`, только добавления: схема ответа маршрута +
   два комментария (правило повтора `AURAT-0109` у брони/продления; `PUT` вместо `POST` у
   `EnsureConversationResponse`). BFF поднимает тег сразу, веб — в `AURAT-0110`, приложение —
   не обязано.

Вне задачи: пагинация списка, коды причин (025), событие кошелька (027), «вопрос» (028).
