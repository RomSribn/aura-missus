# AURAT-0181-006 — review спеки v1 + решения владельца

Дата: 2026-11-07. Ревью — координатор (slave-1-ac), две линзы (android-platform-native, js-integration-migration-tests),
17 замечаний (2 major), владелец: «Передавай все». Все приняты; v2 — `AURAT-0181-007-spec-v2.md`.

## Решения владельца (через координатора)

- **1 — А**: на Android 13+ выбор хранит системная настройка языка приложения (`LocaleManager`); Profile → Language
  пишет туда же. Поправка формулировки: обещание восстановления из бэкапа снято (`allowBackup="false"`) — выбор
  остаётся на телефоне и теряется при переустановке, как с файлом сейчас.
- **2 — А**: пункт «Язык» в настройках Android — только вместе с флагом `AURA_I18N_ENABLED`.
- **3 — А**: список языков в настройках постоянный; язык, выключенный сервером, — приложение на английском, настройка
  не трогается. Поправка: назвать побочный эффект (нативные меню остаются на выключенном языке).
- **iOS — отдельная задача `AURAT-0190`** (выдана координатором, не запущена, на самый конец). 0181 закрывается после
  мёржа Android-части; строка `AURAF-0023-007` при закрытии делится: Android ✓ / iOS ✗ (`AURAT-0190`).
