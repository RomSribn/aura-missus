# AURAT-0174-005 — spec: подписи советников на языке экрана (приложение)

Дата: 2026-11-07 · Статус: **draft — ждёт одобрения владельца**
Фича: `AURAF-0023` строка 011 · Сервер: `AURAT-0173` (закрыта, контракты `v0.29.0` с тегом) · Цифры и места — `004`.

## Что получится

- Сменил язык — каталог советников перечитывается: тип и специализации на списке, на Home, в профиле, на брони и в
  сессии приходят на новом языке без перезапуска. Пока ответ не пришёл, на экране старый каталог (не пустой список).
- В строке списка советников цена видна всегда; длинный тип обрезается многоточием, а не выталкивает цену.
- Глоссарий v3: el «психик» — «Διορατικός / Διορατική» (было «μέντιουμ», как medium).
- Приложение стоит на контрактах v0.29.0.

Новых строк UI нет — переводить нечего.

## 1. Каталог перечитывается при смене языка

- `catalog-store.ts`: `load(force = false)` — как `daily-card-store.ts`. Без `force` — как сейчас (общий запрос).
  С `force` — новый запрос даже при идущем; счётчик `latest` растёт с каждым запросом, ложится только последний
  (`started === generation && asked === latest`); `finally` снимает `inFlight`, только если это он. Ответ на старом
  языке, пришедший до нового или после, не публикуется; провал старого запроса — тоже.
  Поколение (`generation`) остаётся про смену пользователя: оно сбрасывает каталог в пустой, а смена языка — нет.
- `use-advisor-catalog-sync.ts`: второй `useEffect` — `onLanguageChange(() => { if (uid.current) load(true) })`,
  как `use-daily-card-sync.ts`. Вышел — ничего не просит.
- Тесты: store — опоздавший старый ответ (пришёл после нового / до нового) не ложится, старые советники видны во время
  перечитывания, провал старого не ставит `error`, без `force` запрос общий (как было); sync — смена языка при входе
  → `load(true)`, без входа — ничего.

## 2. Тип и цена — раздельно

**Список (`AdvisorRow`)** — тип и цена двумя `Text` в одной строке (`flexDirection: 'row'`): тип
`numberOfLines={1}` + `flexShrink: 1`, цена « · $x/min» — `flexShrink: 0`. Разделитель « · » у цены, чтобы не
пропадал. Обрезка типа: при 393 pt — только lt и ro (192 / 184 при 179), при 412 — ничего; при 360 — большинство
неанглийских и английский «Astrologer · Card Reader» на 1 pt. Сейчас вместо этого обрезается цена.

**Бронь (`BookSessionScreen`)** — там справа звёзды, и на тип остаётся мало (`004`, таблица):

- **А (как в заглушке)** — так же, двумя `Text` в строке. Цена видна, тип — 63 / 96 / 115 pt: даже английский
  «Psychic Reader · Medium» (141) режется до «Psychic…».
- **Б (рекомендую)** — тип своей строкой, цена строкой ниже. Тип — 130 / 163 / 182 pt (английский влезает с 360,
  переведённые — с 393 почти все), цена видна всегда; карточка выше на одну строку (~16 pt). Со скидкой без изменений:
  там цены в строке и так нет (она справа, вместо звёзд).

Место для тестов: `textContent` экранов — «Dream Interpreter · 1,99 $/Min.» станет двумя узлами; проверки
переписываю на тип и цену отдельно.

Остальные места типа (`TopAdvisorRow`, `SessionHero`, `BookReviewScreen`, `AdvisorHero`) — тип один в строке с
`numberOfLines={1}`, цены рядом нет. Не трогаю.
