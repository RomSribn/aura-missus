## Что получится

- Сменил язык — каталог советников перечитывается: тип и специализации в списке, на Home, в профиле, на брони и в
  сессии приходят на новом языке без перезапуска. Пока ответа нет, на экране старый каталог, а не пустой список.
- Перечитывание не удалось — повтор сам на фокусе экрана советников и при возврате в приложение.
- В списке цена видна всегда, длинный тип обрезается многоточием. На брони тип и цена — две строки.
- Поиск советника не требует диакритики: «διορατικη», «ταρο», «ekstrasense», «clarvazatoare» находят своё.
- Глоссарий v3: el «психик» — «Διορατικός / Διορατική». Приложение стоит на контрактах v0.29.0.

Новых строк UI нет — переводить нечего.

## 1. Каталог при смене языка — `entities/advisor/model/`

**`catalog-store.ts`**
- `load(force = false)`. Без `force` — общий запрос, если идёт; **на готовом каталоге обычный `load()` спрашивает
  снова**, как сейчас (на это полагаются повтор в `use-advisors` и `use-write-review`; `ready`-короткое замыкание
  daily-card не копирую). С `force` — новый запрос даже при идущем.
- Счётчик `latest` растёт с каждым запросом; ложится только последний: `started === generation && asked === latest`.
  `generation` остаётся про смену пользователя (сброс в пустой); смена языка каталог не опустошает.
- `finally` снимает `inFlight`, только если это он — сегодня `finally` запроса, начатого до `reset`, обнуляет
  `inFlight` следующего, и третий `load()` шлёт лишний запрос (`007` п. 4а).
- Вытесненный запрос (`!current()`) резолвится `inFlight ?? state.advisors`, а не старыми советниками: тот, кто ждал,
  получает каталог, который ляжет (`ensureLoaded()` пуша). После `reset` `inFlight` — `null`, это пустой каталог.
- **Язык последнего запроса:** `latestLanguage` — `null`, пока запрос ждёт `i18nReady()`, затем язык, на котором он
  ушёл (`currentLanguage()` после `i18nReady()`, как в `http-client`). Новый метод `followLanguage(language)`:
  ничего, если последний запрос ещё ждёт i18n или ушёл на этом языке; иначе `load(true)`. Так холодный старт с
  сохранённым языком делает один запрос, а не два (`007` п. 1).

**`use-advisor-catalog-sync.ts`**
- `onLanguageChange(language => { if (uid.current) advisorCatalog.followLanguage(language) })`. Вход ещё не известен
  (`undefined`) или выход — ничего.
- `AppState` `active`: вошёл и `status === 'error'` → `load()`.

**`screens/advisors/model/use-advisors.ts`** — `useFocusEffect`: `status === 'error'` → `load()`.
**`screens/write-review/model/use-write-review.ts:96`** — `load(true)`: рейтинг после отзыва не берётся из запроса,
ушедшего до него.

**Тесты** (`catalog-store.test.ts`, новый `use-advisor-catalog-sync.test.tsx`, `use-advisors`):
- старый ответ пришёл после нового / до нового — не ложится; новейший упал первым, старый успешен — старый не ложится,
  `status` `error`, советники прежние;
- во время перечитывания на экране прежние советники; вытесненный `load()` резолвится ответом принудительного;
- обычный `load()` / `ensureLoaded()` при идущем принудительном делят его; `load()` на готовом каталоге спрашивает снова;
- `reset()` посреди запроса → новый `load()` → старый завершился → следующий `load()` делит запрос (а не третий);
- `followLanguage`: запрос ждёт i18n — ничего; тот же язык — ничего; другой — `load(true)`;
- sync: вход, потом `'initialized'` с сохранённым языком — ровно один запрос и один каталог; смена языка при входе —
  перечитывание; вход неизвестен или выход — ничего; `AppState` `active` при `error` — повтор, при `ready` — нет;
- `use-advisors`: фокус при `error` — повтор, при успехе типы на новом языке.

## 2. Тип и цена — раздельно

Цена — местная: `formatUsdMinor(price, language)` + `t('shared:price.perMinute')`. Ширины цены (замер ревью, 13 pt):
en « · $3.20/min» 69,6; hu « · 3,20 USD/perc» 95,9; lt 93,5; bg 92,3; da 91,9; hr / it / pl / ro / sk 90,4.

**Список (`AdvisorRow`)** — тип и цена двумя `Text` в одной строке (`flexDirection: 'row'`): тип `numberOfLines={1}`
+ `flexShrink: 1`, цена « · …» — `flexShrink: 0`, разделитель у цены, чтобы не пропадал. Обрезка типа с местной ценой
(замер ревью): при 412 pt — lt и ro; при 393 — 13 ролей в 11 языках (bg cs da el hr it lt×2 nl pl×2 ro sk); при 360 —
большинство переведённых, английский на пределе. Сегодня вместо этого пропадает цена.

**Бронь (`BookSessionScreen`) — Б (`006`).** Без скидки: тип — своя строка (`numberOfLines={1}`, 130 / 163 / 182 pt
при 360 / 393 / 412), под ним цена `${formatUsdMinor(…)}${perMinute}` **без** ведущего « · » и **без**
`numberOfLines` — при крупном шрифте переносится, а не обрезается (`007` п. 9). Карточка выше на одну строку ≈ 19 pt
(12,5 × 1,5); аватар и звёзды по центру. Со скидкой — как сейчас: тип один, цена справа вместо звёзд.

| место | под тип при 360 / 393 / 412 pt | самые длинные типы |
|---|---|---|
| `AdvisorRow` (13 pt), цена в строке | 216 − цена: en ≈ 146 / 179 / 198; с ценой 90–96 pt ≈ 120–126 / 153–159 / 172–178 | lt 192, ro 184, nl 178, pl / et 176, it 174 |
| `BookSessionScreen` (12,5 pt), Б | 130 / 163 / 182 | en 141, lt 184, ro 177 |
| ~~`BookSessionScreen`, А~~ — не выбрано (`006`) | ~~63 / 96 / 115~~ | |

Тесты экранов: проверки «Dream Interpreter · 1,99 $/Min.» переписываю на тип и цену отдельно; бронь — цена своей
строкой без « · ».

Остальные места типа (`TopAdvisorRow`, `SessionHero`, `BookReviewScreen`, `AdvisorHero`) — тип один в строке,
`numberOfLines={1}`, цены рядом нет. Не трогаю.
