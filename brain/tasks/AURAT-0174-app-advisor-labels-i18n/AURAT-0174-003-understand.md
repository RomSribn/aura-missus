# AURAT-0174-003 — understand

Сервер теперь отдаёт тип и специализации советника на языке запроса. Приложение должно: (1) перечитывать каталог при
смене языка так, чтобы опоздавший ответ на старом языке не лёг поверх нового; (2) показывать тип и цену так, чтобы
длинный переведённый тип не прятал цену; (3) поднять глоссарий до v3 (el psychic «Διορατικός / Διορατική»);
(4) закрепить тестом поиск по переведённому типу; (5) встать на контракты v0.29.0 (`topics`). Новых строк UI нет.
