по полу персоны; новое поле `Advisor.topics: AdvisorCategory[]` (контракты `v0.29.0`, тег — с одобрения владельца).

переведёнными сразу после выкатки сервера.

## Что нужно

1. **Каталог перезапрашивается при смене языка.** `entities/advisor/model/catalog-store.ts` поднимает `generation`
   только при сбросе, `model/use-advisor-catalog-sync.ts` перезагружает только при смене uid. Подписать каталог на
   `onLanguageChange` (`shared/lib/i18n/on-language-change.ts`, образец — tarot `use-daily-card-sync.ts`): поднять
   поколение и перезагрузить, чтобы опоздавший ответ на старом языке не лёг поверх нового. Тест гонки.
2. **Тип и цена — в два `Text`** в `AdvisorRow` и `BookSessionScreen`: сейчас строка `${role} · $x/min` одна, и
   переведённый тип выталкивает цену в многоточие (английский уже 217 pt из 216). Обрезается тип, цена видна всегда.
   Проверить по таблице ширин 0173 самые длинные типы по языкам.
3. **Глоссарий v3:** el `psychic` → «Διορατικός / Διορατική» (в v2 было «μέντιουμ» = el medium, и у персон выходило
   «Μέντιουμ · Μέντιουμ»). Поднять `version`, пройти по el-строкам приложения, где psychic взят из глоссария, и
   поправить; веб берёт глоссарий копией по `version` (`AURAT-0175`).
4. Поиск `screens/advisors/lib/filter-advisors.ts` (`${name} ${role}`) ищет по переведённому типу — так и нужно,
   отметить в тесте.
5. Контракты: пин на `v0.29.0`, когда тег будет на GitHub (`topics` приложению не обязателен, но пины держим вровень).
   В типе `Advisor` (`z.infer` — выходной тип) `topics` обязательное: `.default([])` делает его необязательным только
   на входе. Поэтому вместе с пином — `topics: []` в общий `BASE` фикстур (`src/test-support/advisor.ts:8`), иначе
   тесты не скомпилируются (ревью кода `0173`).
6. Новые строки, если появятся, — на 24 языках.
