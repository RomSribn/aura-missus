# AURAT-0116-008 — Fix: Back с Review стирает выбор

Date: 2026-10-21

Ревью владельца по `007`: при возврате фокуса `use-book-session` зовёт
`booking.refreshAvailability()`, а он всегда сбрасывает `startsAt` и `startNow`. Выбрал 15:00 →
Review → «назад» (глянуть другую длительность) → выбор пропал, хотя слот свободен.

Решение владельца — вариант (а): на focus перечитывать сетку, но выбор снимать, только если
слота нет / он больше не свободен в новом ответе или `instantAvailable` стал false. Добавить
тест на Back без ошибки. `refreshAvailability` (сброс после 409) остаётся как есть — его зовёт
Reschedule.
