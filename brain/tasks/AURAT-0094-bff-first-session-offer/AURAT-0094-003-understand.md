# AURAT-0094-003 — understand

Первая платная сессия нового клиента списывается за 50% (клиент платит
`floor(subtotal/2)`), а не со скидкой −$5. Оффер возвращается, если первая сессия
отменена с полным возвратом (≥24 ч). `GET /v1/wallet` сообщает приложению, активен
ли оффер (`firstSessionOffer: { active, pct }`) — тем же предикатом, что и бронь.
Продление — по полной цене; деск («Trial») не трогаем; барьер пополнения $10 — не
здесь. Сначала выпускается `@aura/contracts` v0.21.0 (одно опциональное поле), затем
BFF переезжает на него. Поля и смысл — один в один с тем, что уже разбирает
приложение (`AURAT-0093`).
