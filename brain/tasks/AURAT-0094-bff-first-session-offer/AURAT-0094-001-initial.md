# AURAT-0094-001 — BFF + контракты: first-session offer −50%

Дата: 2026-10-17
Статус: **заведена**, исполнение — `aura-bff-manor`
Репозитории: `aura-bff` (+ `aura-contracts` → **v0.21.0**)
Фича: `AURAF-0017` (одобрена владельцем 2026-10-17). Парная app-задача — `AURAT-0093`.

## Что сделать (по спеке `AURAF-0017`, разделы «Контракт» и «Сервер»)

Контракты v0.21.0 (только аддитивно, поля опциональные):
- `WalletResponse.firstSessionOffer?: { active: boolean; pct: number }`;
- описание `SessionPricing.blocks[].creditMinor` → «скидка первой сессии»
  (имя поля сохраняется ради выпущенных сборок).
- `offerPct` в pricing и `discountMinor` в `Session` — **не нужны** (уточнено
  в `AURAT-0093-008`: приложение выводит их из уже существующих полей).

BFF:
- `session-policy.ts`: плоские 500 → `FIRST_SESSION_DISCOUNT_PCT = 50`;
  `cost = floor(subtotal × 50 / 100)`, `discount = subtotal − cost`
  (округление в пользу клиента).
- Хранение прежнее (`sessions.creditMinor` = скидка, `costMinor` = списано),
  без миграций.
- Право: нет сессии с `creditMinor > 0`, **кроме отменённых с полным возвратом**
  (`refundedMinor = costMinor`) — решение владельца 2026-10-17, замещает
  «кредит при отмене не возвращается» (`AURAT-0023`). Проверка — внутри
  транзакции брони под локами, как сейчас; `GET /v1/wallet` и pricing — тот же
  предикат.
- Продление — по полной цене (как сейчас).
- Деск: чип «Trial» не трогать (решение владельца).
- Переписать тесты с захардкоженными 500; README/OpenAPI.

Приложение (`AURAT-0093`) уже разбирает `firstSessionOffer` локальным расширением схемы
и переедет на `@aura/contracts#v0.21.0`, когда тег появится — поля и их смысл
должны совпасть один в один.
