# AURAT-0148-003 — understand

Приложение рисует сезон из `GET /v1/app-config` в пяти местах `SEASONAL.md` (hero на Home, билет
на месте `CouponTicket`, орб на сплэше, баннер Daily ritual, активный таб) плюс частицы в hero —
по палитре из 17 токенов, без знания `preset.id`. Без сезона всё как сейчас. Код мест должен
попасть в сборку ~15.11: что не в сборке, без релиза не появится. Попутно — кэш конфига, шторка
кода с подставленным кодом (из hero, билета и пуша `promo`), и подписи скидки в брони по
`SessionPricing.blocks[].discount` вместо «−50% First Session» при скидке кампании.
