# AURAT-0148-020 — частицы в hero падают непрерывно (решение владельца)

Дата: 2026-11-01. Владелец проверил сборку на A50 («все работает») и попросил: снежинки в hero падают по
кругу всё время, а не один проход при заходе на экран. Меняет `SEASONAL.md` §6 / §7 («single pass ≤ 12 s,
never loops»).

- `SeasonParticles`: первый вход — с прежним разбросом 0–5.2 с; дальше каждая частица падает заново
  сразу после приземления, в своём ритме (`Animated.sequence([delay, Animated.loop(timing)])`, native driver).
- `useReplayOnFocus(play, { stopOnBlur: true })` — петля останавливается, когда Home уходит с экрана, и
  начинается заново при возврате (не крутится на невидимой вкладке). Билет — без изменений (только фокус).
- Reduce Motion / «Убрать анимации» — частиц нет, как и было.
- Тест: при уходе с экрана — стоп, при возврате — снова; `tsc` ✓, `eslint` ✓, jest 158 / 1162 ✓.
- Пересобран staging-APK, установлен на A50.

Для веба (`AURAT-0149` / `0151`) — то же решение владельца, если он захочет одинаково: отдельной задачей.
На устройстве добавить: A50 — падение кадров при непрерывном снеге (Home открыт минуту).
