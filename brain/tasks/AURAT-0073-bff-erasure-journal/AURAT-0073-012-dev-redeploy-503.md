# AURAT-0073-012 — После Redeploy `bff-dev` не отвечает

Дата: 2026-09-16

Владелец внёс `ERASURE_JOURNAL_*` в Coolify `development` и сделал Redeploy.

## Что видно снаружи (19:52, curl из слота)

| Адрес | Ответ |
|---|---|
| `https://bff-dev.aura-app.cc/health` | **503 `no available server`** — три раза подряд |
| `https://bff.aura-app.cc/health` (прод) | 200 |
| `https://chat.aura-app.cc/` | 200 |

`no available server` — ответ заглушки Coolify: хост `bff-dev` сейчас не
обслуживает ни один контейнер (`AURAS-0004`). Значит, в `010` я ошибся: старая
версия dev **не** осталась работать. Либо деплой ещё идёт, либо новый
контейнер не стартует, а старый уже снят.

Доступа к серверу из слота нет (ни SSH-алиаса, ни прав по правилам слота).
Причину видно только в Deployment Logs в Coolify. По `AURAS-0004` их надо
читать сразу: у неудачного деплоя Coolify удаляет контейнеры и сеть.

## Дальше

Ждём от владельца статус деплоя и хвост лога. Прод и Chatwoot не затронуты.
