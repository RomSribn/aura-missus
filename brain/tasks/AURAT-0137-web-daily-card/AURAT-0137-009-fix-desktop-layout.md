# AURAT-0137-009 — правка ревью: широкий десктоп для `/daily`

Дата: 2026-10-25

## Замечание владельца

«мобильная версия хорошая, давай продумаем более широкую версию для десктопа, которая следует лейауту общему».
Предложены два каркаса (AskUserQuestion). Выбран «Плюм на всю ширину» (рекомендованный): плюм под шапкой во всю ширину, контент в общей `.wrap`, сцена рядом со столбцом слов 400px — как у `/advisors/:id`.

## Сделано

- `pages/daily/ui/daily-page.tsx`: сцена и слова собраны в `.scene` → `RitualStage` и `.words`. В `.words` лежат строка фазы, потом раскрытие и футер с CTA. Разметка для телефона не изменилась.
- `pages/daily/ui/daily-page.module.css`:
  - Десктоп (база, ≥ 901px):
    - `.column` шириной `--wrap`.
    - `.scene` — сетка `minmax(0, 1fr) 400px` с зазором `--s48`, по вертикали по центру.
    - В столбце слов всё выровнено влево: строка фазы, имя (42px), слова карты, дата и «Chat is free to start».
    - CTA стоит в столбце и не прилипает.
  - `≤ 900px`: прежняя колонка 440px по центру.
  - `≤ 760px`: как было, CTA прилипает к низу.
- `pages/daily/config/ritual.ts`: `DESKTOP_HERO_CARD_WIDTH = 240` и `DESKTOP_STAGE_ZOOM = 240 / 176`.
- `pages/daily/ui/ritual-stage.*`: на десктопе вся сцена рисуется крупнее через `zoom: var(--stage-zoom)`; до 900px `zoom: 1`. Геометрия веера и ходы те же, что в приложении, просто крупнее: карта 240px, карты ритуала примерно 98px.
- Загрузка и ошибка остаются по центру над сценой.

Проверки:
- `tsc -b`, `npm run lint` и `npm run build` — зелёные.
- `npm test`: 87 файлов, 1529 тестов, зелёный.
- Два предыдущих прогона уронили `booking.test.tsx › a short balance…` по таймауту при load average около 40. Отдельно этот тест проходит, следующий полный прогон тоже чистый. Карту дня тест не трогает.
