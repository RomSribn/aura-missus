# AURAT-0191-003 — understand

Дата: 2026-11-07

Владелец хочет в бэкофисе переводить тексты своей кампании с английского на 23 языка новой ИИ-интеграцией
(`AURAT-0192`), а потом — переписку в чате (`AURAF-0024`). Эта задача — фундамент для обоих: модуль `translation` в BFF
с нейтральным портом `Translator` (DI), чтобы провайдера и модель можно было сменить конфигурацией, «не только CLAUDE».

Что входит: порт и его доменные типы; адаптеры off / fake / claude (`@anthropic-ai/sdk`); выбор по env при старте и запрет
fake в проде; thinking; учёт денег в USD по `usage`; месячный бюджет и предохранитель с уведомлениями в Telegram; копия
глоссария. Порт должен с первого дня обслуживать короткие тексты интерфейса с ограничениями (место, лимит длины,
плейсхолдеры, форма кнопки, капс), а не только реплики чата.

Чего не входит: конвейер чата, контракты, UI, бэкофис кампании (`AURAT-0192`), eval. Без ключа, без платных вызовов.
Спека → ревью координатора → одобрение владельца → код.
