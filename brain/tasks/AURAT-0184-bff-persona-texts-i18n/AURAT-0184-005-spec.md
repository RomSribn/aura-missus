# AURAT-0184-005 — spec: слоган, био и приветствие персон на языке запроса

Дата: 2026-11-07 · Статус: **draft — ждёт одобрения владельца** (спеку проверит координатор `slave-1-ac`)
Фича: `AURAF-0024` строка 004, `AURAF-0023` строка 011 · Образцы: `AURAT-0171` (колода), `AURAT-0173` (подписи).
Репо: `aura-bff` (+ JSDoc `aura-contracts` — решение 3). Факты и места в коде — `004-context.md`.

## Что получится

- `GET /v1/advisors?lang=de` → у каждого советника `tagline`, `bio` и `greeting` по-немецки, вместе с уже
  переведёнными `role` и `specialties` (`0173`). `name`, цена, рейтинг, отзывы, `topics` — без изменений.
- Без `lang`, с неизвестным кодом или выключенным языком — английский, как сейчас.
- Клиенты уже шлют `?lang` и перечитывают каталог при смене языка (`0174` / `0175`), поля те же — **код клиентов не
  меняется**. Слоган (только веб), био (профиль) и пузырь-приветствие в начале чата приходят на языке интерфейса.
- Чаттеры видят английский: профиль советника в `agent-desk` и Chatwoot не меняются.
- Английские тексты в сиде не трогаю (био — дословно от владельца).

## 1. Приветствие и язык разговора (решение 1)

Заглушка исходила из того, что приветствие — первое сообщение треда на сервере. **Это не так:** на сервере
приветствие есть только в каталоге. Приложение и веб рисуют из `advisor.greeting` пузырь только в интерфейсе: его нет
в истории, в Chatwoot он не уходит, чаттер его не видит (`use-chat-thread.ts` в обоих клиентах). Значит, пузырь
показывается на языке, на котором прочитан каталог, то есть на языке интерфейса. На нём же человек и пишет.

- **А (рекомендую).** Приветствие переводится по `?lang` вместе со слоганом и био. **Точка подключения к
  `AURAI-0012`** — чистая функция `localizeAdvisor(advisor, language)` (§3): переводы зависят от пары (персона, язык),
  а не от запроса. Если исследование заведёт язык разговора и решит, что приветствие идёт за ним, а не за языком
  интерфейса (например, ответ треда с приветствием или настоящее первое сообщение в Chatwoot), оно вызовет эту же
  функцию с языком разговора. Переводы остаются на месте. Для стола чаттера — английский оригинал из базы.
- **Б.** Приветствие остаётся английским до `AURAF-0024`. Тогда переводы приветствий лягут в код неиспользуемыми
  (правило 8 — «no dead code»), поэтому их пришлось бы делать позже, отдельной задачей. Человек видит профиль на
  своём языке, а первый пузырь чата — по-английски.

## 2. Когда выкатывать (решение 2)

До конвейера перевода чата (`AURAF-0024`) чаттеры отвечают по-английски. После выкатки `0184` человек с немецким
интерфейсом читает немецкие профиль и приветствие, а ответ получает английский. Так уже происходит с `role`,
`specialties` и колодой. Приложение в проде этого не покажет, пока выключен флаг языков; веб покажет сразу, по языку
браузера.

- **А (рекомендую).** Выкатывать, когда готово: профиль на языке человека — смысл задачи, а разрыв закроет `AURAF-0024`.
- **Б.** Держать `0184` в `develop` и выкатить в прод вместе с переводом чата.

## 4. Перевод — правила

- **От первого лица персоны; род — по `gender`** (`0173`): прошедшее время и прилагательные о себе (pl «byłam» /
  «byłem», cs «byla» / «byl», fr «née», it «nata», ro «născută», bg «родена»…). У May био безличное, как в английском.
- **Обращение к человеку — по таблице `register`** (`AURAF-0023-glossary.md`): «вы» — bg, cs, el, fr, hr, lt, lv,
  pt, sk, sl; «ты» — остальные; pl — «Ty», «Twój», «Ciebie» с заглавной. **Без согласования с полом человека:**
  без форм, которые выдают его род (pl -łeś/-łaś, fr «prêt(e)», ro / it / es прилагательные о читателе) — обходится
  перестройкой фразы.
- **Глоссарий v3:** `psychic` (человек), `medium`, `tarot` (it «tarocchi», bg «таро», et / lt / lv «taro»); `reader`
  — советник или слово языка для таролога, **никогда** «читатель» (Olivia «Psychic Reader», Veronica «Reader &
  Healer»); `reading` — сеанс / толкование (de «Deutung», fr «consultation»), не «чтение» («30 years reading»,
  «reading professionally»). Где тип совпадает с `role` из `0173` — то же слово.
- **Смысл не добавлять и не терять.** Это слова советника о себе. Огрехи английского (смена лица, «chakra's»,
  «My goal to focus…») не переносятся в перевод: фраза звучит правильно на своём языке. Перевод не приукрашивает и
  не сокращает. Имена собственные и организации (White Eagle Lodge, Aquarian Foundation, Pleiades, Kabbalah) —
  в устоявшейся форме языка, иначе как в оригинале; «P.K.» — как в оригинале.
- У Marta вопросы клиента о партнёре — «he», как в английском: это текст владельца, перевод его не меняет.
- **Оформление:** переносы строк `\n` — там же и столько же, сколько в английском (Sunshine, Marta); кавычки — языка
  (de „…“, fr « … », pl „…”); тире и «&» — по обычаю языка (в слогане «&» можно заменить союзом). NFC; без U+00AD и
  U+02BC; ro — ș ț с запятой; fr — U+00A0 перед ? ! : ; » и после «, не U+202F.
- **Метод** — как в `0173`: de перевожу сам; остальные 22 языка — агенты, по 3–4 языка на каждого, с одним брифом
  (правила выше, род персон, обращение языка, термины `0173` этого языка). У каждого файла — прогон spec. Затем
  сверяю сам: глоссарий, обращение, род, переносы, длины, выборочно — смысл по обратному переводу. Сомнительные
  места — списком для носителей в `execute` (не блокер).

## 5. Тесты (чистые, без БД)

**Переводы, 23 языка × 8 персон × 3 поля:**
- языки — ровно 23 контракта без `en`; в каждом — ровно `id` сида, лишних нет;
- `source` по каждому полю совпадает с отпечатком текущего английского (сообщение — что перевести заново и новое
  значение);
- не пусто, без пробелов по краям, NFC, без U+00AD / U+02BC / U+202F; ro — без ş ţ (седиль); fr — перед ? ! : ; » и
  после « только U+00A0;
- `\n`: в `bio` — столько же, сколько в английском; в `tagline` и `greeting` — нет;
- не совпадает с английским (список исключений пуст — и пусть так остаётся);
- запретные формы глоссария v3 (`reader` / `reading`) — во всех трёх полях, сопоставление как в `terms.js`;
- **обращение** — однозначные формы «не того» обращения на язык: например, fr / cs / sk / lt / lv / el — без «ты»
  (tu / toi / ton; ty / tvůj; σου…), de / es / it / nl / sv — без «вы» (Ihnen / Euch; usted; jullie / u…), pl — без
  строчных ty / twój / ciebie и без -łeś / -łaś. Это страховка, не замена вычитке; точные списки — в коде;
- **род, выборочно:** pl — у женских персон нет «-łem» о себе, у мужских нет «-łam»; исключения — списком;
- длины: `tagline` ≤ 90 знаков (английский до 58, две строки в `MatchCard` на вебе), `greeting` ≤ 320 (до 210),
  `bio` ≤ 1,6 × английского этой персоны. Строк по ширине — в таблице `execute`.

**Код:**
- `localizeAdvisor`: `en` — как в базе; `de` — все пять полей переведены; `id` без перевода → тексты английские,
  подписи — по словарю;
- `advisors.service.spec`: `list('de')` — `tagline` / `bio` / `greeting` немецкие (у Olivia — женский род, у Ivan —
  мужской, по фразе-маркеру); `list('en')` — как сейчас;
- цепочка сид → `advisorUpsert().create` → `toRecord` → `toDto('de')` (`advisors.seed-chain.spec.ts`) — тексты
  переведены;
- desk — английский, существующие тесты.
- `npm run lint`, `typecheck`, `build`, `test`.
