## Что нужно

1. **Слоган и био** 8 персон (`src/modules/advisors/advisor-seed.data.ts`) — на 23 языках, в коде, как колода
   (`AURAT-0171`) и подписи (`AURAT-0173`): файл на язык, `Record` по персонам, отдача по `?lang` в `AdvisorsService.toDto`;
   неизвестный язык / выключенный — английский.
2. **Текст от первого лица**: род — по `gender` персоны (`AURAT-0173`), обращение к человеку — по таблице обращения
   языка (`AURAF-0023-glossary.md`), без согласования с полом человека; глоссарий v3 (`psychic`, `medium`, `tarot`, запрет
   reader / reading); смысл не добавлять и не терять — это слова советника о себе.
3. **Приветствие** — переводы готовятся здесь же, но первое сообщение треда создаётся на языке **разговора** — его
   хранение появится по итогам `AURAI-0012`. До этого приветствие остаётся английским; договориться о точке подключения.
4. Тесты: полнота (каждая персона × язык), NFC, ro ș ț, fr U+00A0, длины для мест показа (профиль, Home), совпадение
   с английским — только по списку; ширины — таблицей для клиентов, как в `0173`.
5. Клиентам ничего делать не нужно: они уже шлют `?lang`; поля те же.
