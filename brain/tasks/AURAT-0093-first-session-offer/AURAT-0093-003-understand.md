# AURAT-0093-003 — Понимание

Дата: 2026-10-17

Владелец меняет приветственную механику: вместо кредита $5 на первую сессию —
**скидка 50% на всю первую платную сессию** (любая длительность, любой
советник), применяется автоматически, без кода. Сервер (BFF) — источник истины:
отдаёт признак оффера пользователю и сам переоценивает сессию при оплате.

В приложении — по дизайну `OFFER.md`: зачёркнутая коралловой линией обычная
цена + акционная рядом (список советников, профиль, бронирование, ревью,
приглашение в чате), чип «−50%», купон-тикет «50% OFF First Session» с иконкой
`percent`/`sale` в шите бронирования и тизер на списке/профиле, «You save $X»,
плашка «You saved» после брони. Когда оффер израсходован — всё возвращается к
обычному виду.

Задача кросс-репозиторная: `aura-app` (этот манор, slave-0) + `aura-bff`
(исполнение в `aura-bff-manor`, контракт фиксируется в спеке `AURAF-0017`).
