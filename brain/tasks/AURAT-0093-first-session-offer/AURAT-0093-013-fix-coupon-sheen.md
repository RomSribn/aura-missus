# AURAT-0093-013 — фикс: блик купона — диагональ, а не горизонтальная полоса

Дата: 2026-10-17

## Замечание владельца (устройство)
В дизайне анимация — беловатое свечение по диагонали; у нас вместо этого ещё
какое-то горизонтальное свечение от левого до правого края.

## Причина
Источник истины — веб-прототип (`prototype/offer.jsx`, `tokens.css`):
`linear-gradient(105deg, transparent 35%, rgba(255,255,255,.65) 50%,
transparent 65%)`, `translateX(-120% → 120%)`, `1.1s` с задержкой `.35s`,
параллельно с `pop-in` (только `scale(.97 → 1)`).

RN-порт дизайнера (`rn/AuraOffer.tsx`) перевёл угол как
`start {0.35, 0} → end {0.65, 1}` — в растянутом единичном квадрате это
градиент почти сверху вниз, т.е. **горизонтальная** белая полоса во всю
ширину. Мы взяли его как есть. Плюс два наших расхождения с прототипом:
`pop-in` с прозрачностью `0.6 → 1` и блик строго после `pop-in`.

## Исправление (`CouponTicket.tsx`)
- `Sheen` — SVG-градиент в пикселях купона (`gradientUnits="userSpaceOnUse"`),
  линия градиента строится по правилам CSS для угла (`cssGradientLine`):
  через центр, длина `|w·sin α| + |h·cos α|`. Полоса 35–65 %, белый `.65`
  в середине (через `stopOpacity` — react-native-svg теряет альфу цвета стопа).
- Ход — `±1.2 × ширина` купона (было константой `±420`).
- `pop-in` — только масштаб; блик стартует через 350 мс, параллельно.
- Токен `theme.gradients.couponSheen` → `theme.offer.couponSheen
  { angle: 105, color, opacity: .65, from: .35, to: .65 }`; импорт `Gradient`
  из `CouponTicket` ушёл.

ней приглушён). tsc / eslint / jest — зелёные. Staged.
