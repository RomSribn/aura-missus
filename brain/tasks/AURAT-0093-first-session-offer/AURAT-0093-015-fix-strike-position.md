# AURAT-0093-015 — фикс: красная линия не по центру зачёркнутых цифр

Дата: 2026-10-17

## Замечание владельца (internal testing, versionCode 26)
Серые зачёркнутые цифры: красный прочерк не по центру цифр.

## Причина
Линия стояла на `top: '52%'` текстового блока. У Hanken Grotesk над цифрами
большой запас (ascent шрифта выше заглавных), середина блока на устройстве
оказывалась у базовой линии — снято крупно со скриншота (профиль, Per min).

## Исправление (`PriceTag.tsx`)
- Зачёркнутая цена — подкомпонент `Struck`: по `onTextLayout` линия ставится на
  `baseline − capHeight/2` (baseline = `line.y + line.ascender`; на Android
  RN берёт capHeight по глифу «T», на iOS — из шрифта), за вычетом половины
  толщины линии. Не зависит от шрифта, размера и `lineHeight`.
- До первого layout — середина блока (`strikeMiddle`, 50 %).

## Тесты

`StyleSheet.flatten` (стиль теперь массив).
