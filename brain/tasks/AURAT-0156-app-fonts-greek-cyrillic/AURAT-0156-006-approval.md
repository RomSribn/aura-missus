# AURAT-0156-006 — approval: решения приняты, спека — на правки

Дата: 2026-11-04.

## Решения владельца

1. **Донор — Commissioner.** Он нейтральнее; Geologica заметно геометричнее («ж», «ф»). Manrope и Plex не
   дотягивают до 800.
2. **Болгарские формы — обычные.** Зашитые формы перекрасили бы русский и украинский текст в чате.
3. **Хинтинг — без нового,** но только если латиница сохраняет свой хинтинг (правка 1). Android — проверить в
   маноре.
4. **Греческий Hanken из апстрима** — нужен взгляд дизайнера (вторая группа алфавитов на листах).

## Спека не одобрена — правки

1. **Латиница Hanken изменится.** Это противоречит обещанию «побайтно те же глифы». У апстрима `eff37d18` нет
   хинтинга (у нашего — `fpgm`/`prep`, ~427 глифов с инструкциями) и нет `grek` в GPOS.
   - Предложение владельца: база — наш нынешний Hanken (положить в `sources/`, как Bricolage), из апстрима
     пересадить только греческие глифы.
   - Либо явно записать, что латиница меняется.
2. **Кернинг: формулировку «дописан в kern» уточнить.** Таблицы `kern` нет, кернинг живёт в GPOS. Пары
   регистрировать под `cyrl` и `grek` (у Bricolage сейчас только `DFLT` и `latn`), иначе у кириллицы и
   греческого не будет кернинга даже у двойников.
3. **Папка `samples/` нарушает именование brain** (brain-guard). PNG положить прямо в папку задачи как
   `AURAT-0156-sheet-*.png` и сжать (сейчас ~2,5 МБ).
4. **Самоназвания в тесте дублируют `AURAT-0158`,** а их буквы уже входят в наборы CLDR. Отдельную проверку
   убрать.
5. **Воспроизводимость:** зафиксировать время в `head` (`recalcTimestamp=False`) и порядок глифов.
6. Мелочи:
   - скрипта `npm run typecheck` нет — проверять через `npx tsc --noEmit`;
   - U+2010 / U+2011 убрать из `FORBIDDEN` в `translations.test.ts`; U+00AD остаётся запрещённым.

Дальше: правки в прототипе с проверкой, затем новая редакция спеки (`007`) на одобрение.
