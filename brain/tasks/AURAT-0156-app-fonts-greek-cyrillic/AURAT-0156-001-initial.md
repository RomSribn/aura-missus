# AURAT-0156-001 — initial

Дата: 2026-11-04. Контекст: `aura-app-manor` slave-0, ветка `feature/AURAT-0156-app-fonts-greek-cyrillic` от
`develop` @ `40d0ee7` (ветку завёл диспетчер; сессия — через `wts-run`).

Владелец: «запускай 1b и 1c параллельно на слейвах и другие задачи одновременно».

Диспетчер: это шаг **1c** фичи `AURAF-0023` — греческий (el) и болгарский (bg) фирменными шрифтами. Основание:
`AURAI-0010` §3 и решение владельца 4; доказательства — `AURAI-0010-evidence.json` (тема `fonts-glyphs`).
Решение владельца: дорисовать глифы при сборке под теми же PostScript-именами, без изменений в JS:
- Hanken Grotesk — греческий из апстрима (marcologous/hanken-grotesk `eff37d18`, community, без хинтинга —
  нужно одобрение дизайнера);
- кириллица для обоих семейств и греческий для Bricolage — из донора; донора выбирает дизайнер по образцам
  (кандидат Commissioner, ещё Manrope, Geologica, IBM Plex Sans; Golos и Onest без греческого);
- воспроизводимый скрипт fontTools в репозитории, боевое качество (прототип из `AURAI-0010` терял GDEF и
  хинтинг), U+202F для французского;
- тест покрытия el/bg в `src/shared/config/__tests__/fonts.test.ts`;
- OFL: RFN не объявлено, менять файлы с прежними именами можно — зафиксировать в спеке.
Образцы для выбора донора — до финальной сборки. Проверка рендера — в маноре (iOS и Android).
