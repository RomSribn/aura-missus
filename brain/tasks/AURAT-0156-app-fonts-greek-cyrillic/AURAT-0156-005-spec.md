# AURAT-0156-005 — spec (draft)

Тип: задача фичи `AURAF-0023`, шаг 1c, пункт `AURAF-0023-006`. Только `aura-app`. JS и `fonts.ts` не меняются.
Основание — `AURAI-0010` §3, решение владельца 4; замеры и прототип — `004-context.md`.

## Что видит пользователь

Греческий и болгарский текст (экраны, чат, самоназвания «Ελληνικά» / «Български» в листе языка) рисуется
Bricolage и Hanken во всех семи начертаниях: без Helvetica посреди слова и без схлопывания 600/800 в Bold.
Латиница и всё остальное — побайтно те же глифы, метрики и кернинг, что сейчас.

## Что меняется

1. **Скрипт сборки — `scripts/fonts/`** (Python, запускается руками, не в CI и не в `npm`):
   - `build-fonts.py` — порт прототипа из `004` (подбор wght/масштаба/ширины по штриху, двойники, композиты,
     кернинг, GDEF, `cyrl`/`grek`, OS/2, notices); пишет 7 TTF в `src/shared/assets/fonts` и
     `android/app/src/main/assets/fonts`, обновляет sha1 в обоих `link-assets-manifest.json`;
   - `requirements.txt` с точными версиями (fontTools, uharfbuzz, skia-pathops);
   - `sources.json` — откуда что берётся, с sha256:
     - Hanken — `marcologous/hanken-grotesk@eff37d18` `fonts/ttf/*.ttf`;
     - донор — `google/fonts@bbda7253`;
     - качается в `scripts/fonts/.cache/` (в `.gitignore`), хэш не сошёлся → ошибка;
   - `sources/` — нынешние 4 файла Bricolage как исходник (466 КБ в репозитории, в приложение не попадают):
     скрипт никогда не читает собственный выход, повторный запуск даёт тот же результат побайтно;
   - `README.md` — зачем, как запустить, как обновить Hanken, когда google/fonts #11159 примут.
2. **Шрифты.** 7 TTF пересобраны:
   - Hanken — апстрим `eff37d18` (греческий) + кириллица донора + U+2009 / U+202F;
   - Bricolage — свой + греческий и кириллица донора, π — донорский;
   - оба — U+2010 / U+2011 → свой дефис.
   Покрытие: кириллица U+0400–045F и Ґ ґ (bg + русский/украинский/сербский в чате), греческий монотонический.
   Имена (PostScript, family), hhea, usWeightClass — прежние; в name ID 5 дописано `Aura el-bg <донор>`,
   в name ID 0 — copyright донора.
3. **Лицензии.** `OFL-<Donor>.txt` рядом со шрифтами. `OFL-HankenGrotesk.txt` сверить с апстримом.
4. **Тест — `fonts.test.ts`.** Свой чтец `cmap` / `hhea` / `name` на Node `Buffer` (~60 строк, без зависимостей):
   - каждое лицо покрывает буквы CLDR 48.2 (main exemplars, обоих регистров) всех 24 языков — строки
     зашиты в тест, генерирует их `scripts/fonts`; защита латиницы от регресса при пересборке;
   - каждое лицо покрывает U+202F, U+00A0, U+2212 и 24 самоназвания (в `languages.ts` их пока нет — лист
     языка `AURAT-0158` возьмёт тот же список);
   - PostScript-имя (name ID 6) каждого файла = имя файла;
   - `NATURAL_LINE` = `(ascent − descent + lineGap) / upm` из файлов;
   - OFL донора лежит рядом;
   - копии в `android/…/fonts` побайтно равны `src/…`.
5. **Правила.** Строка в build rules (раздел Translations): «el/bg — собранные шрифты, `scripts/fonts`; новый
   символ вне покрытия — тест `fonts.test.ts` упадёт, добавить его в сборку».

## Решения владельца (нужны до кода)

1. **Донор.** Рекомендую **Commissioner**:
   - ближе всего к Hanken по x-height;
   - спокойный рисунок рядом с Bricolage;
   - +69 КБ.
   Geologica — равноценная по весам, но шире и геометричнее (заметно в «ж ф ш» и «β δ ζ»). Manrope и IBM Plex
   не дотягивают до 800 (штрих −15…−18% и −4,5%) — не советую. Образцы — `samples/`.
2. **Болгарские формы.** Рекомендую **обычные** (верхняя строка на листах):
   - зашитые болгарские формы меняют и русский/украинский текст в чате;
   - на iOS их иначе не включить.
   Если дизайнер хочет болгарские — вариант уже собран.
3. **Хинтинг.** Рекомендую **без нового хинтинга**: старые глифы сохраняют свои инструкции, новые — без,
   +69 КБ. iOS хинтинг не исполняет. Альтернатива — ttfautohint по всем, +210 КБ, единообразно. Как Android
   рисует оба варианта — проверить в маноре.
4. **Греческий Hanken из апстрима** (community, ещё не принят Google Fonts) — на листах вторая группа алфавитов;
   нужен взгляд дизайнера.

Технические решения в спеке, которые можно оспорить:
- двойники берутся из латиницы цели;
- прописные и строчные подгоняются раздельно;
- Bricolage-исходник хранится в репозитории.

## Проверка

- Slave: `npm run typecheck`, `npm run lint`, `npx jest` (+ `fonts.test.ts`), повторный прогон скрипта —
  побайтно тот же выход.
- Манор после merge, iOS-симулятор и Android-устройство, dev-меню «i18n: next language» до el и bg:
  - лист языка (все 24 самоназвания);
  - заголовок Bricolage 800;
  - текст Hanken 400;
  - eyebrow прописными;
  - цена на fr с U+202F;
  - латинский экран до/после — без изменений.

## NOT in scope

- Греческие прописные без тоноса — правило переводчиков (`AURAT-0154`).
- Шрифты aura-web: веб остаётся на `system-ui` для el/bg; выровнять — отдельная задача, если владелец захочет.
- Полутоновый греческий (U+1Fxx), комбинируемые ударения U+0300/U+0301 с mark-позиционированием.
