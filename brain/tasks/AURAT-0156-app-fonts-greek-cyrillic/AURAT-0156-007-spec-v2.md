# AURAT-0156-007 — spec v2 (draft, по правкам `006`)

Тип: задача фичи `AURAF-0023`, шаг 1c, пункт `AURAF-0023-006`. Только `aura-app`. JS и `fonts.ts` не меняются.
Заменяет `005`. Решения владельца из `006`:
- донор — Commissioner;
- болгарские формы — обычные;
- хинтинг — без нового;
- греческий Hanken — на глаз дизайнеру.

Всё ниже проверено прототипом в scratch (`build_fonts.py`, `transplant.py`, `verify.py`) на всех 7 файлах.

## Что видит пользователь

Греческий и болгарский текст (экраны, чат, самоназвания в листе языка) рисуется Bricolage и Hanken во всех семи
начертаниях. Нет Helvetica посреди слова, 600/800 не схлопываются в Bold.

**Латиница не меняется.** Проверено на выходе по каждому файлу:
- 0 из 597 / 708 исходных глифов изменено (байты `glyf` вместе с инструкциями хинтинга, `hmtx`);
- `fpgm` / `prep` / `cvt`, hhea, порядок глифов, PostScript-имена — прежние;
- все прежние lookup'ы GSUB/GPOS — побайтно прежние;
- cmap вне блока U+0370–03FF — прежний.

Меняется только греческий блок, который и так был неполным:
- у Bricolage был только π — теперь он донорский;
- у Hanken были Δ Ω μ π, тонос, ano teleia — теперь все из апстрима, чтобы греческое слово было однородным.
Старые глифы остаются в файле: на них по-прежнему ведут µ U+00B5 и прочие латинские коды.

## Что меняется

1. **Скрипт сборки — `scripts/fonts/`** (Python, запускается руками; не в CI и не в `npm`):
   - `build-fonts.py` + `transplant.py` — порт прототипа;
   - `requirements.txt` с точными версиями: fontTools 4.60.2, uharfbuzz 0.51.7, skia-pathops;
   - `sources/` — **нынешние 7 TTF как исходник**, база для обоих семейств (726 КБ в репозитории, в приложение
     не попадают); скрипт никогда не читает собственный выход;
   - `sources.json` — внешние файлы с sha256:
     - Hanken `marcologous/hanken-grotesk@eff37d18`, `fonts/ttf/*.ttf` — **только как источник греческого**;
     - Commissioner `google/fonts@bbda7253`, `ofl/commissioner/Commissioner[FLAR,VOLM,slnt,wght].ttf`;
     - качаются в `scripts/fonts/.cache/` (в `.gitignore`); хэш не сошёлся → ошибка;
   - воспроизводимость:
     - `head` не пересчитывается (`recalcTimestamp=False`, время — из исходника);
     - порядок глифов — исходный, затем новые в порядке кодов;
     - два прогона дают побайтно одинаковые 7 файлов (проверено);
   - пишет файлы в `src/shared/assets/fonts` и `android/app/src/main/assets/fonts`, обновляет sha1 в
     `android/link-assets-manifest.json` и `ios/link-assets-manifest.json`;
   - `README.md`: зачем это, как запустить, как пересадить греческий, когда google/fonts #11159 примут.
2. **Hanken:**
   - база — наш файл;
   - греческий блок пересажен из апстрима:
     - 77 кодов, 61 новый глиф;
     - 17 греческих прописных-двойников (Α Β Ε Ζ Η Ι Κ Μ Ν Ο Ρ Τ Υ Χ Ϊ Ϋ, ;) апстрим рисует точной копией своей
       латиницы — они ведут на наш латинский глиф (сверка контуров по каждому глифу, автоматически);
     - общие с латиницей компоненты (bullet, кавычки, `uni0308`) — наши;
     - греческие компоненты с тем же именем, но другим рисунком — копия с суффиксом `.el`;
   - плюс кириллица Commissioner, U+2009 / U+202F (французский).
   Апстрим — другая сборка латиницы: совпадают контуры только 2 из 708 общих глифов, у 142 другое число точек.
   Поэтому базой он не годится — это и была правка 1.
3. **Bricolage:** база — наш файл, плюс греческий и кириллица Commissioner. Как в `005`:
   - подбор wght по толщине штриха, раздельно для прописных и строчных;
   - 49 двойников — из своей латиницы;
   - буквы с диакритикой — композиты.
4. **Оба семейства:**
   - U+2010 / U+2011 → свой дефис;
   - кириллица U+0400–045F и Ґ ґ (bg + русский, украинский, сербский в чате);
   - в name ID 5 — `Aura el-bg commissioner`, в name ID 0 — copyright Commissioner;
   - GDEF: новым буквам класс base.
5. **Кернинг — в GPOS** (таблицы `kern` в файлах нет). Новые пары — отдельный PairPos lookup, добавленный в
   фичу `kern`. В GSUB и GPOS добавлены скрипты `cyrl` и `grek` (копия `DFLT`), поэтому кириллическая и
   греческая строки получают и новые пары, и латинский кернинг двойников. HarfBuzz на выходе, единицы
   ExtraBold / Regular:
   - «То» = «To» = 65 / 95, «ТА» = 65 / 95;
   - донорские пары: «Гл» 92 / 93, «Ту» 13 / 76;
   - греческие: «Γα» 73 / 31, «Υα» 90;
   - сейчас у всех этих пар 0.
   - Hanken — пары апстрима для греческих букв (395–449 на лицо);
   - у апстрима нет кернинга для ο (это o, сдвинутая на 6 единиц): для таких пар берётся наше значение для o,
     поэтому «Το» = «To» = 95, «Υο» = «Yo» = 83, «Ρο» = «Po» = 30.
6. **Хинтинг:** не трогаем. Старые глифы сохраняют свои инструкции, новые — без них. Размер: 726 → 853 КБ
   (+127 КБ: Bricolage +18…+19 КБ на лицо, Hanken +16…+17 КБ).
7. **Лицензии:**
   - `OFL-Commissioner.txt` рядом со шрифтами;
   - OFL Hanken у апстрима тот же;
   - RFN не объявлен ни у Bricolage, ни у Hanken, ни у Commissioner — изменённые файлы под прежними именами
     OFL 1.1 разрешает.
8. **Тест — `fonts.test.ts`.** Свой чтец `cmap` / `hhea` / `name` на Node `Buffer`, без зависимостей:
   - каждое лицо покрывает буквы CLDR 48.2 (main exemplars, оба регистра) всех 24 языков; строки зашиты в
     тест, генерирует их `scripts/fonts`; это защита латиницы при пересборке и покрытие самоназваний;
   - каждое лицо покрывает U+00A0, U+202F, U+2212, U+2010, U+2011;
   - name ID 6 = имя файла;
   - `NATURAL_LINE` = `(ascent − descent + lineGap) / upm` из файлов;
   - `OFL-Commissioner.txt` лежит рядом;
   - `android/…/fonts` побайтно равны `src/…`.
9. **`translations.test.ts`:** U+2010 и U+2011 убрать из `FORBIDDEN`; U+00AD и U+02BC остаются.
10. **Правила:** строка в build rules, раздел Translations, рядом со строками `AURAT-0155`: «el/bg — собранные
    шрифты, `scripts/fonts`; символ вне покрытия — `fonts.test.ts` упадёт, добавить его в сборку».

## Проверка

- Slave:
  - `npx tsc --noEmit`, `npm run lint`, `npx jest` (`fonts.test.ts`, `translations.test.ts`);
  - два прогона скрипта — побайтно одинаковый выход;
  - `verify` из скрипта — инварианты латиницы из раздела «Что видит пользователь».
- Манор после merge, iOS-симулятор и Android-устройство, dev-меню «i18n: next language» до el и bg:
  - лист языка;
  - заголовок Bricolage 800;
  - текст Hanken 400;
  - eyebrow прописными;
  - цена на fr с U+202F;
  - латинский экран до/после — без изменений;
  - Android: новые глифы без хинтинга рядом с хинтованной латиницей.

## Открыто

Взгляд дизайнера на греческий Hanken из апстрима — вторая группа алфавитов на `AURAT-0156-sheet-commissioner.png`.
Ответ не блокирует код: если дизайнер его отклонит, сборка возьмёт греческий для Hanken тоже у Commissioner.
Это один флаг в `sources.json`.

## NOT in scope

- Греческие прописные без тоноса — правило переводчиков (`AURAT-0154`).
- Шрифты aura-web: веб остаётся на `system-ui` для el/bg.
- Политонический греческий (U+1Fxx); комбинируемые ударения U+0300/U+0301 с mark-позиционированием.
