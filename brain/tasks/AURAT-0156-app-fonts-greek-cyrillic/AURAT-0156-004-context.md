# AURAT-0156-004 — context

Источники: `AURAI-0010` §3 и тема `fonts-glyphs` в evidence (high); `AURAF-0023`; код slave-0 @ `40d0ee7`
(ground truth); апстрим marcologous/hanken-grotesk `eff37d18`; google/fonts `bbda7253` (доноры, OFL).
Всё проверено в scratch-прототипе этой задачи (venv: fontTools 4.60.2, uharfbuzz 0.51.7, freetype-py,
ttfautohint-py 0.6.1).

## Код

- 7 TTF в `src/shared/assets/fonts`, побайтные копии в `android/app/src/main/assets/fonts`; iOS — `UIAppFonts`
  в `Info.plist` и ресурсы в `project.pbxproj` по именам файлов. Имена не меняются → эти два файла не трогаем.
- `android/link-assets-manifest.json` и `ios/link-assets-manifest.json` хранят sha1 каждого шрифта —
  обновляются вместе с файлами.
- `fonts.ts` выбирает лица по PostScript-имени; `fonts.test.ts` проверяет имена ↔ файлы и два OFL. Покрытие
  символов и метрики `NATURAL_LINE` тестами не проверяются.

## Замеры (срез на высоте x-height / прописных, доля em)

- Цели: Bricolage x-height .517–.528 (растёт с весом), прописные .660, штрих n .091 / .126 / .144 / .161
  (400/600/700/800); Hanken x-height .493, прописные .697, штрих .085 / .111 / .125.
- Апстрим Hanken `eff37d18`: Latin-метрики и штрихи совпадают с нашими до тысячной; 77 греческих кодов;
  без хинтинга, есть лишний `DSIG`, в GPOS нет скрипта `grek` (у нашего был).
- Доноры: номинальный вес ничего не говорит — нужный wght подбирается по толщине штриха. Для Bricolage 800
  нужен штрих .161: Commissioner (до 900) и Geologica (до 900) достают; **Manrope (до 800) — нет: Bold −6…−9%,
  ExtraBold −15…−18%; IBM Plex Sans (до 700) — ExtraBold прописные −4,5%.**
- У Bricolage прописные низкие (.660 против .713 у Commissioner) — масштаб для прописных и строчных нужен
  раздельный, иначе кириллические прописные торчат над латинскими на 7–8%.

## Прототип сборки (scratch `scripts/build_fonts.py`)

Решает дефекты прототипа `AURAI-0010`:
- GDEF сохраняется, новые глифы получают класс base; `cyrl`/`grek` добавлены в GSUB и GPOS;
- 49 / 30 букв-двойников (А В Е К М Н О Р С Т Х, а е о р с у х, Α Β Ε Ζ Η Ι Κ Μ Ν Ο Ρ Τ Υ Χ, ο, Ѐ Ё Ї …)
  ссылаются на латинские глифы цели — кириллическое слово наполовину остаётся фирменным;
- остальное (122 знака Bricolage, 68 Hanken) — донор с подобранными wght, x-height/высотой прописных и шириной
  (по n/o и H/O, сжатие не больше ±8%), отдельно для прописных и строчных; погрешность штриха ≤ 0,3%;
- буквы с диакритикой — композиты, знак перецентрирован над латинским двойником;
- кернинг донора для пар с его буквами — 1 300–5 200 пар на лицо, дописан в `kern`;
- π у Bricolage заменён донорским — греческое слово однородно;
- Hanken: U+2009 и U+202F (французский) с шириной по пропорции Bricolage; оба семейства: U+2010/U+2011 →
  дефис цели.

Размер: 726 КБ сейчас → 784–822 КБ без нового хинтинга (+58…+97 КБ; Commissioner +69 КБ) → 935 КБ, если
прогнать ttfautohint по всем (+210 КБ). iOS TrueType-хинтинг не исполняет; Android рисует через FreeType
с light-хинтингом — в манор-проверке сравнить.

## Болгарские формы (locl BGR)

На iOS RN не передаёт язык в CoreText — locl не включится никогда; на Android — только при болгарском языке
телефона. Единственный способ показать болгарские формы — зашить их по умолчанию (тогда и русский/украинский
текст в чате будет с ними). Собрано вариантом, на листах — нижние строки.

## OFL

RFN нет ни у Bricolage, ни у Hanken, Commissioner, Geologica, Manrope — менять файлы с прежними именами
можно (OFL 1.1, notices + OFL донора рядом). У IBM Plex RFN «Plex» — нам не мешает (имена выходных файлов
другие), но это ещё один довод против.
