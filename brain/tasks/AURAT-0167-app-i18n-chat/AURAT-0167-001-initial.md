# AURAT-0167-001 — initial

Дата: 2026-11-06. Выдана по просьбе владельца: «да, выдавай и запускай чат» — на предложение выдать и запустить
последнюю задачу шага 3. Запуск — slave-0 (`wts-run`), от `develop` @ `dc98590`.

Шаг 3 фичи `AURAF-0023` — перенос строк. Это задача «чат» из плана `AURAI-0010` § Recommendation, п. 3 — седьмая и
последняя. В develop уже есть остальное: основа i18n, глоссарий, шрифты el/bg, shared-слой, форматтеры CLDR, лист
языка, entities, вход, профиль и аккаунт, витрина, бронь и сессии, деньги (`AURAT-0154`…`0159`, `0161`…`0166`).

Проверка develop @ `dc98590` (координатор, 2026-11-06): `i18next/no-literal-string` по всему `src` и разбор строк в
`.ts` через AST. Вне четырёх слайсов ниже непереведённых строк нет — после этой задачи правило можно включать на всё
приложение (это шаг 4, не здесь).

Что входит; границы уточнить в спеке:
- **`screens/chats`:** строка списка («Chat with …», « · online», «Session live · N min left»), пустой экран
  (заголовок, подзаголовок, «Browse advisors»), «All advisors», превью «Voice message» (`lib/preview.ts`).
- **`screens/chat-thread`:** шапка, поле ввода, вложения (голос, видео, файл, плашки статусов, лист источника,
  черновик, просмотр фото), пузырь сообщения; приглашение на сессию (`config/session-invite.ts`); продление
  (`model/use-extend-checkout.ts`: «Extend · {{cost}}», «Choose a block»); быстрая бронь (`model/use-quick-book.ts`).
- **`features/chat`:** ошибки вложений — `lib/attachment-rules.ts` («That file is … — the limit is …», «Too large —
  the limit is …», «One file at a time»…) и `model/use-attachment-draft.ts` («That file could not be read.» и др.).
  Размеры — форматтером из `shared/lib` с явным языком.
- **`features/tarot-spread`:** расклад в чате — `config/copy.ts` («Your spread», «Choose a card», «You chose …»…),
  a11y «Close» в `SpreadCardViewer`.
- **Маркеры сессии** (поправка координатора 2026-11-06 — решение владельца 5 в `AURAI-0010`): в v1 их переводит
  клиент, по точному совпадению двух английских текстов BFF (точные строки — в aura-bff, где создаются системные
  сообщения сессии; тон — `toneOf` в `features/chat/lib/map-message.ts`). Неизвестный текст — показывать как есть,
  тон не ломать. Машинный `Message.marker` придёт с контрактом v0.28 (шаг 5, выдаётся параллельно); переключение на
  него — задача приложения шага 5, поэтому распознавание держать в одном месте.

Передано из `AURAT-0165` (решение владельца по ревью): тост, ошибки и CTA быстрой брони в `use-quick-book.ts`
(«No longer available — try another time.», «The price just changed — check it and confirm again.», «Start now /
Book · {{cost}}», «Choose a length») — по правилу слайсов здесь; можно взять `book-session:started`,
`review.errors.*`.

Не здесь:
- названия и ключевые слова карт таро — колода, `AURAF-0023-010` (ждёт решения владельца по артам); здесь только
  подписи вокруг них.
- перевод самих сообщений чата — вне scope фичи.

Чувствительное:
- продление сессии из чата — оплата: `@sensitive` payment; суммы — `formatUsdMinor` / `formatUsdMinorSigned`
  (решение владельца: минус U+2212 и плюс по CLDR), как в `AURAT-0166`.
- быстрая бронь: «Start now · {{cost}}» / «Book · {{cost}}» — целые строки, без склейки.

Частые находки ревью `0163`–`0166` — проверить до ревью:
- форма кнопки по языку из глоссария (cs sk lt lv fr pt es de nl — инфинитив; bg hr sl — ед. ч. повелительного;
  el hu — отглагольное существительное); a11y-подпись кнопки начинается с её видимого слова (label-in-name);
- имя в падежном месте («Chat with {{name}}») — переформулировать, чтобы имя стояло отдельно («{{name}} · …»);
- не согласовывать с полом пользователя и советника — он неизвестен;
- плюралы — все формы языка (mt, pl, sk, lt, ga…), «N min left» — через `count`;
- el для строк с `textTransform: 'uppercase'` — капсом без тонуса; fr — U+00A0 перед ? ! : ; »; ro — ș ț;
- `@max` и замер шрифтом (как в `0162-008`, `0164-007`) для узких мест: шапка треда, плашки вложений, кнопки листа
  источника, строка списка чатов;
- `translate.mjs scan … --web <aura-web>` — что из чата уже переведено на вебе.

Правила — раздел «Translations» в `.claude/aura-build-rules.md`; `i18next/no-literal-string` — на `error` для
перенесённых путей. Общие файлы (`app/i18n/namespaces.ts`, `.eslintrc.js`, `translations.test.ts`) — параллельных
задач сейчас нет.
