## Решения владельца

1. **Кнопка «вниз».** Есть непрочитанный ответ советника → кнопка с точкой видна, как только человек не в самом низу
   (смещение больше порога автодокрутки, не «больше высоты ленты»). «Внизу» — **один порог**, и для гашения точки, и
   для автодокрутки (`autoscrollToTopThreshold`). Без непрочитанного — как было, от высоты ленты.
2. **Иконка** — существующая `chev`, повёрнутая вниз, в shared `CircleButton`. Размер и токены записать; точка —
   именованный токен (teal или accent); показ / скрытие — токен MOTION.

## Важные

1. **Смена языка оставляет старые страницы на прежнем языке** (0169 вливается первой → правило пишет 0172).
   (a) Тред из одной новейшей страницы, первый `loadOlder` в полёте на старом языке: обрезать нечего, поколение не
   растёт, страница принимается. `refreshSpreads` 0169 без раскладов ставит отметку нового языка без запроса
   (slave-2 stage `ChatProvider.tsx:533-547`) — страница остаётся на старом языке навсегда.
   (b) «Тред со старыми страницами» — признак того, как пришли сообщения, а не их числа: 50 + N из сокета не
   обрежутся, а `refreshSpreads` перечитывает только новейшие 50.
   Правила: `loadOlder` запоминает язык после `await i18nReady()` (как `syncThread`, stage `:244-245`) и выбрасывает
   ответ при другом `currentLanguage()`; обрезка — по числу (> `HISTORY_PAGE_SIZE` серверных); поколение не растёт на
   перечитывании 0169 (`replaceSpreads` не добавляет и не убирает сообщения); `loadOlder` не пишет `spreadLanguages`;
   обрезка — из `onLanguageChange` на уровне провайдера, не из эффекта экрана; тест «первый `loadOlder` в полёте на
   треде из 50, язык сменился — страница выброшена»; в `0169-007:138-139` записать, что обрезка заменила
   «replaceSpreads по подгруженным страницам».
2. **«Мёртвая зона»** между ~80 (`autoscrollToTopThreshold`, v2:30-31) и высотой ленты (v2:21): mVCP держит позицию
   (`VirtualizedList.js:715-737`), новая строка уходит ниже экрана, кнопки и точки нет. Решено п. 1 владельца. Тест
   хука: смещение 300 + входящее советника → кнопка с точкой. Порог на Android — px
   (`MaintainVisibleScrollPositionHelper.kt` `getInt`, сравнение со `scrollY`; `HostPlatformScrollViewProps.cpp:123-124`
   без перевода), на iOS — pt (`RCTScrollViewComponentView.mm:1093-1116`): задать в dp и переводить
   (`PixelRatio.getPixelSizeForLayoutSize`) или записать как единицы платформы.

## Средние

3. **Поколение и запрос.** Выброшенный ответ не трогает `loadingOlder`; рост поколения сам сбрасывает состояние
   истории; флаг снимает только ответ запроса, который его поставил (токен). Иначе: опоздавший ответ снимает флаг
   нового запроса A, `onEndReached` срабатывает снова (смена длины, напр. «печатает…»,
   `VirtualizedList.js:1584-1590`), уходит B с тем же `before`, приходят одни дубли → `reachedStart` посреди истории.
   Поколение — только растущий счётчик / номер сессии, не обнуляется со сбросом ref (`ChatProvider.tsx:262-266`).
   `syncThread` и раунды дозапроса удалений проверяют поколение после каждого `await`. После выброшенного ответа
   список сам не попросит (`VirtualizedList.js:1587`; перезарядка только при выходе из порога `:1611-1612`) → если тред
   открыт, `!reachedStart`, `!olderFailed` и экран у верха — провайдер перезапрашивает сам. Тесты: страница в полёте
   через обрезку → следующий `fetchHistory` с новым самым старым id без нового `onEndReached`; ответ sync / раунда
   удалений после смены пользователя не сливается; после сброса уходит один запрос с тем же `before`, `reachedStart`
   остаётся false.
4. **Пустой тред и приветствие** (v2:70-73). Без серверных сообщений подвала нет, приветствие стоит само (ошибка
   «earlier messages» над ним — бессмыслица; `syncThread` глотает ошибку, `ChatProvider.tsx:234-236`, — иначе вечный
   индикатор). `loadOlder` на таком треде разделяет идущую синхронизацию (промис синхронизации на тред), а не
   запускает вторую (холодный старт: `:256-260`, `:274`, `:279` — три синхронизации новейшей страницы).
   `reachedStart` ставит только первый ответ без курсора в текущем поколении и только по «первая страница < 50».
   Мигание приветствия при холодном открытии длинного треда из пуша — не показывать, пока идёт первая синхронизация.
5. **Точка «есть новое» — правило в `use-thread-scroll`.** ref с id, виденными в этом монтировании; точка — когда вне
   полосы автодокрутки на новейшем конце появился невиденный id с `from !== 'me'` (решить про `'system'`). Не
   считаются: локальный → серверный id (`ChatProvider.tsx:404-406`), новейшее из-за удаления (`:213`), осадка
   AURAT-0037 (`:159-167`), старые страницы, замена раскладов 0169 (новые объекты, `replace-spreads.ts:28-36`). Тест на
   каждый случай.
6. **Диктор.** Подвал смонтирован всю жизнь треда; после `reachedStart` пустой, без a11y (иначе на последней странице
   фокус теряется). После нажатия «вниз» — фокус на новейшее сообщение (`AccessibilityInfo.sendAccessibilityEvent(ref,
   'focus')`; `setAccessibilityFocus` на Android ничего не делает, `AccessibilityInfoModule.kt:294-296`) или держать
   кнопку до конца прокрутки. Один механизм объявления (v2:117 давал оба → TalkBack дважды,
   `AccessibilityInfoModule.kt:282-291`); образец — `DraftAttachmentBar.tsx:73-94` (iOS:
   `announceForAccessibilityWithOptions(…, {queue:true})` раз на ошибку, не на смену языка; Android — live region
   только на элементе ошибки), тест-образец `ChatThread.i18n.test.tsx:200-222`. Объявлять, только пока подвал на
   экране. Тест: узел подвала переживает `reachedStart`. «VoiceOver идёт по дереву» не доказано — на устройство;
   прыжок по заголовкам в «сначала новое» читает после перехода не тот день — тоже на устройство.
7. **Тесты.** Полночь и DST проходят вхолостую: в Jest пояс не задан (`jest.config.js`, `jest.setup.js` — без TZ).
   Задать пояс с DST (`process.env.TZ = 'Europe/Kyiv'` до первого `Date`), настоящая ночь 2026-10-25, таймер в
   локальные 00:00. Против возврата ошибок первого ревью: 23:59 → после полуночи разделитель «Yesterday» (экран, не
   только хук); данные FlatList от нового к старому, разделитель сразу после самого старого сообщения своего дня;
   история и начальные строки — масштаб 1, сокет — с анимацией; страница в полёте выбрасывается после смены языка;
   шестой дозапрос удалений не уходит. Подвал и точка в тестах экрана достижимы (вход через мок auth + `fetchHistory`
   и события сокета, как `ChatProvider.test.tsx:79`); `initialNumToRender` (10) для длинных тредов. Плюс: на 24 языках
   `history.failed` начинается с `history.failedLabel` (образец `ChatThread.i18n.test.tsx:187-197`); a11y-пропсы
   разделителя, строки повтора, индикатора, кнопки (обе подписи) и объявление.
8. **Внешний вид.** Кнопка — по решению 2. Строка ошибки — стилем разделителя (11,5, по центру, ink-3, без
   `numberOfLines`, `ChatThreadScreen.tsx:347-358`); из этого `@max 70`.
