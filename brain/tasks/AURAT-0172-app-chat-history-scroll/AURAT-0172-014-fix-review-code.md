## Что изменено

1. **Перезапрос — по флагу списка и самому старому id** (`use-thread-scroll`). `onEndReached` ставит `wanted`. Когда
   история свободна: если верх сдвинулся (страница легла или тред обрезан), `wanted` снимается, и дальше спрашивает
   сам список. Если верх на месте (ответ выброшен, ошибка снята событием), хук перезапрашивает у верха. Ответ
   советника внизу верх не двигает. Тесты: ошибка → ответ → снятие → ровно один повтор; выброс → повтор; страница
   легла → не повторяет; обрезка → ждёт список; не у верха → не повторяет.
2. **Нет запроса при открытии.** Хук сам больше не начинает подгрузку — только повторяет то, о чём просил список.
   `nearTop` не считается, пока нет размера контента. Тест: `onLayout(600)` → `onContentSizeChange(700)` → ни
   одного `loadOlder`.
3. **Фокус после «вниз».** Обёртка строки убрана. `newestRef` (callback ref) идёт в доступный элемент новейшей
   строки: в `MessageBubble` — `Pressable` повтора, иначе текст, иначе время; у маркера — подпись
   (`SessionMarker` → `ThreadDivider labelRef`). В shared `Text` добавлен проп `ref` (React 19 передаёт его вместе с
   остальными). Фокус — после того, как список простоял у `offset ≤ 1` 120 мс (`JUMP_FOCUS_SETTLE_MS`); если строки
   ещё нет — до 10 попыток (`JUMP_FOCUS_TRIES`), всё это время кнопка остаётся. Расклад таро и приглашение как
   новейшая строка своей цели фокуса не имеют: после попыток кнопка просто скрывается. Проверить на устройстве, п. 8.
4. **Точка над кругом на Android** — `elevation: theme.shadows.sm.elevation`.
5. **Холодное открытие без pop-in.** Переход `firstSyncPending true → false` считается открытием (`lastSettled`).
   Тест экрана (вход, первый fetch отпущен после монтирования → у всех `popIn === false`) и тест хука на переход
   одним обновлением.
6. **`threadsRef` синхронно.** Присваивается при рендере провайдера; в `onLanguageChange` ему сразу ставится
   обрезанный тред. Тест: 70 сообщений, `reachedStart`, смена языка и `loadOlder` в одном такте → `before` = самое
   старое из оставшихся 50.
7. **`useTodayKey` перевзводится** на каждом срабатывании (`tick`); задержка ≤ 3 ч (`TODAY_RECHECK_MAX_MS`). Тест.
8. Тест провайдера: после нового поколения уходит один запрос с тем же `before`. Тесты хука — № 1.
9. Тест: раунд удалений, отпущенный после смены пользователя, тред `user-2` не меняет, и следующего раунда нет.
10. Тест «поздний день»: `setSystemTime(00:01)` без таймеров → `2026-11-08`.
11. `use-pop-in.test.tsx`: `false` → масштаб 1 и без `Animated.timing`; `true` → 0.97 и анимация; смена флага после
    монтирования не перезапускает анимацию.
12. Синхронизация, выброшенная обрезкой при той же эпохе, ставит `firstSync 'failed'` вместо вечного `'pending'`.
13. Pop-in одноразовый по времени: строка «живая» `POP_IN_WINDOW_MS` (1 с) после прихода; перемонтированная
    виртуализацией — без анимации. Тест.
14. JSDoc `layoutThread` и спека v3 (с пометкой) уточнены про перенумерацию; тест.
