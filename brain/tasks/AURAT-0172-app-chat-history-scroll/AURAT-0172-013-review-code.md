## Важные

1. **Индикатор висит без запроса** (следствие отступления 3, `use-thread-scroll.ts:243-260`). Подгрузка упала;
   пока висела ошибка, `serverCount` изменился (пришло `message.new`, своё сообщение стало серверным); затем
   `onOpen` / `AppState 'active'` снимают ошибку → эффект видит другое число и не перезапрашивает. Список тоже не
   попросит: `onEndReached` уже отработал на этой длине (`VirtualizedList.js:1584-1590`), а `minHeight` подвала не
   меняет длину при «ошибка → спиннер». Исправление: решать по самому старому серверному id, а не по числу.
   Тест: ошибка → ответ советника → `onOpen` у верха → ровно один `loadOlder`.
2. **Лишний запрос при открытии длинного треда** (`:74-89`, `:250-260`). `nearTop` защищён только от
   `viewport === 0`: `onLayout` меряет при `content = 0`, первое событие размера — только `initialNumToRender` строк.
   Исправление: перезапрашивать, только если страницу хотел сам список (флаг в `onEndReached`, снимать, когда
   страница легла); `nearTop` не считать до размера контента. Тест: `onLayout(600)` → `onContentSizeChange(700)`
   при 50 серверных → `loadOlder` не вызван.
3. **Фокус диктора после «вниз» не доходит** (`ChatThreadScreen.tsx:154`, `use-thread-scroll.ts:203-214`). Обёртка
   `<View ref>` без пропов Fabric схлопывает (`ViewShadowNode.cpp:48-76`): iOS шлёт `LayoutChanged(nil)` →
   VoiceOver на кнопку «назад» (`RCTMountingManager.mm:342-347`); Android — `RetryableMountingLayerException`
   (`SurfaceMountingManager.kt:713-723`). Недоступный контейнер фокус TalkBack и не берёт (`'focus'` →
   `TYPE_VIEW_FOCUSED`, `FabricUIManager.java:1241-1245`). Ref — на доступный элемент новейшей строки, не делая
   доступной всю строку: она склеила бы внутренние кнопки. Слать фокус после того, как прокрутка встала. Держать
   кнопку, пока ref не появится.
4. **Android: точка под кругом.** У `CircleButton` `shadows.sm` с `elevation: 2`, у точки Z = 0 →
   `ViewGroup.buildOrderedChildList` рисует круг поверх. Нужна `elevation` из токена или точка внутри `Pressable`.
5. **Холодное открытие: вся первая страница «впрыгивает»** (`:146-163`). `readThread` сливает страницу и ставит
   `firstSync 'done'` в одной фиксации → `settled` уже true, `seen` пустой → `arrivalsSince` отдаёт всё. Переход
   `pending → done` считать открытием. Тест экрана: вход, первый fetch задержан и отпущен после монтирования → у всех
   `popIn === false`; тест хука — тот же переход одним обновлением.

## Средние

6. **Устаревший `threadsRef`** (`ChatProvider.tsx:204-207` — обновление в passive effect родителя, а эффекты ребёнка
   идут раньше): на холодном открытии `loadOlder` видит пустой тред и запускает вторую синхронизацию; на смене языка
   `before` берётся по необрезанному треду → дыра или ложный конец. Обновлять синхронно (при рендере; в
   `onLanguageChange` — обрезанный). Тест: история 70, `reachedStart`, смена языка → следующий `before` = самое
   старое из оставшихся 50.
7. **`useTodayKey` застревает**, если таймер полуночи сработал в тот же день (монотонные часы Android, коррекция
   времени, смена пояса): эффект зависит только от `todayKey`. Перевзводить на каждом срабатывании; по желанию
   ограничить задержку.
8. Тест «страница выброшена обрезкой → следующий fetch без нового `onEndReached`» зовёт `loadOlder` руками. Нужны
   тест хука (обрезка во время загрузки, потом освобождение) и тест провайдера (после сброса уходит один запрос с
   тем же `before`).
9. Нет теста раундов удалений после смены пользователя: раунд задержан → `user-2` → ответ раунда не меняет тред, и
   следующего раунда нет.
10. Тест «сообщение следующего дня перечитывает `Date.now()`» не может упасть: часы стоят на 23:58. Нужно
    `setSystemTime(00:01 8-го)` без таймеров → ждать `2026-11-08`.
11. «История — в масштабе 1» проверено только пропом. Нужен тест `usePopIn`: `false` → 1 и без `Animated.timing`;
    `true` → 0.97.
