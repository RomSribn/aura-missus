# AURAT-0172-001 — initial (заглушка)

Дата: 2026-11-06
Репо: `aura-app-manor` (приложение). Выдан из `aura-app-manor` (сессия slave-1-9e) по решению владельца на спеку
`AURAT-0167-005` (п. 1 — «Today» над лентой треда).

## Слова владельца (дословно, 2026-11-06)

> «вариант с Today над тредом нужно записать в отдельную задачу, делать инфинити скролл снизу вверх, как в телеграмм
> мессенджере, когда кролл вверх подгружает сообщения более старые, делать обозначения вместо Today по дням.»

## Что нужно

1. **Лента треда как в Telegram:** открывается внизу, на последних сообщениях; прокрутка вверх подгружает более старые
   страницы истории; позиция при подгрузке не прыгает; индикатор загрузки сверху; в начале истории — без лишних
   запросов.
2. **Разделители по дням** вместо одной подписи «Today» над всей лентой (`screens/chat-thread/ui/ChatThreadScreen.tsx`,
   `ListHeaderComponent`, ~`:189`): «Today», «Yesterday», дальше — дата в формате языка (форматтеры `shared/lib`,
   `relativeDay` / `shortDateParts` из `AURAT-0159`; часовой пояс устройства). Плавающий разделитель при прокрутке,
   как в Telegram, — решить в спеке.
3. **Контракт уже есть:** `GET /v1/advisors/:advisorId/messages?before=<id>&limit=` — `HistoryQuery.before`,
   «scroll-back from the oldest visible one», страницы по возрастанию (`aura-contracts/src/chat.ts`, ~`:309-333`).
   Приложение сейчас берёт только `after` (досинхронизация) и `deletedFrom` (`features/chat/model/ChatProvider.tsx`,
   ~`:222-240`, страница `HISTORY_PAGE_SIZE` = 50). Проверить, что BFF отдаёт `before` так, как описано.
4. **Учесть:** удаления (`deletedFrom` / `deletedIds`) вместе с подгруженными старыми страницами; новые сообщения с
   сокета не сбивают позицию, пока человек читает старые; черновик и отправку; маркеры сессии и расклад таро в
   ленте; кэш треда.
5. Списки — legacy API RNGH (`LegacyFlatList`), пока RN < 0.86.2 (`.claude/aura-build-rules.md`, React Native, п. 7).
6. Новые строки — сразу на 24 языках (раздел «Translations»).

Веб — отдельно, если владелец захочет того же.
