# AURAT-0117-005 — Spec: «Now» в шторке Book aura-web

Date: 2026-10-21
Type: task (строка `AURAF-0020-006`, колонка UI; правило `AURAD-0009`). Новой фичи нет.
Status: draft — на одобрение владельцу

## Цель

В шторке Book для «сегодня» первым в ряду времени стоит **«Now»**, когда сервер отвечает
`instantAvailable === true` для выбранной длительности. «Now» оплачивается тем же путём, что слот,
и бронируется `startNow: true` без `startsAt` под тем же ключом попытки. Подтверждение — только
ответ сервера; после него человек видит идущую сессию (баннер с отсчётом из `AURAT-0114`), а не
«запланировано». BFF и contracts **не меняются** (`004`).

«Что делаем» написано по рекомендациям решений 1–7 (в конце).

## Что делаем

### 1. Выбор — `features/book-session`

- `use-book-session.ts`: `instant = availability.instantAvailable === true` (ответ — уже для
  выбранного блока; при смене блока ответа нет, пока не придёт новый — «Now» не висит от чужого
  блока). Выбор получает `startNow: boolean` рядом с `startsAt`; они взаимоисключающие.
  `selectNow()`; `selectSlot` / `selectDate` / `selectMinutes` / `clearTime` снимают «Now».
  «Now» держится, пока свежий ответ этого блока говорит `instant` (как слот держится, пока сетка
  его продаёт). В view: `instant`, `startNow`, `selectNow`; `endsAt` для «Now» — `null` (конец
  назначит сервер).
- `lib/choice.ts` (`initialChoice`): из чата (`soonest`) — «Now», если `instant`, иначе ближайший
  слот, как сейчас; первый открытый день — сегодня, если `instant`, даже когда слотов сетки
  сегодня нет. Черновик с «Now» восстанавливается, только если `instant` всё ещё true.
- `lib/draft.ts`: черновик `+ startNow?: boolean` (необязательное — старые черновики читаются).
  Ссылка `?book=1&slot=` у открытой шторки для «Now» пишется без `slot` (ссылка не несёт «сейчас»;
  перезагрузка вернёт «Now» из черновика).
- `ui/booking-form.tsx` — передаёт «Now» в пикер; `ui/booking-total.tsx` — для «Now» строка
  «Starts now · 30 min» вместо даты и интервала.

### 2. Пикер — `entities/session/ui/session-time-picker.tsx`

- Необязательный проп `instant: { selected: boolean; onSelect: () => void } | null` (Reschedule
  его не передаёт — там «Now» не бывает). Показывается, когда выбран сегодняшний день: первая
  кнопка сетки, вид и `aria-pressed` — как у слота, текст «Now», `aria-label` «Now, starts right
  away». Сегодня с `instant` не «пустой» (сетка рисуется с одной «Now»; «No times left this day»
  не показывается) и не помечен «full» в полосе дней.
- Стиль — классы слота (`.slot`, `.selected`), новых литералов нет.

### 3. Оплата — `features/pay` и `entities/session/api`

- `BookSessionArgs` и `PayAttempt`: время — `startsAt: string | null` + `startNow: boolean`
  (ровно одно); тело — `BookSessionRequest.parse({ startNow: true, minutes, idempotencyKey })` или
  со `startsAt`, как сейчас. Комментарий «веб не стартует сейчас» убирается.
- `usePay`: `ready` — выбрано время **или** «Now»; ключ попытки — по-прежнему до определённого
  исхода (`AURAF-0020-024`), смена «Now» ↔ слот его не сбрасывает; повтор после потери ответа —
  тот же ключ. Двойного нажатия нет (как сейчас).
- `lib/pending.ts` (карта, только `PSP_ENABLED`): `startsAt` nullable + `startNow` — возврат с
  hosted page бронирует «Now» тем же ключом.
- CTA для «Now» — «Start now · $X» (`CHECKOUT.md`) вместо «Confirm & pay $X»; кнопки
  пополнения (карта / кошелёк) — без изменений. Строка «Free cancellation up to 24 h before» для
  «Now» не показывается (отмены за 24 ч у идущей сессии нет); «You save $X» — остаётся.
- Отказы — как у слота: 409/400 → «That time is no longer available — pick another one.»,
  выбор снят, сетка (и `instantAvailable`) перечитаны — «Now» пропадёт, если его больше нет.

### 4. После подтверждения сервером

- Куда идти — **по сессии из ответа**, не по выбору на экране (повтор ключа может вернуть другую):
  `ACTIVE` → тред `/chats/:advisorId` на месте шторки (как приложение: Booked для моментальной
  нет), иначе → `/booked/:id`, как сейчас. Хелпер `bookedPathOf(session)` в `entities/session/lib`
  — общий для `widgets/book-sheet` и `/checkout`.
- В треде таймер даёт `AURAT-0114`: бронь уже кладёт сессию в кэш (`upsertQueryData`) и
  инвалидирует список, плюс `session.updated` с сокета — баннер появляется без новых запросов.
- Черновик тратится, как сейчас.

### 6. Тесты (Vitest)

- `lib/__tests__/choice.test.ts`: из чата с `instant` — «Now»; без — ближайший слот; сегодня без
  слотов, но с `instant` — открытый день; черновик с «Now» при `instant: false` — не восстанавливается.
- `lib/__tests__/draft.test.ts`: `startNow` читается; старый черновик без поля — тоже.
- `pay/lib/__tests__/pending.test.ts`: запись с `startNow`.
- `app/__tests__/booking.test.tsx`: «Now» первым только сегодня и только при `instant`; смена блока
  перечитывает и прячет / показывает; тело POST — `startNow: true` без `startsAt`; CTA «Start now ·»;
  `ACTIVE` → тред, `SCHEDULED` → Booked; 409 — снято, перечитано; потеря ответа → повтор тем же
  ключом; Reschedule «Now» не показывает.

## Не делаем

- BFF / contracts — не нужны. Quick book-шторки в чате веба (отдельной от Book) — нет, как и было.
- Онлайн-присутствие советника в «Now» — сервер его не проверяет; веб тоже не добавляет.
- Опрос `availability`, пока шторка открыта (решение 6).

## Решения

**1. Что выбрано при открытии.**
- А. **Из чата (`soonest`) — «Now», если доступен, иначе ближайший слот; из профиля — как сейчас
  (ссылка / черновик / ничего).** Как Quick book приложения: из чата человек хочет поговорить сейчас.
- Б. «Now» нигде не выбран сам — только нажатием.
- **Рекомендация: А.**

**2. Куда после подтверждения моментальной сессии.**
- А. **Сразу в тред с советником (баннер с таймером), без Booked** — как приложение.
- Б. Booked с текстом «Session started» и главной кнопкой «Open chat».
- **Рекомендация: А.** Решаем по статусу сессии из ответа сервера.

**3. Порядок слияния с `AURAT-0114`.** Без баннера человек заплатит и не увидит, что сессия идёт
(ровно то, из-за чего «Now» отложили в `AURAT-0107-005` §7).
- А. **Пишем сейчас от develop `d70639f`; merge gate — только после того, как `AURAT-0114` в
  develop: влить develop в ветку, разрешить `booking-form.tsx` (`ChoiceCard`), прогнать проверки.**
- Б. Ждать с кодом, пока `AURAT-0114` не смёржена.
- **Рекомендация: А.**

**4. Подпись CTA для «Now».**
- А. **«Start now · $X»** (`CHECKOUT.md`, приложение). Б. Оставить «Confirm & pay $X».
- **Рекомендация: А.**

**5. Строка политики под CTA для «Now».**
- А. **Не показывать «Free cancellation up to 24 h before» / «free reschedule up to 4 h before»;
  «You save $X» оставить.** Б. Показывать как у слота.
- **Рекомендация: А** — для идущей сессии это неправда.

**6. Устаревший `instantAvailable`, пока шторка открыта.**
- А. **Без опроса: ответ сервера на бронь — истина; 409 снимает выбор и перечитывает.**
- Б. Перечитывать при возврате во вкладку / раз в минуту.
- **Рекомендация: А.**

**7. Карта / кошелёк (`PSP_ENABLED`, только dev).**
- А. **Тот же путь для «Now»: пополнение, затем бронь `startNow` под тем же ключом (и после
  возврата с hosted page).** Б. Для «Now» кнопки пополнения прятать.
- **Рекомендация: А.**

## После мёржа (манор, bff-dev)

Советник без брони на ближайшие N минут → шторка из профиля: «Now» первым сегодня; из чата — «Now»
выбран; «Start now · $X» → тред, баннер с отсчётом, баланс уменьшился. Длительность, которая
упирается в чужую бронь, — «Now» пропадает. Вторая вкладка: занять окно → в первой 409, «Now»
исчез.
