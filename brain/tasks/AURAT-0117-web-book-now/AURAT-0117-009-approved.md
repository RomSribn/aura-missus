## Решения для приложения (`AURAT-0116`, поправка владельца 2 из `006`)

Приложение повторяет решения веба (`AURAT-0117-006`) на экране брони с датами
(`BookSessionScreen`, `SlotGrid`): **«Now»** — первым в ряду «сегодня», пока
`availability.instantAvailable === true` для выбранной длительности (ответ читается для блока —
`minutes` в запросе); **из чата «Now» выбран сам**, если доступен, иначе ближайший слот; из профиля —
ничего не выбрано. Бронь — `startNow: true` без `startsAt`, тем же ключом попытки, что слот.
Кнопка — **«Start now · $X»** (`CHECKOUT.md`); строки **«Free cancellation up to 24 h before»** (и
переноса за 4 ч) для «Now» **нет**, «You save» остаётся. Куда после подтверждения — по сессии из
ответа: **`ACTIVE` → тред без Booked** (баннер с отсчётом), иначе — Booked. Отказ «Now» — свой
текст «It can’t start right now any more — pick a time.», выбор снят, сетка перечитана; после
пополнения через стор — «… {{amount}} is on your balance — pick a time.».
