# AURAT-0089-008 — APK на телефон владельца

Дата: 2026-10-21

На предложение мёржа владелец ответил: «поставь апк на телефон, проверю что
ничего не сломалось на UI». Мёрж не одобрен, ветка в `slave-0`.

- Собрано из слота: `npm run apk:staging` (R8, все 4 ABI, `bff-dev.aura-app.cc`),
  `892caa7`; `classes.dex` 8.6 MB, APK 92.6 MB (было 104 MB).
- Телефон: Samsung A50 (SM-A505FN), Android 11. На нём стояла 28 / 1.0.3 staging,
  подписанная тем же upload-ключом → `adb install -r` поверх, данные и вход сохранены.
- Запуск: процесс жив, в `logcat` нет FATAL / ClassNotFound / ошибок RN.
  (`MQD: NoSuchMethodException MessageQueue.isPolling` — рефлексия по
  фреймворку Android, к R8 отношения не имеет.)
- `keystore.properties` копировался из манора на время сборки, затем удалён из слота.

Дальше: владелец смотрит UI. После его ответа — мёрж (с отдельным подтверждением)
или правки в слоте.
