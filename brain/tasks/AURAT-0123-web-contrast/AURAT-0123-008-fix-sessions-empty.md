# AURAT-0123-008 — Fix: пустой стейт `/sessions` не по центру

Date: 2026-10-23

## Слова владельца

> почему тут пустой стейт не по центру, а слева в компоненте? [скриншот `/sessions`, desktop,
> «No sessions booked» по центру левой колонки]

> возьми в эту ветку

## Причина

`pages/sessions/ui/sessions-page.module.css` (`AURAT-0110`): сетка `.root` всегда из двух колонок —
список и липкая панель детали 480px (380px до 900px). Без выбранной сессии (`selectedId === null`:
сессий нет, ошибка, загрузка) панель не рендерится, а колонка под неё остаётся — пустой стейт
центрируется в левой колонке. В хендоффе (`web/web-sessions.jsx`, `SessionsWeb`) без сессий —
`EmptyState` по центру страницы.

## Решение

`.root:not(:has(> .panel))` → одна колонка `minmax(0, 1fr)`. Заголовок и табы слева, пустой
стейт (и ошибка, и пустой Past без панели) — по центру страницы. На desktop панель есть всегда,
когда список не пуст (выбирается первая сессия), — раскладка со списком не меняется. Специфичность
правила (0,2,0) выше `.root` в медиазапросе 900px, телефон и так одноколоночный.
