# AURAT-0123-005 — Spec: контраст текста в aura-web

## Цель

Весь текст и значимые иконки веба держат 4.5:1 на своём фоне. Цвета хендоффа остаются
**заливками** (точки, полосы, тумблеры, мягкие фоны, бренд); для текста появляются отдельные
токены. Параллельные `AURAT-0136` / `AURAT-0137` получают короткое правило «чем красить текст» и
после мёржа переходят на него. Тест не даёт низкоконтрастному тексту вернуться.

## Что делаем (по рекомендациям)

1. **`tokens.css`** — токены выше; у каждой группы комментарий «текст / заливка под белым /
   только заливка»; исправить ложный комментарий про `--error`.
2. **Teal-текст** — 22 правила `color: var(--teal)` → `--teal-ink` (тег причины `/match`,
   «You save», «Online», «Session live», иконки баланса / оплаты / щита, пилюли треда,
   «Reviewed», ссылка входа и т. д.).
3. **Coral-текст** — `color: var(--accent)` и `color: var(--accent-hover)` (37 правил) →
   `--accent-ink`; глобальная ссылка `a` → `--accent-ink`. Hover текстовых ссылок
   (`a:hover`, `.nudgeLink:hover`, «Reset», «Cancel») сейчас на `--accent-hover` — тот станет
   заливкой, поэтому hover ссылки = подчёркивание, цвет `--accent-ink`.
4. **Белый на заливке** — `background: var(--teal)` / `var(--accent)` под белым текстом →
   `--teal-strong` / `--accent-strong`; hover primary → `--accent-hover`, hover кнопки teal → `--teal-hover`. Заливки без текста
   (онлайн-точки, полосы баннера и фильтра, тумблер, кольцо Ask, линии шагов) — без изменений.
5. **`--ink-3` как текст** (решение 4) — текстовые правила (подсказки, мета, плейсхолдеры,
   `.eyebrow`, `.muted-3`) → `--ink-2`; иерархия держится размером / весом / регистром, как уже
   у eyebrow. Остаются на `--ink-3`: зачёркнутая цена `PriceTag` (разрешено хендоффом) — через
   именованный `--ink-struck: var(--ink-3)`, точки typing, разделители, отключённое (WCAG его не
   требует).
6. **Фокус** — обводка `:focus-visible` `--accent` (2.81 на paper) → `--accent-ink` (≥ 3:1 для
   не-текста). Мелочь, но та же строка.
7. **Защита** — `shared/config/__tests__/contrast.test.ts` (по образцу `breakpoints.test.ts`):
   - читает `tokens.css` и проверяет таблицу пар «текстовый токен × светлый фон» ≥ 4.5 и
     «белый × strong-заливка» ≥ 4.5 — значения поменяют, тест скажет;
   - сканирует все `.css` в `src`: `color:` (и `fill` / `stroke` у иконок) не берёт
     `--teal`, `--accent`, `--accent-hover`, `--ink-3`; белый текст стоит только на
     `--*-strong` / тёмных (plum, ink) фонах внутри того же правила.
8. **Правило веба** — в `aura-web-build-rules.md` («Design system») короткий абзац «Чем красить
   текст» (текст: `--ink`, `--ink-2`, `--teal-ink`, `--accent-ink`, `--error`; белый — только на
   `--teal-strong` / `--accent-strong` / plum / ink; gold-текст — только на plum; `--teal`,
   `--accent`, `--ink-3`, `--gold` — заливки и иконки-декор). Файл лежит в воркспейсе манора,
   не в репо — правка отдельно от кода, после ревью.
9. **Сообщение 0136 / 0137** — тот же список в `007-execute.md` и в итоге задачи; после мёржа
   они переходят на токены (конфликты — манор).

Gold-звёзды на светлом не трогаем: это иконка рядом с числом рейтинга (информация дублируется).
Строки и переводы не меняются. Логики нет — только CSS и тест.
