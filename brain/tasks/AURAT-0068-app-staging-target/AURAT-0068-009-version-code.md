# AURAT-0068-009 — versionCode 18

Дата: 2026-09-14

На вопрос о проверке в маноре владелец спросил, как поставить `versionCode 18`,
и попросил сделать это самому.

Прошлые подъёмы (9…17) были прямыми однострочными коммитами на `develop` в
маноре. Из слота так нельзя — манор трогается только через `wts-finish` /
`wts-release`, — поэтому подъём сделан на ветке задачи и уходит повторным
`wts-finish`.

- `android/app/build.gradle:100` — `versionCode 17` → `18`.
- Коммит `a21147c` на `feature/AURAT-0068-app-staging-target`: «build:
  versionCode 18 — первая сборка internal testing на staging».

Дальше: повторный мёрж (с одобрения владельца), затем сборка
`npm run aab:staging` в маноре и проверка по `005`.
