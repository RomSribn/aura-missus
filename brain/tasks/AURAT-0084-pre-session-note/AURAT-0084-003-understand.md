# AURAT-0084-003 — understand

За 5 минут до старта каждой запланированной платной сессии BFF пишет в диалог
Chatwoot приватную заметку, видимую только чаттерам. Если на диалог назначен агент,
заметка его упоминает — Chatwoot шлёт ему уведомление `conversation_mention`
(Web Push / звук). Клиент заметку не видит, приложение ничего не получает.
