# AURAT-0084-010 — частичная проверка в маноре

2026-10-12. Владелец проверил на живом стеке: **заметка за 5 минут приходит**, время
в ней — UTC. Обсудили: BFF шлёт готовый текст, Chatwoot его не локализует, пояса
чаттера BFF не знает, пояс клиента не хранится. Варианты: убрать время / рабочий
пояс из настройки / оставить UTC. **Решение владельца: оставить UTC**, кода не
меняем.

Не проверено: упоминание assignee + push, заметка без assignee, перенос, отмена.
