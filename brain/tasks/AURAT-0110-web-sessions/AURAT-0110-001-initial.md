# AURAT-0110-001 — Initial (заглушка; исполняется в `aura-web-manor`)

Date: 2026-10-20
Выдан в `aura-app-manor` для `AURAF-0020` (веб-клиент), этап 2 — строка 009 scope (колонка
UI), первый экран этапа 2 по Р5 `AURAD-0019`. Владелец выбрал его параллельно с `AURAT-0108`
(оплата) и `AURAT-0112` (главная), 2026-10-20. Рядом в `aura-bff-manor` идёт `AURAT-0111` —
`GET /v1/sessions/:id` (строка 026) и новый тег контрактов. Опирается на `AURAT-0107`
(бронь, Booked с отложенным «Go to session», `entities/session`: `saving`, `slots`, `ics`).

Что нужно: человек видит предстоящие и прошедшие сессии, переносит (бесплатно до 4 ч),
отменяет (возврат по правилам), добавляет в календарь, оставляет отзыв — NAVIGATION §2.9,
§3.6, §4, §5 (`/sessions?id=`), README §4.6, §5, §6 веб-хендоффа; мобильные
`SESSIONS_BOOKING.md`, `REVIEWS.md`; приложение — `screens/{sessions,session-detail,
reschedule,write-review}`, `features/advisor-review`; `AURAD-0009`, `AURAD-0014`.

- **Данные — BFF как есть.** Список — `GET /v1/sessions` (все статусы, свежие первыми, до
  100); Upcoming = SCHEDULED + ACTIVE, Past = FINISHED, CANCELLED не показываем (как
  приложение). Перенос — `PATCH /v1/sessions/:id {startsAt}` (400 — сетка, lead, горизонт;
  409 — не SCHEDULED, до текущего слота меньше 4 ч, слот занят); отмена —
  `POST …/:id/cancel` → `{session, refundedMinor, balanceMinor}` (409 — уже не SCHEDULED);
  отзыв — `PUT /v1/advisors/:advisorId/review` (`ratingTenths` 10–50, текст ≤ 400,
  `anonymous`; 403 `review_not_eligible`; повтор правит отзыв), свои — `GET /v1/reviews/me`.
  Начатую сразу (`startNow`) сессию нельзя перенести и отменить. Одна сессия по id — через
  `GET /v1/sessions/:id`, когда `AURAT-0111` выкатится (подъём тега контрактов — отдельным
  коммитом); до тех пор — поиск в списке, как сейчас в `getSession`.
- **Реальное время.** `session.updated` сейчас отбрасывается в `chat-sync`: писать его в
  кэш RTK Query — место в `app` или `shared` (импорт entity → entity запрещён); после
  переподключения — перечитать список (догона по сокету нет). Без веера запросов по
  советникам: лимит BFF 120/мин на IP общий с синком чата.
- **Экран.** Сегменты Upcoming / Past; карточка; детали — панель на desktop, шторка на
  телефоне, `/sessions?id=`; шторки переноса (форма брони без длительностей и без
  черновика брони — нужен режим) и отмены (оценка возврата портом `refundEstimate`, после —
  серверный `refundedMinor`; при полном возврате со скидкой перечитать кошелёк и pricing —
  оффер вернулся); форма отзыва (звёзды публикуются сразу, текст — после модерации);
  `.ics` — вынести из `pages/booked` (после переноса файл устаревает: `SEQUENCE`); Booked
  «Go to session» включить; пустые состояния и ошибка загрузки.
- **Решить в спеке** (хендофф и приложение расходятся): Join с T−5 мин (веб) или «Open
  chat» всегда (приложение, мобильный хендофф) и нужна ли отдельная Message; кнопка переноса
  выключена по `serverNow` внутри 4 ч (веб) или решает сервер (приложение); чипы причин
  отмены (передать их некуда); строка Past — «Leave a review» / «Book again» (право на отзыв
  на сервере — своё сообщение, а не завершённая сессия); правая панель на вкладке Past;
  входы в отзыв с профиля и из чата — здесь или позже; дни переноса — 7 с завтра (хендофф)
  или 14 с сегодня (как бронь `AURAT-0107`); тексты возврата — на баланс, не «to your card»;
  строку Reminder и плашку «email and push 30 min before» не показывать — напоминаний
  человеку BFF не шлёт.
- Перенос из aura-app только нужного, копией с тестами и шапкой
  `// Ported from aura-app <path> (<ID>)`: `entities/session/lib/{refund,session-state}.ts`
  (`session-state` отложен сюда из `AURAT-0107`), `relativeDay` из `shared/lib/dates.ts`,
  `screens/session-detail/lib/labels.ts`, `features/advisor-review/config/review.ts`, правило
  `use-review-access`; сценарии — из тестов `RescheduleScreen`, `SessionDetailScreen`,
  `WriteReviewScreen`. Новые строки — сразу на все 24 языка (правило 9).

**Живая платная сессия в треде** (баннер, таймер, Extend, раннее завершение) — нет ни в одной
строке `AURAF-0020`: чат и бронь её вынесли, хендофф веба не рисует. Join ведёт в тред, где
есть только маркеры начала и конца; остаток минут можно показать на `/sessions` из `endsAt`.
Новая строка и её ID — в `aura-app-manor`, по решению владельца; в этой задаче — не делать.

Найденные пробелы BFF — владельцу и в бэклог, ID выдаётся в `aura-app-manor`: нет
`offerRestored` в ответе отмены (выводится из суммы); у отмены нет тела (причина); нет
предпросмотра возврата; availability не исключает переносимую сессию (её окно — занято);
`PATCH` не проверяет занятость человека у другого советника; напоминаний человеку нет;
право на отзыв (своё сообщение) расходится с «завершённой сессией» хендоффа.

Вне задачи: живая сессия в треде (см. выше), пагинация списка, напоминания и web push,
аналитика.

нужен список сессий: запрос вводит та задача, что влита первой); общие `router.tsx`, локали
`app`, `entities/session`. Старт — `wts-task` в `aura-web-manor`, спека на одобрение
