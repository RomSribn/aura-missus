# AURAT-0110-003 — Understand

Дата: 2026-10-20

Владелец хочет экран `/sessions` в aura-web (`AURAF-0020`, строка 009, колонка UI): человек
видит предстоящие и прошедшие сессии, открывает деталь (`/sessions?id=`), переносит,
отменяет с возвратом на баланс по правилам сервера, добавляет в календарь и оставляет
отзыв; `session.updated` из сокета обновляет кэш. Данные — BFF как есть, перенос логики из
aura-app копией с тестами; строки — на 24 языках.

Сейчас — только check → understand → context → spec; спека с вариантами и рекомендацией
по каждому спорному решению заглушки — владельцу на одобрение. Живая платная сессия в
треде — не делать. Пробелы BFF/контрактов и новая строка под живую сессию — просьба к
владельцу выдать ID в `aura-app-manor`.
