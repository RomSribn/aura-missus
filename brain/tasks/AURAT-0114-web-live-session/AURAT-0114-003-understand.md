# AURAT-0114-003 — Understand

Date: 2026-10-20

Владелец хочет, чтобы в треде чата aura-web шла живая платная сессия так же, как в приложении:
баннер с обратным отсчётом до `endsAt` по часам BFF (с предупреждением под конец), продление
блоками сервера (Extend: ключ попытки, 402 — нехватка, 409 — разные причины), раннее завершение
с предупреждением о сгорающих минутах. Активная сессия треда берётся из кэша сессий
(`AURAT-0110`) и двигается событием `session.updated` — без запросов по советникам.

На этом шаге — только спека: решения из заглушки (баннер до старта, шапка треда, `/sessions` и
главная во время сессии, что показывать на 409, путь 402 при PSP) — с вариантами и
рекомендацией, на одобрение владельцу. Пробелы BFF / контрактов — запросом в `aura-app-manor`
через владельца. Код — после одобрения.
