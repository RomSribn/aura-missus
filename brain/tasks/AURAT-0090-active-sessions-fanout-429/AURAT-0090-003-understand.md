# AURAT-0090-003 — Что нужно

Приложение само себе устраивает 429: при каждом выходе на передний план и открытии вкладки
чатов оно шлёт по запросу на каждого советника — за активными сессиями и за историей чата.
Нужно убрать оба веера (активные сессии — одним `GET /v1/sessions`, история — без дублей и, по
решению владельца, через список диалогов в BFF) и сделать так, чтобы редкий 429 на чтении не
ронял экран. Общий лимит BFF не поднимать.
