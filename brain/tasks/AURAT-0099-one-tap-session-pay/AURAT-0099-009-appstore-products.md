# AURAT-0099-009 — Лестница покупок в App Store Connect

Дата: 2026-10-21

Владелец попросил завести те же продукты в App Store Connect, хотя версия
`1.0.0` ещё на ревью (заявка `09e11ae6-…`, `WAITING_FOR_REVIEW` с 2026-10-15).

## Что сделано (App Store Connect API, ключ `XHRC8JZJJN`)

Созданы 116 покупок `aura.topup.usd1 … usd120` (без 10/25/50/100), по образцу
`aura.topup.usd10`:

| Поле | Значение |
|---|---|
| Тип | `CONSUMABLE`, `familySharable: false` |
| Reference name | `Top-up N USD` |
| Локализация en-US | «$N wallet credit» / «Adds $N of credit to your Aura wallet.» |
| Review note | как у прежних четырёх |
| Цена | база **USA**, ручная; остальные страны — автоцены Apple от базы |
| Доступность | те же 34 территории, `availableInNewTerritories: false` |
| Скриншот для ревью | **не загружен — намеренно** |

**Цена в США — ровно $N, где у Apple есть такая точка, иначе $N − 0.01.** Прежние
четыре стоят ровно $10/25/50/100 (не $X.99, как в Play). Выше $100 у Apple только
точки `…99` (плюс $109, $119, $129): 101–108, 110–118 и 120 стоят $100.99 …
$119.99. Покупатель не платит больше кредита ни в одном случае.

**Почему без скриншота.** Без него покупка остаётся `MISSING_METADATA` и не
может попасть в отправляемую заявку — ни руками, ни «прицепиться сама» после
ответа ревьюеру (`AURAT-0079-008`, уточнение 2026-10-08). Сборка 1.0.0 эти
продукты не запрашивает, и 116 лишних покупок в её ревью — лишний повод для
отказа. Песочница TestFlight покупки в `MISSING_METADATA` продаёт (так
проверялись первые четыре, `AURAT-0081-011`).

Прочитано обратно: 120 покупок, у новых — `MISSING_METADATA`, одна локализация,
одна ручная цена USA по правилу выше, 34 территории; прежние четыре —
`WAITING_FOR_REVIEW`, не тронуты; заявка по-прежнему `WAITING_FOR_REVIEW`.

## Осталось

- К выпуску сборки с `AURAT-0099`: скриншот ревью для каждой из 116 (640×920 —
  другие размеры отклоняются, `AURAT-0079-007`) и добавить их в заявку той
  версии.
