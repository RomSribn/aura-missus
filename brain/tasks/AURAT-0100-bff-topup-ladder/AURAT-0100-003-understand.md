# AURAT-0100-003 — Understand

Date: 2026-10-19

Сервер должен кредитовать продукты лестницы `aura.topup.usd1 … usd120`
(`usdN` = N × 100 минорных единиц), чтобы приложение могло купить в сторе ровно
недостающую сумму перед бронью (`AURAF-0019-009`). Только добавление: четыре
нынешних продукта (`usd10/25/50/100`) сохраняют кредит, прошлые покупки,
возвраты и уведомления сторов разбираются как раньше. Всё вне лестницы — 400.
Контракты не меняются; округление — забота приложения, сервер кредитует по
своей таблице (`AURAD-0010` п.1).
