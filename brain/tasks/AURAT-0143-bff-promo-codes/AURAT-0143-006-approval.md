# AURAT-0143-006 — Approval

Date: 2026-10-27

Владелец: «Одобряю §9 целиком (1–6), с правками»:
1. Оператор: `backoffice:operator remove` удаляет строку (`deleteMany` — подтверждено в
   `prisma-operators.repository.ts`). `createdByOperatorId` / `disabledByOperatorId` — без FK,
   рядом снимок логина на момент действия; иначе remove упадёт на FK или список потеряет «кем».
2. «Отключить все неиспользованные» — обязательная галочка в той же форме («Понимаю: включить
   обратно нельзя», `required`, без JS): промах необратимо гасит розданную кампанию.
3. Нормализация: кроме пробелов и тире убирать любые пробельные (включая NBSP) и невидимые
   символы (U+200B–U+200D, U+2060, U+FEFF) — коды будут копировать из Instagram и Telegram.
Мелочи: отключение партии блокирует коды в порядке id; имя CSV-файла — из id партии, не из
названия кампании.

Все правки внесены в `AURAT-0143-005-spec.md` (§2, §3, §4, §5, раздел «Правки владельца»).
Решения §9: потолки $100 / 500 / 90 дней (макс. 365), коды показываются повторно, эндпоинт
`POST /v1/wallet/promo-codes/redeem`, отказ `promo_code_campaign_used`, лимит только на
«не найден», всё за `billing_enabled`.
