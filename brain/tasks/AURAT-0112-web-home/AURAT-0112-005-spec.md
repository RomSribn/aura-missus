# AURAT-0112-005 — Spec: главная `/` в aura-web

Date: 2026-10-20
Type: task (касается строк `AURAF-0020-004`, `-012` — вариант v1, `-013`; колонка UI). Новой фичи нет.
Status: одобрена 2026-10-20 (`006`) — рекомендации 1–12 + правки владельца (идея таро, без «Verified», «free chat», без строки бэклога)

## Цель

Вместо пустой `/` — главная по канону HomeA веб-хендоффа: приветствие, Ask, купон, «How Aura
works» гостю, ближайшая сессия и последние чаты вошедшему, советники из каталога, темы. Ask — в
варианте v1 строки 012: без `/match` и без подбора, переход в публичный каталог по категории.
В шапке гостя появляется Get started (отложен из `AURAT-0104`). BFF и contracts **не меняются**.

Решения 1–12 — в конце, у каждого варианты и рекомендация. «Что делаем» написано по рекомендациям.

## Что делаем

### 1. Раскладка (README §3, NAVIGATION §2.1)

Desktop (≥ 761): сверху — дата (`Intl`: «Tuesday, 20 October») и приветствие (решение 7). Дальше
две колонки 50/50: слева карточка Ask, справа — стек: купон (только при оффере) → для гостя «How
Aura works», для вошедшего ближайшая сессия → последние чаты (решение 10). Ниже — «Top advisors»
(5-up) и «Ask about» (3 темы). Баннера Daily Card нет (решение 6).

Телефон (≤ 760): одна колонка в том же порядке: приветствие → Ask → купон → правый стек →
«Top advisors» (2-up, 4 плитки) → «Ask about». Таб-бар — как на других страницах.

Пока Firebase не сказал, кто это (`useAuthStatus() === 'loading'`), правый стек — скелетон, а не
гостевой блок: «How Aura works» не мигает перед сессией.

### 2. Ask — `features/ask-question` (новый)

- **ui** `AskHero`: eyebrow «Ask an advisor · first chat free», заголовок «What's on your mind?»,
  подзаголовок v1 (решение 3), поле (`textarea`, ≤ `QUESTION_MAX_LENGTH` = 250, placeholder
  хендоффа), чипы тем `All · Love · Tarot · Psychic` (решение 1), кнопка **Ask** (coral, disabled
  пока поле пусто), под ней — чипы-идеи (4 на desktop, 3 на телефоне).
- **model** `useAskQuestion`: Enter = Ask, Shift+Enter = новая строка, IME-композиция не
  отправляет. Ask → вопрос сохраняется (§3) → `/advisors?cat=<тема>` (без темы — весь каталог).
  Чип-идея — то же сразу, с текстом и темой идеи. Входа не просит (решение 2).
- **config**: идеи — `{ id, category }`, тексты — ключи локали. По хендоффу: «Does he still think
  about me?» → LOVE, «Should I take the new job?» → PSYCHIC, «What does my dream mean?» → PSYCHIC,
  «Will we get back together?» → LOVE (решение 1 — замена одной на TAROT).
- Поле — цель Get started (§6): `id`-якорь, фокус и кольцо.

### 3. Вопрос едет в первый бесплатный чат (решение 3)

- Вопрос хранится во вкладке (`sessionStorage`, не в URL — текст вопроса не попадает в адресную
  строку, логи, `Referer` и аналитику), `entities/message/model/question-draft.ts`.
- В каталоге над результатами — строка «Your question · “…” · Pick an advisor and ask them in a
  free chat» с × (убрать вопрос).
- Первый чат, открытый после Ask (Chat free на плитке, Free chat в профиле — у гостя после входа с
  resume), получает вопрос **в поле composer**, не отправляет его сам; после подстановки вопрос из
  вкладки удаляется. Бронь его не несёт (поля нет — строка 028).

### 4. Советники — «Top advisors» (решение 4)

- Первые 5 каталога (`useAdvisors`, уже в кэше) в порядке сервера, как «Top advisors» приложения;
  телефон — 4. «See all advisors →» → `/advisors`.
- Плитка — та же, что в каталоге: тело → профиль, **Chat free** → gate(null) → `/chats/:id`,
  **Book** → gate('book') → `/advisors/:id?book=1`.
- Плитка с кнопками теперь нужна двум страницам → поднимается из `pages/advisors` в
  `widgets/advisor-card` (`AdvisorTile`/`AdvisorRow` сущности + кнопки с gate; feature в feature
  импортировать нельзя — Steiger). `pages/advisors` переходит на него, поведение не меняется.
- Загрузка — скелетоны; ошибка — `EmptyState` small с Try again, как в каталоге; пустой каталог —
  секции нет.

### 5. «Ask about» — 3 темы (решение 5)

Три плитки по категориям контрактов: «Love & relationships» (LOVE), «Tarot readings» (TAROT),
«Psychic insight» (PSYCHIC), подпись — «{n} advisors» по каталогу (плюралы), иконки — из набора.
Плитка — ссылка на `/advisors?cat=…`. Тема без советников — плитка не рисуется.

### 6. Get started — шапка гостя (NAVIGATION §1.1)

- Гостю (`status === 'guest'`) рядом с Log in — **Get started** (coral, sm). Это ссылка на `/#ask`
  (`paths.home({ ask: true })` в `shared/config/routes.ts`), работает с любой страницы.
- На главной `model/use-ask-focus` по якорю `#ask`: прокрутка к полю (smooth; при
  `prefers-reduced-motion` — без анимации), фокус, coral-кольцо 1.4 с (CSS-анимация, класс снимает
  модель), затем `replace` без якоря — повторное нажатие срабатывает снова.
- Вошедшему не рисуется. На телефоне обе кнопки в шапке 58 px. Тест «Get started waits for Home» →
  «гость видит Get started, вошедший — нет; нажатие ведёт к полю и фокусирует его».

### 7. Правый стек гостя — «How Aura works»

Три шага (тексты v1, решение 3): 1. «Ask your question» — «Love, a tarot reading, a dream —
anything on your mind.» 2. «Choose your advisor» — «Pick one who fits and ask them in a free
chat.» 3. при оффере «Book with {pct}% off» — «Your first private session is {pct}% off.», без
оффера «Book a private session» — «A private paid chat at a time you choose.». Внизу — «Verified
advisors · private chats» (без «encrypted»: сквозного шифрования нет).

### 8. Ближайшая сессия — вошедшему (решение 8)

- `entities/session`: `getSessions` — `GET /v1/sessions` → `SessionsResponse.parse`, тег
  `Sessions` (в `baseApi.tagTypes`); `bookSession` его инвалидирует. Это тот же список, что нужен
  `AURAT-0110` — вводит тот, кто влит первым, второй берёт готовый.
- `lib/next-session.ts` (+ тест): `ACTIVE` раньше всех, иначе ближайшая `SCHEDULED` со
  `startsAt` ≥ `serverNow()`; `FINISHED`/`CANCELLED` — нет.
- Карточка (plum-шапка как в хендоффе): eyebrow «Next session · today / tomorrow / in 3 days»
  (`Intl.RelativeTimeFormat`, по календарным дням) или «Session in progress» для `ACTIVE`; блок
  даты (число + месяц, `Intl`); «{n}-min private chat with {name}» (имя и фото — из каталога);
  «18:30 – 19:00». Вся карточка — ссылка «Open chat» → `/chats/:advisorId` (сессия идёт в чате,
  как кнопка Booked). Reschedule — строка 009, не рисуется.

### 9. Последние чаты — вошедшему

`useConversations` по id каталога (тот же кэш, что `/chats`; запрос истории на каждого советника —
долг `AURAF-0020-023`) → две самые свежие строки в `ConversationList` (виджет `AURAT-0105`, без
изменений) + «All chats →» → `/chats`. Бейдж «новое за визит» — как в списке.

### 10. Пустые и особые состояния (решение 10)

- Нет предстоящей сессии — карточки нет; нет чатов — блока нет; **нет ни того, ни другого —
  «How Aura works»**, как гостю (новый человек видит, что делать).
- Загрузка сессий и чатов — скелетоны; ошибка чтения — блок не рисуется (у `/chats` своя ошибка с
  повтором; главная ошибками не кричит).
- Биллинг выключен (404 у pricing / wallet / sessions): купона и `OffChip` нет, шаг 3 — без
  процента, сессии — блока нет. Каталог и чаты работают.

### 11. Строки

Новые namespace: `home-page` (`pages/home`), `ask-question` (`features/ask-question`),
`advisor-card` — только если виджету нужны свои строки (кнопки уже в `advisors-page` — переедут);
дополнения — `app` (`nav.getStarted`), `advisors-page` (строка вопроса), `send-message` — нет.
Всё сразу на 24 языках (правило 9); плюралы «{n} advisors» — по языку; дата, «in 3 days», время —
`Intl` на языке интерфейса.

### 12. Маршрут и FSD

- `router.tsx`: `{ path: ROUTES.home, element: <HomePage /> }` (не lazy — первая страница).
- `pages/home`: `ui/home-page.tsx` (+ `.module.css`, отступы — токены), `ui/next-session-card.tsx`,
  `ui/how-it-works.tsx`, `ui/topic-tiles.tsx`; `model/use-home-page.ts`, `model/use-ask-focus.ts`;
  `lib/greeting.ts` (+ тест: час → утро/день/вечер); `config/home.ts` (5 / 4 советника, 2 чата,
  темы → иконки); `config/locales/*`.
- `ui/` — только рендер; таймер кольца, якорь, навигация — в `model/`.

## Решения (владельцу)

**1. Как Ask выбирает категорию.** Сопоставления «вопрос → категория» нет; категорий три.
- А. **Чипы тем у поля** `All · Love · Tarot · Psychic` (по умолчанию All, тема необязательна) +
  **чипы-идеи с заданной темой**: набрал вопрос и, если хочешь, выбрал тему → каталог по ней; идея
  — одним нажатием.
- Б. Только чипы-идеи с темой; набранный вопрос ведёт во весь каталог.
- В. Тема обязательна: Ask неактивен, пока тема не выбрана.
- (Ключевые слова на 24 языках — не делаем: угадывание, которое врёт.)
- **Рекомендация: А.** Б оставляет набранный вопрос без смысла; В — лишний обязательный шаг.
- Попутно: у идей хендоффа нет ни одной про таро. Предлагаю заменить «Will we get back
  together?» на «What do the cards say about my week?» → TAROT. Скажи, если оставить как в
  хендоффе.

**2. Нужен ли гостю вход на Ask.**
- А. **Нет.** Каталог публичный; вход просится там, где он нужен — Chat free / Book, с resume (как
  сейчас). Причина `ask` не вводится (без потребителя — правило 5).
- Б. Да, как хендофф: gate('ask') «Log in to send your question», после входа — каталог.
- **Рекомендация: А.** В хендоффе вход стоит перед `/match`, который персонален; перед публичным
  каталогом он только отсекает людей. Строка 004 для Ask получит смысл вместе с `/match`.

**3. Что с текстом вопроса.** Передать его пока некуда: `/match` нет (012), поля в брони нет (028).
- А. **Поля в v1 нет**: карточка Ask — «What's on your mind?» + три темы-кнопки → каталог; Get
  started фокусирует первую тему. Честно, минимум кода, но главный крючок хендоффа пропадает.
- Б. **Поле есть, вопрос едет в первый бесплатный чат** (§3): хранится во вкладке, в каталоге
  видна строка вопроса, открытый после Ask чат получает его в composer (не отправляет сам).
  Подзаголовок: «Write your question — then pick an advisor and ask them in a free chat.»
- В. Поле есть, текст пропадает после Ask.
- **Рекомендация: Б.** Бесплатный чат — единственное место, где вопрос сегодня может дойти до
  советника, и eyebrow «first chat free» про это и говорит. В — обещание, которое мы не держим.
  Цена Б: хранилище вопроса, строка в каталоге, подстановка в composer.

**4. Блок советников вместо «Online now».** Онлайна в каталоге нет, гостю он запрещён
(`AURAT-0102-006`), presence у веба — только по своим разговорам.
- А. **«Top advisors»** — первые 5 каталога в порядке сервера (как приложение).
- Б. «Highest rated» — сортировка по рейтингу на клиенте.
- В. «Online now» вошедшему по presence — покажет лишь тех, с кем уже есть чат; гостю — ничего.
- **Рекомендация: А.** Порядок каталога — серверный «Recommended», приложение показывает то же.

**5. «Ask about».** Хендофф — 4 темы (Love, Career, Dreams, Future), из них в контрактах только
Love.
- А. **Три плитки по категориям** контрактов → `/advisors?cat=`.
- Б. Не рисовать (темы уже есть у поля Ask).
- **Рекомендация: А** — вход в каталог по теме без вопроса. Новые категории — решение contracts,
  вне задачи.

**6. Баннер Daily Card.** Карта дня — этап 2 (строка 013).
- А. **Не рисовать** до строки 013.
- Б. Информационный баннер «Draw your card in the Aura app» без кнопки.
- **Рекомендация: А.** Кнопка без цели нарушает правило 5, а реклама приложения без ссылок на
  сторы (их URL нет в конфиге) — тупик.

**7. Приветствие.**
- А. **Как веб-хендофф**: «Good morning / Good afternoon / Good evening, {name}» по часу браузера
  (5–12 / 12–18 / иначе); без имени (гость, пока профиль не прочитан) — без запятой и имени.
- Б. Как приложение: «Hi, {name}» / «Hi there».
- **Рекомендация: А** — для веба хендофф первичен; три ключа вместо двух, перевод тот же.

**8. Ближайшая сессия: куда ведёт.** `/sessions` — `AURAT-0110`, идёт параллельно.
- А. Как хендофф: карточка → `/sessions?id=` (до слияния `AURAT-0110` — пустая страница) +
  Reschedule / Details.
- Б. **Карточка → чат с советником** («Open chat», сессия идёт в чате, как на Booked); без
  Reschedule (строка 009). Когда `AURAT-0110` в develop, ссылка становится `/sessions?id=` — если
  она влита раньше, делаю сразу так.
- В. Блока нет до `AURAT-0110`.
- **Рекомендация: Б.**

**9. Последние чаты: цена запроса.** Список чатов сейчас — история по каждому советнику каталога
(8 запросов, `AURAF-0020-023`).
- А. **Как `/chats`**: тот же хук и кэш — переход на `/chats` после главной ничего не перечитывает.
- Б. Не показывать чаты на главной до `GET /v1/conversations`.
- **Рекомендация: А.** Персон 8, кэш общий; с 023 главная станет дешевле без изменений в UI.

**10. Пустые состояния вошедшего.**
- А. **Пустой блок не рисуется; ни сессии, ни чатов — «How Aura works»**; ошибки — блок не
  рисуется.
- Б. `EmptyState` хендоффа в каждом блоке («No sessions booked · Find an advisor», «No messages
  yet · Browse advisors»).
- **Рекомендация: А** — два пустых орба в правой колонке выглядят как поломка; новому человеку
  «How Aura works» полезнее.

**11. Тексты «match» и «Finding advisors…».** В v1 подбора нет.
- **Рекомендация:** «we'll match you», «Get matched», «Finding advisors…» не пишем (тексты v1 —
  §2, §7); «Finding advisors…» не нужен — Ask синхронный. Вернутся с `/match`.

**12. Аналитика** (`get_started_click`, `ask_submit`). Инфраструктуры аналитики в вебе нет.
- **Рекомендация:** не в этой задаче (как `AURAT-0107`); текст вопроса туда не попадёт и потом.
