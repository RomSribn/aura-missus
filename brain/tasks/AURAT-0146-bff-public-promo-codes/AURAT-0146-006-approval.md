Решение по порогу (§4): **предупреждение + галочка**, не жёсткий запрет. Публичный код на сумму
не меньше самой дешёвой сессии создаётся, только если на подтверждении отмечена галочка
«понимаю: код без лимита оплатит сессию целиком». Без галочки — ошибка поля/страница с отказом.
Галочка проверяется сервером и на шаге создания (скрытые поля — браузерные).
