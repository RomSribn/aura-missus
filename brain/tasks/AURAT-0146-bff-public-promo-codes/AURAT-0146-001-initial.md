## Что нужно

Публичный многоразовый промокод (A1 из `AURAI-0009` §2): оператор выбирает имя кода (`WINTER5`),
сумму и срок; код гасит любой аккаунт по одному разу, кредит `PROMO_CREDIT` на баланс.
Решения владельца (`AURAI-0009` §8): **для всех аккаунтов, без лимита и бюджета, только срок**;
дедупа по телефону нет. Условие: сумма публичного кода **меньше самой дешёвой сессии** (сейчас $11,
сверить на проде) — бэкофис не даёт создать больше (или требует отдельную галочку).

Где менять — `AURAI-0009` §2 «A1 — что менять»: вид партии `single | public`, vanity-формат,
частичный unique вместо `codeId @unique`, повтор по (код, кошелёк), ключ проводки
`promo:<codeId>:<walletId>`, сводка бэкофиса для публичных кодов. Клиенты (`AURAT-0144`,
`AURAT-0145`) должны работать **без релиза** — новые отказы не вводить без нужды.

Запущена 2026-10-31 в `aura-bff-manor` slave-1.
