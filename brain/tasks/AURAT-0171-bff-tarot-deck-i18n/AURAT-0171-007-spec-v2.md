# AURAT-0171-007 — spec v2: колода таро на языке пользователя + резолвер `?lang`

Дата: 2026-11-06 · Статус: **draft — ждёт одобрения владельца**
Заменяет `005-spec.md`: решения владельца (хранение — Б, JSDoc — А) и 13 замечаний ревью (`006-review.md`).
Фича: `AURAF-0023` строка 010 · Решение: `AURAT-0137-006` §3A · Резолвер: `AURAT-0168-007` §2.
Репо: `aura-bff` + одна строка JSDoc в `aura-contracts` (§6).

## Что получится

- `GET /v1/tarot/daily?lang=de` → карта дня по-немецки: `name`, `keywords`, `daily`. `imageUrl` и арт — те же
  (английские надписи на картинках остаются — решение владельца 2026-11-06).
- То же для `POST /v1/tarot/spread/:messageId/pick?lang=…` — **и на первом нажатии, и на повторе** — и для карты
  открытого расклада в `GET /v1/advisors/:advisorId/messages?lang=…`.
- Без `lang`, с неизвестным кодом, `DE`, двумя `lang` или выключенным языком → английский, как сейчас. Старые сборки
  ничего не замечают.
- Заметка чаттеру «Card chosen: …» — по-английски.

## 1. Перевод колоды

78 карт × `name` / `keywords` / `daily` × 23 языка (≈ 5,4 тыс. строк).

**Имя карты** (нужно `0169` / `0170` / `0167` для фраз с `{{card}}`):
- именительный падеж традиционного названия колоды Райдера–Уэйта в этом языке, не дословный перевод
  (de «Der Narr», «Die Hohepriesterin», «Zwei der Kelche»; fr «Le Mat», «La Grande Prêtresse»; es «El Loco»,
  «Dos de Copas»; it «Il Matto», «Due di Coppe»; pl «Głupiec», «Dwójka Kielichów»);
- у старших арканов — артикль там, где он есть в традиции языка, с заглавной, как в изданных колодах; младшие — как в
  списке; без кавычек;
- в шапке каждого языкового файла: «артикль у старших: да / нет» и таблица мастей и рангов (Wands / Cups / Swords /
  Pentacles; Ace, Page / Knight / Queen / King → форма в имени карты). Масть одна на все 14 карт.

**Текст:**
- термины глоссария v2 (`tarot`: it «tarocchi», bg «таро», et / lt / lv «taro»; `tarot-card`); обращение — по
  таблице `AURAF-0023-glossary.md` (формальное: bg, cs, el, fr, hr, lt, lv, pt, sk, sl; pl «Ty» с заглавной;
  остальные на «ты»);
- обычный регистр во всех языках, el и ga тоже; капс, где он нужен, делают клиенты (`upperLabel` в приложении,
  аналог на вебе) — передаю в `0169` / `0170`;
- правила английской колоды: ровно **три ключевых слова** через « · » (ключевое слово бывает из нескольких слов,
  «Moving on»); одно-два предложения; **никаких предсказаний** — совет на сегодня; тяжёлые карты (Смерть, Башня,
  Дьявол, Десятка мечей) названы честно, рядом — что можно сделать сегодня; семь карт дизайна — по смыслу.

**Метод:** перевожу сам, 6 агентов по 4 языка параллельно. Потом — **обратный перевод `daily` каждого языка на
английский и прогон английской проверки на предсказания** (регуляркой по будущему времени переводы проверить нельзя:
английские тексты сами используют безличное будущее); итог — в `execute`. Ревью носителями — желательно, не
обязательно (не `@sensitive`).

**Для клиентов** — таблица «самое длинное `name` / `keywords` по языку» в `execute` и в передаче `0169` / `0170`
(баннер Home — `numberOfLines={1}`; подпись в `SpreadCardViewer` — одна строка).

## 2. Хранение — только в коде (решение 1 — Б)

- `src/modules/tarot/deck-translations/<lang>.ts` — 23 файла: `Record<cardId, { name, keywords, daily, source }>`,
  где `source` — отпечаток английского текста на момент перевода (короткий хэш `name|keywords|daily`); `index.ts` —
  `TAROT_DECK_TRANSLATIONS: Readonly<Record<TranslatedLanguage, …>>`, `TranslatedLanguage = Exclude<Language, 'en'>`.
- `localizeCard(card: TarotCardRecord, language: Language): TarotCardRecord` — чистая функция: `en` → как есть;
  перевода карты нет → английский (карта, добавленная в колоду раньше перевода, не ломает ответ).
- Таблицы, миграции и сида нет. Английский — в `TAROT_DECK_SEED` → `tarot_cards`, как сейчас. Репозитории не меняются.

**Единственная точка:** `localizeCard` вызывается внутри `toTarotCardDto(card, assetsBaseUrl, language)` — того самого
места, где любая карта становится DTO. `language` — обязательный параметр, без значения по умолчанию: компилятор
заставит каждый путь выбрать язык явно.
- `TarotService.toDto(card, language)` — карта дня и `pick` на **обоих** путях (первая запись через `findCard`,
  повтор через `findFirst`) — оба идут через `toDto`;
- `ChatService`: `toDto` / `toSpreadDto` получают `language`; `getHistory` передаёт язык запроса; отправка, вебхук,
  сверка, маркеры (всё, что уходит в сокет или в ответ отправки) — явно `SOURCE_LANGUAGE`: в сокет уходят только
  новые вставки, у нового расклада карты нет;
- `announceSpreadPick` берёт `card.name` из записи, не из DTO → английский.

## 3. Резолвер `?lang` — по `AURAT-0168-007` §2, без отступлений

- `src/common/language/request-language.ts` — чистое ядро:
  `languageFromQuery(raw: unknown, disabled: readonly Language[]): Language | null` (код из `LANGUAGES` и не
  выключенный, иначе `null`: нет параметра, неизвестный, `DE`, массив `?lang=de&lang=fr`, выключенный);
  `languageOrDefault(language) → SOURCE_LANGUAGE` при `null`.
- `RequestLanguagePipe` (`@Injectable`) берёт провалидированный `DISABLED_LANGUAGES` из `ConfigService`;
  `@RequestLanguage()` = `Query(LANGUAGE_QUERY_PARAM, RequestLanguagePipe)`; `@ApiLanguageQuery()` — одно описание
  для Swagger. `Accept-Language` не читается.
- `LANGUAGE_QUERY_PARAM` — реэкспорт в BFF `src/contracts/language.ts` (файл `0168`), после влития `develop`.
- Маршруты: контроллер получает `Language | null`, в сервис передаёт `languageOrDefault(…)` —
  `TarotController.getDaily`, `TarotController.pickSpreadCard`, `ChatController.getHistory`.

## 4. Тесты (чистые, без БД)

**Колода, на все 23 языка** (`deck-translations.spec.ts`):
- ровно 78 карт, те же id, лишних нет; ни одного пустого поля;
- три ключевых слова через « · », все непустые и разные; `keywords` ≤ 48 знаков (самая длинная английская — 36,
  запас ⅓); `daily` ≤ 220; имена без предела;
- 78 разных `name` и 78 разных `daily` в языке;
- `name`, `keywords`, `daily` ≠ английским (список исключений `SAME_AS_ENGLISH` — пустой, пока не понадобится);
- таблица мастей и рангов — константа на язык: имя карты масти содержит форму масти, придворной — форму ранга, туза —
  форму туза;
- NFC; нет U+00AD и U+02BC; fr — U+00A0 перед `? ! : ; »` и после `«`; ro — ș ț (не ş ţ);
- **отпечаток:** `source` каждой карты = хэш текущей английской карты из `TAROT_DECK_SEED`; тест называет карты и
  языки, которые надо перевести заново после правки английского;
- каждая локализованная карта как DTO проходит `tarotCardSchema`.

**Код:**
- ядро резолвера: нет параметра, неизвестный, `DE`, массив, выключенный `mt` при `DISABLED_LANGUAGES=mt` → `null`;
  `languageOrDefault`;
- `localizeCard`: `en`; переведённая; карта без перевода → английский;
- `toTarotCardDto` / `toSpreadDto`: переведённая карта, без перевода, нераскрытый расклад — без `card`;
- `tarot.service.spec`: `pick` с `de` — первая запись (`recorded: true`) и повтор (`recorded: false`) — оба по-немецки;
  заметка чаттеру — английская; карта дня — по-немецки;
- `chat.service.spec`: история с `de` — карта переведена; ответ отправки и `fanOut` — английский путь;
- смоук `tarot.smoke.spec`: заглушка `ConfigService` — по ключу (`DISABLED_LANGUAGES: ['mt']`, URL — для
  `TAROT_ASSETS_BASE_URL`); `?lang=de` → по-немецки; `?lang=DE`, без параметра, `?lang=mt` → английский.
- `npm run lint`, `typecheck`, `build`, `test`.
