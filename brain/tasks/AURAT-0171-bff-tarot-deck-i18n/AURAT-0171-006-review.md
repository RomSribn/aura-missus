# AURAT-0171-006 — review спеки 005 + решения владельца

Владелец на вопросы по `005` сначала попросил уточнить; ответ пришёл через координатора (`slave-1-9e`,

## Решения владельца

1. **Хранение — Б**: переводы только в коде (`deck-translations/<lang>.ts`), применяются одной функцией
   `localizeCard(card, language)` при сборке ответа. Без таблицы, миграции и сида. Причины: язык не протаскивается в
   чтения репозиториев (на этом стояли оба важных замечания); нет 1 794 строк сида на каждом старте; английская колода
   и так из кода.
2. **JSDoc `TarotCard.name` — А**: коммит в `main` контрактов после `v0.28.0`, без тега.

## Замечания (сверено с кодом)

Важные — с вариантом Б сводятся к одному требованию: **каждый путь, который отдаёт карту клиенту, проходит через
`localizeCard`.**
1. `pickSpreadCard` на успешном пути берёт карту `findCard(row.cardId)` (`prisma-tarot.repository.ts:126`), повтор —
   `findFirst include card` (~:142). По `005` первое нажатие вернулось бы по-английски. Тест — оба пути с `?lang=de`.
2. История собирает карту в `toStoredSpread` (`prisma-messages.repository.ts:341-354`), `MESSAGE_INCLUDE` общий.
   Локализовать при сборке расклада в DTO истории; остальные пути — английский. Тест: переведённая, без перевода,
   нераскрытый.

Средние: 3 — форма имени (именительный, артикль у старших по традиции, «артикль: да/нет» в шапке файла);
4 — `keywords` с пределом по языку, имена без предела + таблица самых длинных для `0169` / `0170`; 5 — обычный
регистр везде (el, ga тоже), капс — на клиентах; 6 — «без предсказаний» проверять обратным переводом `daily` на
английский + английской проверкой, итог в `execute`; 7 — проверки из `aura-app translations.test.ts:254-277` (NFC,
U+00AD / U+02BC, fr U+00A0, ro ș ț, `name ≠ English` с исключениями, таблица мастей и рангов константой);
8 — отпечаток английского текста в каждом языковом файле, тест называет устаревшие переводы.

Мелкие: 9 — «три ключевых слова» (бывают из нескольких слов), непустые и разные; 10 — заглушка `ConfigService` в
смоуке — по ключу; 11, 12 — отпадают с Б; 13 — реэкспорт `LANGUAGE_QUERY_PARAM` в `src/contracts/language.ts` BFF
после влития `develop`.
