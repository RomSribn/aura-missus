(от develop `6b429d2`). Выдано манором `manor-8e`.

Слова владельца (дословно): «посмотри 2 проблемы от клиента: 1 - почему-то у человек недоступный
слотбронирования Now (я по-этому выключил рабочие часы сейчас на проде), а 2 - проблема с локализацией,
при немецком языке и маленьком девайсе, как-будто недоступен контен на скрине бронирования [Image #5]
запусти это в свободныъ слейвах, можешь использовать эмулятор для тестов»

Этот слот — проблема 2. Проблема 1 — AURAT-0221 (aura-bff-manor slave-1).

Скриншот клиента: Android (Samsung), экран «Sitzung buchen» (`BookSessionScreen.tsx`):
- «WILLKOMMENSANGEBOT» в CouponTicket ломается по буквам на 4 строки рядом с «✓ Angewendet»;
- имя / роль советника обрезаны («Olivia Fl…», «Hellseheri…»);
- футер в столбик: сумма + старая цена, «Du sparst / 16,00 $» в две строки, кнопка «Uhrzeit wählen»
  (неактивна) — занимает бо́льшую часть экрана;
- от карточки «Private Chat-Sitzung» видна только шапка, длительность / дата / время / «Now» не видны.

Задача манора: найти, почему контент «как будто недоступен» (не прокручивается / нет признака
прокрутки / перекрыт футером), исправить вёрстку для узких экранов и длинных языков (не только de).
Эмулятор разрешён владельцем (emulator-5556 Galaxy_A16_API36, emulator-5554 Mi10T_Pro_API31), Metro —
из слота на отдельном порту; после проверки вернуть size / density / font_scale. Если «Now» не виден
из-за вёрстки — сразу сообщить манору (важно для AURAT-0221).
