# AURAT-0222-006 — approval

2026-11-20, через манора `manor-8e` (AskUserQuestion владельцу).

Владелец сам проверил кейс клиента на emulator-5556 (384 dp, ×2.0, de, −50%): «да, точно скроллится, проверил».

Решения:
- Спека — «Да, с дополнениями»:
  (а) один раз вызвать `flashScrollIndicators()` после загрузки контента: iOS сам полосу не показывает,
      на Android это тоже не помешает;
  (б) критерий приёмки: в случае клиента (384 dp, ×2, de, скидка) первый ряд длительностей виден без прокрутки.
- Шрифт — «Да, ×1.3»: `theme.fontScale.chrome` для футера, купона и ставки.
- Кнопка — «Да, в этой задаче»: неактивная «Uhrzeit wählen» по нажатию прокручивает к «Freie Uhrzeiten».
  Для озвучки она не disabled, а «ещё не готова»: нужны accessibilityHint и состояние, понятные
  TalkBack / VoiceOver. Новая строка — во всех 24 языках, с JSDoc и `@max`. Нужен тест на прокрутку по нажатию.
- Поломки на ×2 вне экрана — «Отдельный аудит позже». Записать follow-up в брейн, ID не брать.
- Ничего не коммитить до ревью манора и одобрения.
